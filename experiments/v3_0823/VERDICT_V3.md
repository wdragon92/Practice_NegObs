## 승용 요약 (5문장)

1. **계기판 셋 다 "판정 불가"가 나왔고, 사전등록 종합 규칙(§3.5)에 따라 예비 종합은 `미달`이다 — 다만 세 계기판 어디에도 `악화`는 없다.**
2. **막힌 곳은 두 군데뿐이다**: ① 트윈-조건부 recall 은 8지점 중 6~7지점이 옳은 방향이지만 **|Δ| 가 단 한 지점도 σ를 넘지 못했고**(풀링층 안에서 **H2 계단참형은 크게 이기고 H1 둔덕형은 크게 져서** 서로를 상쇄한다), ③ N-cue 함정 FA 는 **프레임축 8/8 전부 개선 방향**인데 **칸축에서 부호가 뒤집혀** §3.5 의 "축 간 부호 불일치 = 판정 불가"에 걸린다.
3. **그 부호 뒤집힘에는 하나의 물리적 정체가 있다** — v3-A 는 **울리는 프레임 수를 줄이는 대신 한 번 울릴 때 더 넓게 칠한다**(칸/FA프레임 v2 3.72 → v3 6.01, C팔·τ_op·시드 합산). 계기판② 가 이것을 독립적으로 확인한다 — **"울릴지 말지"는 단서 개수를 따르고(프레임축), "얼마나 넓게 칠할지"는 광학 질량을 따른다(칸축 8/8)**. 프레임축이 좋아지고 칸축이 나빠지는 것은 같은 사실의 두 얼굴이다.
4. **계기판② 는 애초에 v2 팔이 없어서(등록된 처분) 판정 대상이 성립하지 않는다** — v3 단독 절대값만 있고, 그마저 등록 하한을 통과한 단위가 4개라 회귀 자유도가 2다.
5. **판정표 밖에서는 사전등록이 예고한 거동이 실제로 관측됐다** — ⓐ v2 의 헤드라인 진단이었던 *"발화의 60 % 가 낙차를 지워도 남는다"* 가 v3-A 에서 **30 %** 로 반토막 났고(트윈 통과율 0.412 → 0.702, **FA-정합 프레임축 8/8 σ 초과** — 단 이 열은 사전등록 판정 지표가 **아니어서** 판정을 바꾸지 않는다), ⓑ 완전 은닉층은 `|Δp| ≤ 0.05` 가 21/21 × 3/3 로 유지되며(동등 발화 = 정답), ⓒ **맨-가림 H 는 조용하되 0 이 아닌 확률(보정 0.181 · 발화율 2.6 %)** 을 내는 반면 **같은 경험 위험빈도(0.24)의 단서 보유 H 는 20.9 % 발화**한다 — 단서-조건부 지도가 겨눈 바로 그 분리다.

### 2.1 단조성 항등 — "보정본 병기"의 정확한 의미 (**중요**)

temperature 는 **강단조** 변환이므로 (a) τ_op 0.5(`sigmoid(z/T) ≥ 0.5 ⟺ z ≥ 0`)와 (b) **분위로 잡는 FA-정합 8지점** 양쪽에서 **선택되는 칸·프레임 집합이 불변**이다. 따라서 계기판 ①②③ 와 헤드라인 표의 recall·FA 는 **원본과 보정본이 수치 동일**하다.

## §10. 한계 (정직 인쇄)

### 10.1 본 웨이브가 만든 한계

1. **σ 가 판정을 삼켰다.** `PREREG §3.2` 가 예고한 그대로다 — *"σ 가 큰 팔의 PASS 는 '움직이지 않았다'가 아니라 '3시드로는 판정 불가'다."* rgb 팔의 등록된 σ 실측이 V 0.204 · det 0.199 · E 0.380 이었고, 본 웨이브의 계기판 σ 도 같은 자릿수(0.04~0.19)다. **판정력이 있으려면 시드를 늘리거나 test-ext 씬 수를 늘려야 한다.** `§3.2` 는 *"씬-일반화 주장은 통계가 아니라 test-ext 의 씬 수 확충으로만 강화한다"* 고 못박았다.
2. **선택 에폭 산포 (D92 인쇄 의무 이월)**: 세 시드의 선택 에폭이 **24 / 2 / 11** 이다. β = 0.75 에서 H 항이 선택 점수의 **77~91 %** 를 차지하고 `rgb_s42` ep24 의 h = 62/90 은 인접 에폭(6·7)의 10배다. **본 판정 표의 시드 σ 는 '훈련의 산포'가 아니라 '선택 지점의 산포'를 상당 부분 포함한다.** 이것은 등록된 식이 만든 결과이며 결과를 본 뒤 식·문턱·patience 를 움직이는 것은 `§6-1` 위반이므로 본 웨이브도 아무것도 조정하지 않았다.

> 넘고 조성항은 **−0.299 로 음수**다. 즉 **넓어짐의 113 % 는 우는 프레임이 41 % 줄어서 생긴 비율 효과**이고,
> 조성으로 보면 v3-A 는 오히려 **덜** 칠했다. **다섯 가족 중 넷은 절대 칸 수가 줄었다.**
> **조성항이 실제로 양수인 것은 경계칸형⁻(63→147, +133 %)와 미분류(339→464, +37 %) 둘뿐이다.**
> 이 둘이 `§1`·`§5.4` 의 "넓게 칠함"에 남는 **유일한 가족 귀속**이다.

**D팔은 정반대이고, 거기서는 조성이 지배한다**: Δ **−3.376** = 규모 **−0.640** + 조성 **−2.737**.
가족별 Δ(절대 칸): 지형통계형⁺ −1.274 (260→173) · **경계칸형⁻ −0.872 (75→2, −97 %)** ·

**위험도 단서도 없는 팔에서 v3-A 는 실제로 덜 칠했고, 그 감축은 경계칸형⁻ 과 미분류에 몰려 있다.**
B팔은 Δ **+0.076** = 규모 +0.707 + 조성 **−0.631** 로 두 항이 거의 상쇄된다.

**미분류의 정체 (인쇄 의무)** `[실측]`: C팔 미분류는 v2 339건 중 밴드 **3a 250 · 밴드 2 80 · 밴드 1 9**,
