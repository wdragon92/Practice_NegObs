## 0. 결론 4줄 (먼저 읽을 것)

1. **"비어 있다"를 숫자로 확정했다.** 근경 지면 밴드의 **저주파 대비 σ_LF**(64× 다운샘플
   휘도 표준편차 ×100)가 실사 한국 도시 포장 **5.41~21.56**(n=8, 중앙값 11.0)인데
   담당 16씬 중앙값 **1.28** `[실측]`. **14/16 씬이 실사 하한 미달**이고,
   그중 **12씬(σ_LF 0.64~1.66)은 실사 중앙값의 1/7~1/17**이다.
   결(grain)은 있는데 **구조(structure)가 없다**.

2. **채워야 할 곳은 카메라 앞 0.56~2.0 m 의 폭 1.44 m 띠 하나다.** h0.3 프레임에서
   지면은 세로 **77.1 %**, 그중 **0.56~2.0 m 대역만 54.0 %p** `[실측]`. 5 m 너머 지면은
   전부 합쳐 **9.4 %p**뿐이다. → **요소를 5 m·10 m에 놓으면 아무 일도 일어나지 않는다.**

3. **원인은 요소 부재 + 포장 모듈 스케일 오류 2중이다.** 담당 16씬에서
   측구 0 · 빗물받이 0 · 잡초 0 · 맨홀 1씬 · 줄눈 기하 5씬뿐 `[실측]`.
   동시에 `plaza_light` 모듈이 **125×250 mm**(실측), `plaza_lower` **58×117 mm**로
   한국 규격(화강석 판석 300×600 / 보도블록 200×100 `[법령·KS]`)의 **1/2.4 · 1/1.7**이다.
   모듈이 작아 2 m 너머에서 앨리어싱돼 **무지 포장으로 붕괴**한다.

4. **가장 값싼 최대 효과는 프림 0개짜리다.** 실사 σ_LF의 주 원천은 맨홀이 아니라
   **포장 유닛별 톤 편차**다. 현행 MDL은 macro 파장 **14.0 m** 하나뿐이라
   1.44 m 근경 띠 안에서 사실상 상수다 `[실측: scene_common.py:1160-1161]`.
   **유닛 셀 해시 알베도 지터(σ≈0.10)** 하나로 σ_LF 대부분을 회수한다 — 기하 무변, GT 무변.

### 2.5 유닛 톤 편차 부재 `[실측]`

### 7.1 이월 지적 — sceneC2 낙엽 채도 `[실측]`

규약이 "수종명이 아니라 **잎 텍스처 픽셀을 직접 열어 판정**"하라 했으므로 열었다.

성격이 같다. 갈변 낙엽의 정량 채도 기준은 본 조사가 확보하지 못했다(§8).
**지적**: 최소한 `leaf_tex_tint`(의도적 오텀 가산분)를 **제거**해 텍스처 원본 채도로 되돌린다.

```bash
# 근경 밴드 지표 (하단 30 %)
python3 - <<'PY'
import numpy as np; from PIL import Image
def sigma_LF(p, band=0.30, k=64):
    a=np.asarray(Image.open(p).convert('L')).astype(np.float32)/255.
    H,W=a.shape; b=a[int(H*(1-band)):,:]
    h,w=b.shape; h-=h%k; w-=w%k
    return float(b[:h,:w].reshape(h//k,k,w//k,k).mean(axis=(1,3)).std()*100)
print(sigma_LF('look_check/scene01/v7_pt/pt_noon_preset_h0.3_d2.png'))
PY

# 카메라 모델 (검증됨): HFOV 60.0° / VFOV 35.98° / pitch −10° / eye=(−d, gy, h)
#   d(v) = h / tan(10° + atan((v−0.5)·2·tan18°))     v = 화면 세로 비율(위 0 → 아래 1)
#   반폭(D) = D · tan30°
```
