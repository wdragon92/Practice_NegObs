## scene01_campus_stairs — 벤치 차폐 해소

**결함**: `benches` 의 (−9.25, −3.0) 이 프리셋 그리드 d10 카메라 eye(−10, −2.75, h)
앞 0.79 m 에 놓여 `preset_h0.3_d10` 상단 전폭을 좌판 밑면으로, `preset_h0.9_d10`
하단 10 %를 좌판 띠로 덮었다.

**조치**: 해당 1기만 `cy −3.0 → −5.0`.

**검산**
- 중심–eye 거리 √(0.75² + 2.25²) = **2.37 m** (요구 1.5 m 이상 충족).
- 벤치 최근접 모서리(x −9.475, y −4.1; along="y" 이므로 길이 1.8 × 폭 0.45):
  전방 0.53 m · 측방 1.35 m → 시선축에서 **69°**. 수평 화각 ±30° 밖 = 프레임 밖.
- 간섭 점검: 화단 A(−5,−6, size 3 → x −6.5..−3.5) 불간섭, 자전거 거치대
  (x −13.5..−12.7) 불간섭, 상부광장 y0 = −8 이므로 벤치 남단 −5.9 는 슬래브 내부.
- 대칭쌍 점검
  - (−9.25, +3.0): 카메라 축선(y=−2.75)에서 5.75 m — 무해. 화단 B(−9, 6, size 3 →
    y 4.5..7.5)와 겹치므로 +5.0 대칭 이동은 **불가** → 존치.
  - (−11.95, ±3.0): eye x −10 보다 뒤(x −11.95) → 시야 밖. 무해.
- 벤치는 `cue_scene_dressing` 소속 드레싱이며 위험 기하 아님 → 트랜스폼 변경 허용.

**미반영(경미)**: 볼라드·자전거 거치대 백색화(0.55~0.65 권장)는 판정상 [경미]이며

## scene04_parktrail — 관목 형상 전면 교체 (재수정)

**결함(치명급 신규)**: v4-B1(경사 보정 `build_slope`) + v4-B2(군락당 3장 중첩)
조합이 역효과. `build_slope` 는 상면만 구배에 맞춘 **얇은 판**을 만들고, 그 판
3장이 서로 다른 각도로 어긋나 "잔디를 뚫고 나온 각진 판떼기 더미"로 렌더됐다
(`step_detail` 우측 x1250~1920 · `canopy_anchor` 우하 · `trail_approach` 좌우 ·
`preset_h0.9_d5` 중경). 구 렌더의 '회녹색 콘크리트 블록'보다 악화.

**조치**: 관목 군락을 **눌린 타원체(add_sphere) 3개 중첩 = 수관 blob** 으로 교체.

| 항목 | v4 (폐기) | v5 |
|---|---|---|
| 프리미티브 | `build_slope` 경사 슬래브 / `build_hedge` 박스 | `sc.add_sphere` (축정렬 회전체) |
| 파라미터 | `hedge.clumps = (dx,dy,sx,sy,h)` ×3 | `hedge.blobs = (dx,dy,rx,ry,rz)` ×3 + `embed=0.25` |
| 사면 처리 | 형상 자체를 전단(shear) | **배치 높이만** `_resolve_gz` 로 보간, 형상은 축정렬 |
| 접지 | 매입/부유 ±0.157 | 구 중심 = `gz + rz*(1−embed)` → 하단 `rz*0.25` 매입 |
| 재질 | `M["hedge"]`(잔디 텍스처 + 틴트, 잔디와 동계열) | `M["shrub"]` 상수색 신설 |

- `blobs = ((0.00,0.00,0.72,0.60,0.34), (0.52,0.40,0.50,0.42,0.25),
  (−0.44,−0.36,0.55,0.38,0.29))` — 최대 높이 1.75 × 0.34 ≈ **0.60 m**
  (구 군락 최대 h 0.62 와 실루엣 규모 동등, 평면 점유 ≈ 1.5 × 1.2 m).
- 재질 `shrub = (0.030, 0.047, 0.021)`, `rough 1.0`, `specular_level 0.0`
  — 기존 수관 알베도 규약(0.025~0.06 계열) 준수. `canopy_a/b`(0.035~0.060)보다
  한 단계 어둡고 채도를 낮춰 판정 (c)"잔디와 더 분리" + '나무 수관 vs 지면 관목'
  구분을 동시에 만족.
- 사면/평탄 분기 자체가 사라져 **경사 전단 아티팩트가 원천 소멸**.
  프림 경로(`Hedge_{n}_{j}`)와 군락 6개소 좌표는 불변.
- 콜라이더: 구 슬래브는 `collider=True` 였으나 관목은 보행 충돌 대상이 아니고
  지면(잔디 슬래브)이 이미 콜라이더를 가지므로 미부여(`add_sphere` 규약).

**범위 밖으로 남긴 것**
- `slope_understory` 밴드(D8)와 `bg_slope_hedges`(A3 봉합)는 **길게 이어지는
  식생 띠**라 파편 인상을 만들지 않고, A3 사면 봉합이라는 기하 역할이 있어
  `build_slope` 를 유지했다(`grade` 계산도 이 용도로 존치).
- (경미) 낙엽 무더기 D11 직사각 데칼 경계, 하부 트레일 좌측 슬래브 5~10 cm
  연단(구 렌더에도 존재 = 이번 수정 무관, 별건 정리 권장).

## scene05_amphitheater — 라이저 패치 / 뷰 차폐 / 지지대

### 1. 진입 아크 계단 라이저의 백색 사각 패치 — 원인 규명 후 제거

**증상**: `preset_h1.8_d2` (860,460–1010,560)에서 석재 텍스처 라이저 위에
텍스처 없는 순백 직사각형이 좌우 대칭 1쌍씩, **한 단 걸러** 반복.

**원인(추적 근거)**
- 패치가 나타나는 단은 `Step_1 / Step_3 / Step_5` 뿐이고, 이 세 단의 내경
  `r_in` 이 각각 **6.65 / 5.8 / 5.0** 으로 티어1/2/3 의 `r_in` 과 정확히 동일.
- 즉 진입 계단 라이저면(seg 4, dθ 4.5°)과 티어 내면(seg 32, dθ 11.25°)이
  같은 반경의 동일평면이면서 세그 분할만 달라 두 접평면이 스치듯 교차 →
  교차 근방에서 깊이 정밀도 이내로 붙어 **Z-다툼**.
- 위로 올라온 쪽이 티어 재질 `plaza_light`(밝은 무늬 없는 화강암)이라
  '텍스처 없는 순백 사각형'으로 보였다. 좌우 1쌍인 이유는 두 접평면이
  θ = ±(진입 seg 중앙과 티어 seg 중앙의 중점)에서 교차하기 때문.
- `Step_0/2/4` 의 `r_in`(7.075 / 6.225 / 5.375)은 티어 경계가 아니어서 무증상 —
  '한 단 걸러' 패턴과 정확히 일치.
- 세그 간 틈 가설은 기각: `build_arc_steps` 가 `chord × 1.03` 으로 이미 겹침을
  확보하고 있어(진입 단 기준 세그당 약 25 mm 접선 여유) 틈이 생길 수 없다.

**조치**: 진입 계단 반경 사다리를 **10 mm 안쪽으로 평행 이동**(r-캐스케이드).
v4-A1 이 쓴 z-캐스케이드(−1.200 > −1.203 > −1.207)와 같은 취지의 반경판.

```
entry.radii (7.5, 7.075, 6.65 , 6.225, 5.8 , 5.375, 5.0 )
         →  (7.5, 7.065, 6.64 , 6.215, 5.79, 5.365, 4.99)
```

**검산**
- 진입 라이저면이 그리는 실제 반경 범위 = `r .. r/cos(2.25°)` = `r + 5.1 mm`.
  → 6.640 .. **6.6451** vs 티어 내면 최소 **6.650** ⇒ 전 구간 ≥ 4.9 mm 이격.
  티어2 5.5 mm(5.7945 vs 5.80) · 티어3 6.1 mm(4.9939 vs 5.00) — 동일평면 소멸.
- 진입 단이 티어보다 10 mm 안쪽에 서므로 티어면이 확실히 가려진다(밝은 면 미노출).
- 공극 점검: `Step_2` 외경 6.64 ~ 티어1 내경 6.65 사이 10 mm 구간은
  `Step_1`(6.64..7.065, base −1.6)이 z −0.397 까지 채운다 → 관통 공극 0.
  최하단 `Step_5` 내경 4.99 는 스테이지 림(r_out 5.22) 내부에 매입 → 노출면 없음.
- **위험 기하 불변**: `tops`(라이저 0.20 × 6단, 총 낙차 1.2 m) · `a0/a1/seg/base_z`
  전부 불변. 디딤폭은 최상단만 0.425 → 0.435, 나머지 0.425/0.375 그대로 →
  보행 프로파일(A2/A3 재설계 결과) 동일.
- 동일 함수를 쓰는 `aisles`(seg 3, dθ 4°)도 자동 반영: 바깥 반경 여유
  `r/cos(2°) = r + 4.0 mm` < 10 mm → 티어와 이격 유지.

### 3. 나무 지지대(stakes) 무력화 — 공통 수정 누락분 반영

**결함**: v4-B3 '신식재 삼각 지지대 제거' 공통 수정이 scene01/03/04 에만
반영되고 scene05 만 누락(`stage_lookup` 좌우 · `side_arc` 좌측 ·
`preset_h0.3_d10` 네 모서리에 지지대 노출) → 5씬 일관성 붕괴.

**원인**: scene05 는 나무를 `sc.build_planter(..., tree_mtls=...)` 로 심는데,
`build_planter` 는 내부 `build_tree` 호출에 stake 인자를 전달하지 않는다.
`scene_common.py` 는 수정 금지 대상.

**조치**: 씬 로컬 헬퍼 `planter_no_stake()` 신설.
1. `sc.build_planter(..., tree_mtls=None)` 로 화단(경계석·캡·잔디)만 생성,
2. `sc.build_tree(..., stake_r=0.004, stake_h=0.02, stake_off=0.2)` 로 나무를
   직접 식재 — scene03/04 와 **동일 규약**(치수 0 근접으로 무력화).

**검산**
- 식재 높이 `base_z + 0.40` = `build_planter` 내부 호출과 동일
  (`grass_h` 기본값 0.40, 내부는 `build_tree(..., base_z + gh, ...)`).
- 프림 경로 동일(`{prefix}/Trunk`, `{prefix}/Canopy_i`, `{prefix}/Stake_i`) →
  기존 USD 계층·이름 규약 유지.
