## 1. C-1 — `paving_interlock` 텍스처 교체 (감독 승인 항목)

### 문제
구 텍스처는 **이끼 낀 유럽식 사고석**(불규칙 석괴 + 황록 줄눈)이라 06/08/11/13 도시 4씬의
보도·광장이 "고성 광장 바닥"으로 렌더됐다. 게다가 석괴가 커서 h0.3 컷의 60~80 %를 점유.

### 선정 과정
1. ambientCG API(`/api/v2/full_json?type=Material&q=paving`)로 후보 165종 열거 →
   `PavingStones*` 150종 프리뷰(`surface-preview/{ID}/{ID}_SQ_Color.jpg`) 일괄 수집 후
   컨택트시트 5장으로 육안 스크리닝.
2. 1차 후보 8종(006 / 015 / 078 / 081 / 093 / 095 / 109 / 135) 확대 대조.
   - 006·078 : 러닝본드 회색이나 블록이 크고 표면이 거칠어 옹벽 블록 인상.
   - 093·095 : 회색+적갈 2색 인터로킹(한국 2색 관행에 근접)이나 **이끼·마모**가 있어
     C-1 이 지적한 "유럽 노후 포장" 인상이 남는다.
   - 135 : 적갈 인터로킹, 채도가 높아 광장 전면에 깔면 과함.
   - **015 · 109** : 무이끼 정형 콘크리트 블록. 109 는 오염·얼룩이 있어 최종 **015** 채택.
3. `curl -sL -A "Mozilla/5.0" "https://ambientcg.com/get?file=PavingStones015_2K-JPG.zip"`
   → Color / NormalDX / Roughness 를 canonical 파일명으로 반입.

### 반영
| 대상 | 값 |
|---|---|
| 소스 | ambientCG **PavingStones015** (CC0, 2K-JPG, 2048², photogrammetry) |
| 파일 | `assets/paving_interlock_{diff,nor,rough}.jpg` (경로·파일명 **불변**) |
| 패턴 | 정형 인터로킹 블록 바스켓위브, 회색 콘크리트, 모래 줄눈, 이끼 0 |
| 알베도 | sRGB 평균 0.552 → **선형 0.271**(p99 0.42) — §4 순백(>0.8) 무관 |
| 반복수 | 정사각 유닛 170 px / 2048 = 타일당 12 → 블록(2유닛) 장변이 |
| 실블록 크기 | scale_m **1.0 → 0.17 m** · **1.2 → 0.20 m** · **1.5 → 0.25 m** (실물 200×100 대역) |

- 즉 06/11(scale 1.0) 0.17 m, 13(1.2) 0.20 m, 08(1.5) 0.25 m — C-1 이 요구한 "블록
  0.2×0.1급"을 **텍스처 자체의 반복수로 달성**했다. TEX 경로가 그대로이므로 **씬 파일
  수정·재검증 불필요**(scene06/08/11/13 의 `scale=dict(paving_interlock=…)` 손대지 않음).
- 시각 대조: `Docs/audit_v4/fixlog_W0_paving_cmp.png` (구/신 2×2 타일링, 1타일 = 1 m).
- `scene_common.py` TEX 등록부에 출처·반복수·씬별 블록 크기를 주석으로 명기.
- 구 텍스처 3종은 세션 스크래치패드에 백업(재현이 필요하면 위 curl 1줄로 재취득 가능).

## 2. C-5 — `build_hedge` 형상 자연화 (갈색 육면체 → 상단 라운딩)

### 문제
12 억새 4띠 · 13 생울타리 3매가 **단일 각진 박스**라 "건초 더미 / 흙벽돌 상자"로 읽힘.

### 반영 (`scene_common.py:build_hedge`)
- 시그니처 : `(…, h, mtl=None, base_z=0.0, scale_m=1.2, tint=…, **rounded=True,
  crown_max=48, bulge=1.03**)` — 신규 3개 전부 말미 키워드·기본값이라 **기존 호출 무영향**.
  (전 씬 호출부 스캔 결과 위치인자 7개 초과 사용처 0건, 반환값 사용처 0건 확인.)
- 구조 : 본체 박스를 `h*0.72` 로 낮추고(경로 `prefix/Box`·collider 유지) 그 상단
  z 에 **눌린 타원체(crown blob) 열**을 겹쳐 상단 실루엣을 라운딩·요철화.
- 덩이 크기 ≈ 수관 높이(`pitch0 = max(0.30, min(W, 1.2h)) × 0.9`), 띠가 넓으면 단변 방향
  **2~3 열을 반 피치 엇갈려** 배치(`Crown_{열}_{i}`) — 폭 넓은 억새 밴드가 "가로 소시지"가
  되는 것을 방지.
- 결정성 : 좌표+길이 해시 시드 → 재실행 동일, 띠마다 요철이 다름.
- 안전장치 : 상면 정점 ≈ `base_z+h` (블롭별 ±6 %), 장변 끝단 돌출 **≤ 5 cm 클램프**,
  단변 돌출 ≤ 0.1×열폭 → 벽 상단(15 RetHedge)·개구 에지(D3 Overhang) 배치에서도
  부유·과돌출 오독 없음. `rounded=False` 또는 `h≤0.06 / 장변≤0.05` 이면 **구 동작(단일 박스)**.

## 3. C-4 보조 — `build_tree` 원경 롤리팝 완화 + 줄기 과세 보정

감독이 이미 수정한 **부호(a)·지지대 기본 OFF(b)** 코드는 그대로 두고 다음만 추가.

- 위성 블롭 **7 → `canopy_blobs=10`**(기본), 중심 블롭도 축비 지터(구형 실루엣 회피).
- 산포 상향 : 반경 `0.15~0.55 → 0.18~0.68`, 블롭 반경 `0.30~0.55 → 0.30~0.58`,
  연직 분포 `0.05~0.85 → −0.05~0.95`, 납작률 지터 확대.
  → 검산: 기본값 나무 1그루 수관 최대 반경 1.05 m, 블롭 11개, z 1.66~3.25.
  (구 대비 외곽 반경 +약 16 %로 억제 — 기존 씬에서 난간·건물과의 관통 위험 최소화)
- **`canopy_spread=1.0`** 신설: 원경 개체만 키우고 싶은 씬이 `canopy_spread=1.15` 등으로
  미세조정 가능(호출 없으면 무변화).
- **[mod6 §1(c)] `trunk_r` 기본 0.06 → 0.09**(지름 18 cm). `trunk_r` 를 명시 지정하는
  호출(03/04/07/10/N5 등)은 영향 없음 — 기본값 호출(05/17/18 등)만 개선된다.

- `python3 -m py_compile scene_common.py` 통과. `scenes/main`·`scenes/batch1` 의
  `scene_common.py` 는 루트 파일 심볼릭 링크라 자동 반영.

  RT 재렌더 시 확인할 것: ① 06/08/11/13 보도 블록 크기 인상(특히 08 scale 1.5 = 0.25 m),
