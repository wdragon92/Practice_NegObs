# 조사 배경 브리프 (병렬 에이전트 공용) — 2026-07-28

## 연구 본체
- **주제**: RGB 맥락단서(scene + element context)만으로 **보이지 않는 낙차(negative obstacle /
  drop-off)** 를 추정. 기존 연구는 "보이는 시야각 기반 직접 탐지"(LiDAR/스테레오)인데,
  이 연구는 낙차가 **카메라에서 안 보이는 상태**에서 주변 맥락으로 추정하는 것이 핵심.
- **학습 방식**: U-Net 계열 segmentation (낙차 위험 영역 / 낙차량 맵).
- **데이터 전략**: **시뮬레이션에서 합성 데이터 생성 → 학습 → sim2real 로 실제 환경 전이**.
  즉 sim2real 이 논문의 성립 조건. 시뮬레이터 렌더가 현실과 너무 다르면 주장 자체가 무너짐.
- **맥락 단서 4계열**: ①설비 역추론(난간·볼라드·점자블록 = 법이 낙차에 강제 → 준공 증거)
  ②기하(텍스처 절단·도로끝-하늘 접합) ③스케일 앵커(수관·차 지붕·사람 상반신이 눈높이 이하)
  ④조명(암부·그림자 — 확증 전용).
- **스코프**: 주간 가시광 한정(야간 제외). 대상 = 한국 일상 보행/주행 공간
  (캠퍼스·지하도·공원·수변·육교·주차장·골목·산사·제방).

## 현재 구현 상태 (문제의 대상)
- **Isaac Sim RTX** 로 Python USD 스크립트가 씬을 절차적으로 조립. 총 33씬
  (본편 21 = `scenes/main/`, hard-negative/변주 배치 12 = `scenes/batch1/`).
- 렌더: `RaytracedLighting`(반복) / `PathTracing`(최종, totalSpp=512, maxBounces=8,
  OptiX denoiser on), DLSS Quality, 1920×1080, headless viewport capture.
- 조명: `DomeLight`(PolyHaven HDRI `qwantani_noon_puresky_4k.exr` + 자체 lookfix 파생본:
  태양 원반 클램프 + 지평 헤이즈 리프트) + `DistantLight`(angle 0.53°, HDRI 태양 방위 정합).
  흐림용 `kloofendal_overcast_4k.exr`.
- 재질: **OmniPBR MDL 단일 계열**. `scene_common.make_pbr()` — diff/nor/rough 3맵
  (PolyHaven/ambientCG 4K jpg) 월드 트라이플래너 투영 또는 st-UV + 상수 틴트.
- 지오메트리: **전부 USD 프리미티브** — `UsdGeom.Cube` / `Cylinder` / `Sphere` 조합.
  외부 메시(glTF/FBX/USD 에셋) 임포트 **0건**. 베벨/챔퍼 **0건**. 변위/테셀레이션 **0건**.
- 식생: 나무 = 눌린 구(Sphere) 3개 중첩 + 원기둥 줄기. 관목/헤지 = 눌린 구.
  잔디 = **지오메트리 없음**, 평면에 텍스처만.
- 지면: 평면 슬래브(Cube) 위 타일링 텍스처. 미세 기복/침하/균열/웅덩이 지오메트리 없음.
- 건물: 무텍스처 흰/회색 박스 + 파란 사각형 = 창문. 창틀·멀리언·반사·발코니·실외기 없음.
- 없음: 사람/차량 등 동적 개체, 데칼(오염·균열·페인트), 소품 엔트로피(쓰레기·낙엽 더미·
  케이블·맨홀), 렌즈/센서 효과(비네팅·수차·블룸·DoF·모션블러·노이즈·노출/AWB),
  도메인 랜덤화, GT 라벨 파이프라인(아직 미착수).
- 조건 변주는 batch1 일부만 (눈 C1 · 낙엽 C2 · 젖음 C4). 본편 21씬은 **정오 맑음 단일 조건**.

- RTX 4090 24GB **1대**, Ubuntu, Isaac Sim. Blender 4.5 설치돼 있음(`~/blender-4.5.4-linux-x64`).
- 렌더 병렬 금지(GPU 1대). PT 1컷 수백 프레임 누적 필요.
