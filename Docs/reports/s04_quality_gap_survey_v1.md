### 1.2 지표 정의 `[본 조사 신규 — numpy+PIL, GPU 0]`

- `micro_sd` = `median(local_std(luma, 5×5)) × 255` — 재질 입도(8비트 레벨). 값이 클수록 표면에
  국소 요철/입자가 산다.
- `flat%` = `100 · mean(local_std(luma,5×5) < 1/255)` — 죽은 평면 픽셀 비율. `t1_material_layer_spec_v1.md`
  §2.2 의 `flat_gnd` 정의와 동일 커널(다만 하단 2/3 제한 없이 전화면).
- `bins50` = sRGB 를 채널당 16단계로 양자화했을 때 **화면의 50 %를 덮는 데 필요한 색 구간 수**.
  팔레트 폭 지표(작을수록 단조).
- `modal_tile%` = 16 px 타일 평균휘도의 최빈 2 % 버킷이 차지하는 타일 비율 — **단일 톤 슬래브 점유**.
- `tile_peak@lag` = 자기상관 최대 피크(lag ≥ 8 px) — **주기 반복(타일링) 가시성**. 1.0 에 가까울수록
  주기적, 짧은 lag 의 낮은 값은 "부드러운 그라디언트", 긴 lag 의 높은 값은 "무늬 반복".
- `bound/W` = 하늘/비하늘 경계선 길이 ÷ 프레임 폭 — **실루엣 복잡도**(무차원).
- `w80` = 하단 2/3 에서 `min(R,G,B) > 0.80` 픽셀 비율(sRGB 표시값) — 규약 "순백 대면적 금지" 지표.
  `t1_material_layer_spec_v1.md` §2.2 정의 그대로. `w75` 는 같은 정의의 0.75 판.
- `gnd_*` 접두 = **하단 35 %** 밴드(보행자가 보는 노면)만 떼어 같은 계산을 한 것.
  `gnd_chroma` = `mean(max(RGB) − min(RGB))` (무채색이면 0).
- `sat` = 하단 2/3 의 `mean((max−min)/max)` — HSV 채도 평균.
- `edge>0.02%` = 인접 픽셀 휘도 기울기 크기가 0.02 를 넘는 픽셀 비율 — 구조·윤곽 밀도.

전 지표는 세션 스크래치의 `imgstat.py` / `region.py` 로 계산했다(작업용, 리포에 커밋하지 않음).
재현이 필요하면 위 정의만으로 충분하다 — 외부 의존은 `numpy` + `PIL` 뿐이다.
