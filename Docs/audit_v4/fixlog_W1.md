### 1-2. 카메라 재조준 — `spiral_up` (판정 ④ / C-8)

구 컷(eye 6.13,−13.60 → 서향)은 **음영측 외벽 + 데크 소핏 암부**로 프레임 90 %가
죽었다. 태양 방위를 좌표로 풀어 순광 축을 잡았다.

```
돔 회전 φ = 171.5 − 110 + 233.5 = 295°
그림자 방위 = atan2(cosφ, −sinφ) = 25°  →  태양 방위 = 205°, 고도 49.79°
나선 상행 접선 방위(하단부, a≈114°) = (sin a, −cos a) → 방위 24°
  ⇒ 상행 방향을 보면 시선 방위 ≈ 0~25°, 피사면 법선 ≈ 180~205° = 순광
```
`spiral_up = eye [1.70, −11.20, 1.45] → tgt [5.30, −11.20, 2.15]`
(진입 통로 방위 135° 에서 상행 방위 45° 를 봄. 통로 유효고 4.503 m 안, 기둥
r0.5 축에서 1.8 m 이격 — 스모크 ray march 무차단.)

## 4. 후속 확인 요청 (다음 렌더 판정에서 볼 것)

1. **06 그리드(데크 종주)** — 기둥머리 상면(5.000)과 원경 수목 띠가 하나의
   연속 평면으로 읽히는가. 개방 베이 너머로 차도·원경이 비쳐 회랑 암부가
   걷혔는가.
2. **06 페시아/소핏** — 외주 실루엣이 매끈해졌는가, 지상 시점(`ground_graze`)
   에서 적층 블록 인상이 사라졌는가. 페시아 상단 립(최대 0.154 m)이 디딤
   판독을 방해하지 않는가.
3. **06 `spiral_up`** — 순광 재조준으로 상행 판독이 성립하는가(구 컷은 암부 사망).
4. **06/11 콘크리트 중성화** — `concrete_wall` × 등화 틴트가 갈색기를 제거했는가.
   알베도 0.40/0.435 가 정오광에서 과하지 않은가.
5. **11 `sidewalk_approach`** — 사인이 접근자를 마주보며 흑색 사각형이 사라졌는가.
6. **11 `under_grating`** — 역광 축에서 슬릿 투광 스트라이프가 보이는가.
   태양 근접(방위차 25°)으로 인한 과노출이 없는가(있으면 고도 축만 −10° 조정).
7. **06/11 수목 띠** — 지평은 닫혔는데 원경이 "녹색 벽"으로 답답해지지 않았는가.
   (답답하면 `treeband["rows"]` 의 높이만 낮추면 된다 — 기하 영향 없음.)
