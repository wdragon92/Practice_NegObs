- 해석 사전 등록: recall이 단서 쪽에 몰리면 논지 성립 / 맨-가림 쪽에서도 높으면 지름길 증거 —
  어느 쪽이든 논문 재료. 헤드라인 숫자 무수정(분석만 얹는다).

### 6.2 CUE-OFF 대조 (구명 B1) — 개입 실험

- **질문**: "본 표의 그 모델(frozen)이 단서에 의존하는가" — 재학습하면 질문이 바뀌므로
  **zero-shot 평가 전용**(frozen 체크포인트 무수정, 추론만).
- **절차**: ① 비-test 씬 중 매트릭스 기준 단서 풍부한 H 씬 1–2개 선정(선정 근거 기록) ②
  `cue_*` 토글(PS §2 규약 — 위험 기하 불변)로 **위험 유지 + 단서 제거** 팔을 격리 렌더,
  위험 기하 불변 해시게이트 ③ RGB/Depth/B2 × 3시드 zero-shot 평가 ④ 기존 on팔 대비 H recall Δ.
- **확장(여력)**: 무위험+단서 팔 추가로 {위험+단서 / 위험−단서 / 무위험+단서} 삼각 완성.
- 해석 사전 등록: 붕괴 → "모델이 단서를 쓴다"의 개입 증거 / 유지 → 지름길 신호(한계 구체화).

### 6.3 sceneC2 원인 규명 `[승용: "필요하면 씬은 더 고쳐나가도 좋아"]`

- **차이 감사**: sceneC2가 타 씬과 다른 점 전수 비교 — 구성 요소·재질/MDL·깊이 통계 분포·
  장식 밀도·카메라 프리셋·h0.3 가시성 → 가설 목록 `C2_ROOTCAUSE.md`.
- **분기 증거**: GPU-1(Depth 신off 평가)이 1차 분기 — 신off에서도 Depth FA 잔존이면 기하/렌더
  요인 우세, 소멸이면 장식 요인 우세. 필요 시 요소 단위 토글 소형 렌더(격리)로 가설 검증.
- **씬 수정**: 수정판은 **신규 버전 씬으로 격리 제작**(정본 씬 파일 무수정), 변경 대장 기록.
  본 표 반영 여부는 결재란 — 단 §5.3에 따라 수정판 기반 재평가 결과는 미리 뽑아 둔다.
  test 씬의 수정판은 진단 전용으로만.

### 6.4 YOLO∪U-Net 융합행 (재훈련 0)

- 기존 YOLO det2cell 출력(τ 0.25)과 U-Net 그리드(τ 0.5)를 **셀 단위 OR(max 병기)**로 합성 →
  본 표 형식의 추가 행. V/E/H 층화 + FA + 트윈 Δ 전부, 3시드.
- 목적: "V는 YOLO, E/H는 U-Net" 상보성의 정량 증거. 본문/부록 배치는 결재란.
- 백본 이식·캐스케이드류 재훈련 구조는 EXTENSION_LOG에 연장 단계 제안으로 계보와 함께 기록.

### 6.5 3a/3b 원인 규명 (결재 #4 재료) `[승용: "시점 때문일 수도"]`

- **재집계 분기(CPU-2 우선)**: 기존 평가 산출물에서 3a/3b 프레임을 시점 프리셋(h×d)·씬·가림
  주체별로 층화, Δ와 recall 분해 → 3a의 Δ≈0이 전 시점 균일인지 특정 시점(h0.3 등) 집중인지
  → `3A_VIEWPOINT_AUDIT.md`.
- **렌더 분기(GPU-5, 조건부)**: 집중 신호가 나오면 해당 구성 소형 프로브로 확인.
- 산출: 재결재안 — "3b 한정 유지" vs "시점 조건부 서술" 중 근거 우세안 + Claude 예비 판정 +
  양안 문장 초안.

### 6.6 광도 스트레스 (평가 전용)

- **val 프레임**에 밝기/감마/노출 변형 → frozen 체크포인트 zero-shot 성능 곡선. 훈련 무접촉,
  **test 사용 금지**. 목적: 실측 파일럿 전 조명 민감도 사전 정보(#5·#6 연동).

### 6.7 Gazebo 트랙 — 조사→구축→비교 `[승용: "필요한 부분… 가능하면 진행"]`

- **목적 2층**: ① (이번 창) **교차 시뮬레이터 zero-shot** — Isaac Sim에서 배운 frozen 모델이
  Gazebo drop-off 씬에서도 단서를 읽는가(도메인 갭 일반화 증거 후보 + baseline 동일 환경 비교
  기반) ② (연장) TurtleBot3·ROS 실기 트랙의 시뮬 기반.
- **단계 (각 단계 착지 기록 후 다음 — 어디서 멈추든 산출이 남는 구조)**:
  a) 조사 — baseline 논문의 Gazebo 환경(버전·월드·에셋 공개 여부) 파악, Classic/신형 gz와
     ROS1/2 선택 근거 확정.
  b) **격리 설치** — 성립 조건: `env_isaaclab` 무접촉(7월 환경 층화 사건 계보). Docker 또는
     완전 분리 워크스페이스, 설치 후 시스템 파이썬 무오염 검증.
  c) drop-off 씬 제작 — 계단·단차 기하 + 단서 오브젝트(난간·경고블록) 최소 1–2씬, 카메라
     프리셋 h0.3/h0.9 정렬, 씬 사양 기록.
  d) 캡처 → frozen 3모델(RGB/Depth/B2) zero-shot 평가(실사진 추론 경로 재사용) → 정성 패널
     필수 + 가능하면 그리드 정량.
  e) (여력) baseline YOLO를 동일 씬에서 실행 — 동일 환경 직접 비교.
- 산출: `GAZEBO_TRACK.md`(단계별 착지). 논문 반영 범위는 결재란 + Claude 예비 판정.
- 시간 규율: 45분 룰을 **단계 단위**로 — 설치가 막히면 조사 산출로 착지하고 큐 복귀.
  실패도 착지다. GPU 사용 구간(d)은 락 규약 하 짧은 홀드로.
