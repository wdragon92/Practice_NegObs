Generated by `rt_response/code/f2_twin_conditional.py` · CPU · read-only over the frozen v2 twin dumps.

**Definition.** A hazard-ON frame counts as a *twin-conditional* hit iff the model fires on a GT-positive cell **and** the byte-paired hazard-OFF twin of the same camera cut does **not** fire on those same cells:

```
hit(frame) = [ max_on_gt ≥ τ ]  ∧  [ max_off_gt < τ ]      τ = 0.5
```

The off arm costs no extra render and no extra inference — it is already in `twin/twin_pairs.csv`.  Pairs are the KEPT (pose-matched) pairs.
