## 1. scene03_riverbank — 사행 판정 컷 신설 (기하 무수정)

### ① 판정 ㉠ "코드상 사행은 있으나 판정 가능한 컷이 하나도 없다"

원인 분석(판정 동의): 구 4컷(`levee_walk`·`stair_down`·`beach_lookup`·`across_river`)이
전부 하천에 **직교**해 화각 안 하천 길이가 15~40 m 뿐 → 파장 110 m 곡선은 그 구간에서
사실상 직선. **미장센 3컷 신설로 대응**(기하·PARAMS 사행 상수 무수정, 카메라만).

| 컷 | 시점 | 부각 | 프레임 내 수변 길이 | 직선 대비 휨 | 차폐 |
|---|---|---|---|---|---|
| `river_along` [미장센] | 둑마루 자갈도로 h1.65, 상류 종방향 | −6.2° | 33.5 m | 0.43 % | 8/68 |
| `meander_air` [판정] | 둔치 상공 h16, y −44 → +25 | −15.4° | 64.0 m | **14.09 %** | 41/129(교량 34) |
| `bank_oblique` [판정] | **건너편 둔치** 상공 h8, 상류 사선 | −12.7° | 60.0 m | **14.15 %** | 26/121(전부 교량) |

* 좌표는 전부 `river_dx()` 를 통해 사행 좌표계에서 계산 — 진폭을 바꾸면 카메라도 자동 추종.
* **휨(bow) 지표의 근거**: 3차원의 직선은 어떤 투영에서도 직선으로 맺힌다. 따라서
  수변선(s=18.2)을 화면에 투영해 **양 끝점을 잇는 현에서 벗어나는 최대 편차**는
  "직선 수로였다면 정확히 0" 인 순수 사행 신호다. 이를 프레임 반폭(tan30°) 대비 %로 환산.
  구 4컷은 이 값이 0.0~0.1 % 수준(프레임 안 수변선 자체가 짧다) → 판정 불가였다.
* **차폐 검산**: 카메라–수변 표본을 잇는 선분과 근경 요소(교량+파라펫·수목 수관/줄기
  분리·파고라·볼라드·수위표·원경 도시) AABB 의 slab 교차. 판정 2컷의 차폐는 **전부
  교량 상판** 이며 연속 구간(하천을 가로지르는 다리는 정상 미장센) — 나머지 구간은 개방.
  수목은 수관과 줄기를 분리해 넣었다(통짜 박스로 잡으면 수관 아래 빈 공간까지 오판).

### ② 사행 진폭 상향 — **하지 않았다**(정량 근거)

지시는 "필요시"였고, 다음 세 가지로 **불요**라고 판단했다.

1. 현 진폭/수로폭 = 14.8/15.8 = **0.94** 로 브리프 요구 "1~2배"의 하한을 이미 충족.
   판정문도 "코드상 사행은 있다"고 인정했고 결함은 **컷 선택**이라고 명시했다.
2. 신설 판정컷에서 화면 휨 14 % (프레임 반폭 대비)가 확보된다 — 육안 판독에 충분.
3. 진폭을 올리면 **자기 규약이 깨진다**. A1 6.0→6.8·A3 −2.0→−2.6(진폭 17.3) 을
   시산하면 최대 |yaw| 26.7°(현 23.2°)까지는 괜찮으나, y −47.5..−37.5 꼬리에서
   인접 세그 yaw 변화가 **7.7° > 규약 6.5°** 로 튀고(사인·3차항 상쇄 지점의 변곡),
   밴드 겹침 lip 도 0.46 → 0.69 m 로 커진다. 세그를 촘촘히(seg_dy 5.0→4.0) 하면
   해소되지만 밴드 프림이 약 30 % 늘고 **위험 기하 주변 재조립**까지 유발한다.
   → 비용 대비 이득이 낮다. **감독이 원하면 A1=6.8·A3=−2.6·seg_dy=4.0 한 줄로 적용 가능**
   (그 조합의 검산 수치는 위와 같다).

### ③ 판정 ③(신규 결함) 처리

| 항목 | 조치 |
|---|---|
| 볼라드 과대 | `cx −0.6→−1.2` · `cy ±1.5→±2.2`. **−X 로 후퇴시키면 카메라(−6)에 가까워져 오히려 커진다** → 도로-스퍼 경계선(s −1.0)까지만 물리고 시선축 밖으로 벌렸다. `levee_walk` 기준 방위각 \|az\| 14.8° → **25.3°**(프레임 가장자리). 계단 진입 전면이라는 §2 기능 근거는 유지. |
| 거리표지(적백 봉) | **전량 삭제**(`markers=[]`). v5.2 §6 "기능 필수물 외 비움" + 판정 ㉣. 빌더 경로는 유지. |
| 계단 트림 톱니 | **미수정 — 판정 전제를 좌표로 반증.** 트림은 `build_slope` 회전 박스 1장이라 상면이 **연속 평면**이다. 상면 z(x)=0.02−0.4571x, 단 i 의 디딤면 z=−0.16(i+1) 이므로 트림 상면은 전 구간에서 디딤면보다 **+0.02(단 후연) ~ +0.18(단 전연)** 높다 → 트림 자체에는 톱니가 없다. `stair_down`(부감)에서 보이는 톱니 실루엣은 **계단 디딤면 자체**(위험 기하 GT, 그 컷의 존재 이유)다. 트림을 scene14 식으로 더 올리면(z0 +0.18) 둑마루 어깨에 18 cm 연석이 서서 **grazing 은닉(현재 합격 항목)** 을 해칠 위험이 있어 손대지 않았다. |
| 수면 균질 시안 / 원경 도시 슬래브 / 자갈도로 백선 | 이번 회차 범위 밖(잔여 시뮬 티) — 미조치. |

## 2. scene04_parktrail — verge "이끼 바위밭" 재작업

### ① 원인 확정

`v6_rt/rt_noon_below_lookup.png` 실사 확인: 계단 양측이 **이끼 낀 암괴 수십 개**.
원인은 판정 지적대로 **크기 × 확대 텍스처**의 곱이다.
* 크기: rowA 타원체 1.4 × 1.24 × 0.84 m (사람 무릎을 넘는 덩어리)
* 재질: `grass` diff/**nor**/rough 를 uv **1.6 m/타일** 로 물림 → 1.6 m 주기 노멀맵이
  1.4 m 덩어리 위에 얹히면 잎이 아니라 **암괴 요철**이 된다.

### ② 조치 (판정 권고 ㉠ 그대로 + 배치 불규칙화)

| 항목 | 구 | 신 |
|---|---|---|
| 재질 | grass 텍스처 uv1.6 + hedge 틴트 2종 | **상수색 `tuft` 3종**(0.070/0.105/0.042 계열, ±5 % 틴트 지터, rough 1.0·specular 0) — shrub 대비 2.2배 밝아 **잔디 층 > 관목 층** 명도 서열이 생긴다 |
| 행 구성 | 초지 1행 + 관목 2행 | **초지 3행 + 관목 2행** |
| 치수 | rx 0.70 · rz 0.42 (최고 0.74 m) | rx 0.30/0.42/0.46 · rz 0.17/0.24/0.26 (**최고 0.54 m** = 무릎 아래) |
| 간격 | step 0.85 등간격 | step 0.26/0.40/0.50 + **간격 지터 ±35 % + 결측 12 %** → 군락·빈틈 |
| 방향 | 전 개체 동일 축 | tuft 행 50 % 는 **rx/ry 교환**(add_sphere 에 회전 인자 없음) |
| 개수 | 38 | **121** |

### ③ 검산 (`verge_selfcheck`, 시드 결정적이라 실측값)

```
개체 수            121 (tuft 99 / shrub 22)
① 계단 침범 여유   min(|y|−ry) = 0.942 m > 계단 반폭 0.90   → OK
② 접지 여유        min(rz·embed − rx·구배0.261) = +0.0027   → OK (부유 0)
③ 흙띠(y=1.30) 피복 91.7 %                                  → OK
최대 높이          0.54 m (구 0.74 m)
```
* 좌표 생성을 `verge_instances()` 로 분리해 **조립기와 검산기가 같은 좌표**를 쓴다.
* rx/ry 교환을 쓰므로 침범 검산의 y 반경은 `max(rx,ry)` 로 잡았고, 접지 부등식이
  깨지는 shrub 행(ry>rx)은 **교환 대상에서 제외**했다(rowB 0.160 < 0.172 이 되어버림).
* 피복 8 % 빈틈은 의도 — 풀 뭉치 사이로 흙이 조금 보이는 것이 초지의 정상이다.
* 흙 은폐 범위는 오히려 넓어졌다: 구 rowA 는 \|y\| 1.20~2.44 라 **트림 이음선
  0.90~1.20 이 노출**됐는데, 신 rowA0 는 0.97 부터 덮는다.

### ④ 미조치 (범위 밖 — 판정 ③ 잔여)

배경 생울타리 평면 슬래브 · 파고라 지붕 · 낙엽 텍스처 대비 · `step_detail` 언더컷.
담당 지시가 verge 한정이라 손대지 않았다(각각 별도 픽스 필요).

## 3. scene18_wavy_artstair — 정체성(바다) 구조 재편 + 벽화·슬리버·치크월

### ① 판정 ㉠ 수평선 미시인 — **구조 문제로 확인 후 재편**

구 구성의 모순: 수면을 지반 밑(top −4.40)에 깔았기 때문에 **지반 절단면 1.39 m** 가
생기고, 그것을 가리려 세운 마을(x 21~42.5, 지붕 앙각 +2~+7°)이 **수평선 앙각
(−0.4~−5°)** 까지 통째로 가렸다. 저시점일수록 마을이 이긴다 → 구조적으로 달성 불가.

**→ 가릴 절단면을 없애는 방향으로 재편.**

| 요소 | 구 | 신 |
|---|---|---|
| 지반 | x −50..50, y ±50 | **x −60..34**(동단 = 해안선), y ±90 |
| 수면 | x 46..530, top **−4.40** | x **31**..530(지반 밑에 3 m 물림), top **−3.35** |
| 절단면 | 1.39 m (마을로 차폐 필요) | **0.34 m** = 낮은 호안(차폐 불요) |
| 호안 | 없음(잔디가 바다에 직접) | 산책로 밴드 x 29.5..34 신설 |
| 마을 | 14동, x 21~42.5, **y −34~38 전폭** | 13동, x 17~32.5, **\|y\| ≥ 13 남·북 군락**(계단 조망축 개방), h 12→**3.0~5.6** |
| 상가 D/E | h 12/15 · 4~5층 (암적색 아파트) | **h 5.0/6.2 · 2층** (판정 ㉤) |

### ② 검산 (`_sea_selfcheck` — 화폭 ±30° 를 5° 간격 레이캐스트)

```
컷              pitch    수면 앙각        최대차폐   화폭 개방   프레임내 수면띠
wave_raking    −11.7°  −5.19 ~ −0.40°   +4.55°      69 %       4.79°   OK
oblique_down   −14.7°  −8.20 ~ −0.63°   −0.16°      77 %       7.57°   OK
sea_beauty      −9.9°  −9.93 ~ −0.89°   −2.45°     100 %       9.04°   OK
preset_h0.3_d5 −10.0°  −4.85 ~ −0.39°   +4.40°      54 %       4.46°   OK
preset_h1.8_d10−10.0°  −6.24 ~ −0.55°   +1.59°      62 %       5.69°   OK
```
* 남은 차폐(31~46 %)는 **프레임 좌우의 마을 군락** — 의도한 구도(마을이 양옆에서
  프레임을 닫고 가운데로 바다가 열린다 = 실제 바닷가 계단마을).
* 세로 반화각 18°(vFOV 36°, 16:9 기본 초점거리) 가정. 이 가정은 검산 코드 상단에 명시.
* 상가를 낮췄지만 `lower_lookback` 상반부는 여전히 채워진다:
  상가 8.2° < 언덕 성토1 11.3° < 성토2 13.9° < 성토3 15.3° 로 층층이 올라간다.

### ③ 카메라

* `oblique_down` **재조준**: eye(−4,4.5,2.6)→tgt(3.5,0,−1.5) [부각 25.7°] 는
  수면 밴드가 프레임 중심 +20~25° 로 완전히 벗어났다 →
  eye(−4.5,5,3.0)→tgt(7.5,0,−0.4) [**부각 14.7°**]. 계단(하좌) + 수평선(상부) 동시 수용.
* `sea_beauty` **신설**: eye(−12,−9,5.5)→tgt(26,4,−1.5). 화폭 개방 100 %.
* 지시 "최소 3컷(beauty·oblique·계단 하강 축)" → `sea_beauty` / `oblique_down` /
  `wave_raking`(+ 그리드 프리셋 전부) 로 충족.

### ④ 판정 ㉡ 벽화 "레고 블록" → 사선 연속 띠

* 팔레트 5색(채널비 7~9 원색) → **7색, 채널비 ≤ 2.2 의 벽화 중간톤**
  (테라코타·머스터드·세이지·청록·청·자주회·크림). 최대 채널 0.52 → §4 순백 규약 여유.
* 색 인덱스를 단 i 가 아니라 `floor(i + (y−y0)/폭 · skew)`(skew 2.5)로 잡아
  **색 경계가 계단을 사선으로 가로지르는 연속 띠**가 된다. 색 경계와 단코 경계가
  어긋나므로 이 씬의 정체성인 **색 위장 효과는 오히려 강화**된다.
* 세그별 마모 틴트 3종(±10 %) → 같은 띠 안에서 명도가 흔들려 솔리드 판 인상과
  세로 이음선이 함께 완화. 재질 7×3 = 21종.

### ⑤ 판정 ㉢ 슬리버 파손 — 원인 2개 분리

1. **상부 보도 물결 세그**(판정이 지목한 `seg_w_min` 0.052): x_cut 을
   `−amp−0.05` → `−amp−seg_min_w(0.20)` 로. 최소폭 0.052 → **0.203 m**(권고 0.15 상회).
   동측 에지(계단 접합면)는 불변이므로 첫 단차 0.16 균일도 그대로.
