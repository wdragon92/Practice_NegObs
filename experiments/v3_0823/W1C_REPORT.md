## §1. REPAIR 1 — 렌더러 seg-stale 수리 (D79 ③ · C 전 필수)

### 1.1 무엇이 고장났나

`NEGOBS_SEG_STRICT=1` 은 **결정론적** stale(= `t0` 계단이 어노테이터를 재평가하지 않아
씬 프로세스 전 컷이 cut 0 의 마스크가 되던 결함)을 없앴다. 남은 것은 **산발적 경합**이다 —
컷 경계에서 어노테이터가 `rep.orchestrator.step()` 이후에도 직전 평가를 돌려주는 경우가

볼 수 없고, 사후 판정이라 막지도 못한다.

### 1.2 수리 — 옵트인 분기 안의 컷별 검증 + 재페치 + 마커

## §3. W1-C 렌더 · 게이트

### 3.1 VG-01-AC 계수 영역 — **as-built 판정** (보고 의무)

`AC-INSTR-1` **C3-7** 의 3층 문면은 `h12_gates.gate_vg01`((A,B) 축)의 층 이름을 그대로
빌려 왔다. 그 축에서 "발자국 안 불일치 = 실패" 가 성립하는 이유는 **A 와 B 가 발자국
안에서 같아야 하기 때문**이다. **(A,C) 축은 그렇지 않다** — C 는 발자국을 **메우는** 팔이라
발자국 안에서 A 와 다른 것이 정상이고, 문면을 글자 그대로 옮기면 게이트가 **정상 씬을
전수 실패로 읽는다**(D76 이 VG 정의 결함 4건에서 겪은 것과 같은 종류의 오독).

그러므로 (A,C) 축의 "발자국 안 불일치" 를 다음으로 **조작적 정의**했다:

```
fp_corpus = finite(A) ∧ finite(구off) ∧ (z_구off − z_A ≥ 0.30)     ← 팔·카메라 무관 (W1-D 계보)
fp_AC     = finite(A) ∧ finite(C) ∧ finite(D) ∧ (z_C − z_A ≥ 0.30)  ← C3-3 문자 그대로
mismatch  = |fp_corpus \ fp_AC|   ← 코퍼스 계기가 낙차라고 말하는데 C 가 들어올리지 못한 셀
```

| 층 | 조건 |
|---|---|
| `hm_exact` | `mismatch = 0` ∧ 대칭차 = 0 (C 가 코퍼스 발자국을 정확히 재현) |
| `hm_tol_offprint` | `mismatch = 0`, `fp_AC` 에 여분 셀 (발자국 밖 시점 의존) |
| `hm_fail` | `mismatch > 0` |

`hm_fail` 인 (밴드,씬)의 (A,C) 쌍은 **계기판① 모집단에서 제외하고 제외 쌍 수를 인쇄**한다
(C3-7 후단 그대로 — 격리 자체는 벌점이 아니고 **인쇄 누락만이 위반**이다). 부수로 **발자국
밖 A↔C 셀차**(순수 시점 의존량, C3-8 `refuse_vs_A` 의 축소판)도 인쇄해 두 독법 어느
쪽으로 읽든 숫자가 표에 있게 했다.

### 3.2 C팔 GT — 라벨러를 돌리지 않는다 (C3-2)

2×2 사양상 C·D 는 **전 칸 음성**이다. 그러므로 C 에 라벨러를 돌려 나온 `polar_gt` 를
**채택하지 않고 0 으로 고정**하며, C 의 높이맵은 (ⓐ) A 의 발자국을 만드는 z_off 참조와
(ⓑ) VG-02 검사 입력으로만 쓴다. C 의 융합 시점 의존은 **C 의 라벨을 오염시킬 수 없고**
오직 A 의 발자국 크기와 게이트 판정에만 나타난다. `w1c_verify.py` 는 이 진술을 코드로
집행한다 — C 의 GT 는 `spec_constant_all_negative` 로 인쇄되고 어떤 라벨러 출력도 그 자리에
들어가지 않는다. 계기 상속(C3-1)·독립 재융합(C3-5)은 `w1b_fuse.py` 에 `W1B_ARM=C` 로
넣었고, A/B/B2 경로의 술어는 한 글자도 바꾸지 않았다.

**C3-1 을 게이트가 강제한다 — 스모크가 그것을 요구했다.** 스모크 3씬으로 게이트 배터리를
먼저 돌렸더니 `scene02` 가 `hm_fail` 144셀로 나왔다. 원인은 팔의 결함이 아니라
**계기 불일치**였다 — A 는 `fused` 인데 융합을 아직 안 돌린 C 는 `aabb` 였다. **다른 자로 잰
두 높이맵의 셀 비교는 어떤 수치든 의미가 없다.** 그래서 `w1c_verify.py` 에 층 하나를 더
두었다: `instrument_mismatch` — 판정을 **거부**하고(그 행의 셀 수치는 판정에 쓰지 않는다),
처방(`W1B_ARM=C w1b_fuse.py --write` 를 verify **전에**)을 인쇄한다. 재현 순서(§6)가
그래서 fuse → verify 다.

## §4. REPAIR 3 — 쌍짓기 데이텀의 *계기* 수리

### 4.1 무엇이 고장났나

VG-datum 은 같은 컷 이름의 두 팔에서 `cam.ground_z` 를 비교한다. 그런데 `cam.ground_z` 는
`pre.ground_z(-d, y)`, 즉 **그 렌더의 카메라 스트립 AABB 탐침**이다. 카메라 데이텀
스트립(x<0 · |y| ≤ 0.90 · d ∈ [1.2,12]) 안에 단서/드레싱 프림이 서 있으면 그 프림의 상면이
곧 "지면"이 되고, 팔에서 그 프림을 지우면 지면이 무너지며 카메라가 같이 내려앉는다.
W1-D 실측(`W1D_REPORT.md` §3):

| 씬 | 밴드 | Δ`ground_z` | 실패 컷 | A `ground_z` | D `ground_z` |
|---|---|---:|---:|---:|---:|
| scene02 | base | **2.8236** | 9/24 | 2.8400 | 0.0164 |
| scene10 | base | **0.2500** | 3/24 | −0.0050 | −0.2550 |
| sceneN1 | base | **12.8000** | 3/24 | 12.8000 | 0.0000 |

셋 다 **카메라 한 자리**의 문제다(같은 컷 인덱스가 세 조명 조건에 공유되므로 3컷씩 걸린다).
v2 에서 (A,C) 트윈 183/792 을 날린 기전과 같다.

### 4.2 왜 씬 기하를 고치지 않는가

*"드레싱 프림을 스트립 밖으로 옮긴다"* 는 씬-기하 수리는 **A 팔과의 연속성을 깬다.**
v3 의 A 팔은 `260819_main_on` 등을 **전량 재활용**하고(계획 §1.2 "신규 컷 0"), 그
프레임들은 프림이 지금 있는 자리에 있을 때 찍혔다. 프림을 옮기면 재활용 A 팔은 더 이상
같은 씬의 산물이 아니다. 그러므로 수리는 **계기 층**에서 한다 — **재는 자를 바꾸는 것이지
재는 대상을 옮기는 것이 아니다.**

### 4.3 수리 — 팔-불변 보행면 기준 (`instrument` 옵트인 모드)

W1-D 는 이미 **단서가 하나도 없는 팔**에서 보행면을 재는 계기를 갖고 있다
(`w1d_verify.py:274-282`):

```
ring   = dilate(fp_corpus, 20셀 = 1.0 m) − fp_corpus − ¬finite(z_D)
walk_z = median(z_D[ring])            (ring < 50셀이면 grid median)
```

`z_D` 는 D 팔 높이맵이고 D 팔에는 단서가 **하나도 없다**. 그러므로 `walk_z` 는 (a) 카메라와
무관하고 (b) 어느 팔의 단서 구성과도 무관한 **씬 수준 상수**다. 물음이 바뀐다:

| | 술어 | 성질 |
|---|---|---|
| **구** (기본값) | `\|ground_z_A − ground_z_X\| ≤ tol` | 두 팔이 **서로를** 판정한다 |
| **신** (옵트인) | `\|ground_z_A − walk_z\| ≤ tol` **∧** `\|ground_z_X − walk_z\| ≤ tol` | 팔-불변 기준이 **각 팔을** 판정한다 |

신 계기의 3층: `instr_exact`(두 팔 다 보행면 위) / `instr_one_off`(**결함이 그 팔·그 카메라
자리로 국소화**) / `instr_both_off`(두 카메라가 같은 프림 위 — 쌍은 살리되 사실은 인쇄).

신 계기가 구 계기가 못 하는 두 가지:
① **결함을 팔과 카메라 자리에 국소화한다.** sceneN1 컷 0004 에서 구 계기는 "쌍이 깨졌다"만
말한다. 신 계기는 "**A 팔의 카메라가 보행면보다 12.80 m 위 프림 위에 서 있었다**"고 말한다 —
W1-D 가 **손으로** 알아낸 그 사실이다.
② **C 팔에서 쌍을 되살리되 사실을 숨기지 않는다.** C 는 드레싱을 **남기므로** 스트립 프림도
남는다. 두 팔이 같은 프림 위에 서 있으면 구 계기는 통과하지만 그 통과는 "둘 다 같은 오차를
갖는다"는 통과다. 신 계기는 그 경우를 `instr_both_off` 로 인쇄한다.

**모드는 옵트인이다.** `mode="camera"` 가 기본이고 그 경로는 `w1b_verify.datum_pose` /
`w1d_verify.datum_pose` 와 층 정의·문턱(`datum_exact` < 1e-6 · `datum_tol` ≤ 0.02 m ·
`datum_fail` > 0.02 m)이 같다. `instrument` 모드는 **cue/dressing 제거가 스트립을 건드리는
팔**에서만 켠다. 구현: `experiments/v3_0823/code/w1c_datum.py`.

### 4.4 실측이 드러낸 것 — **기준의 정의역이 하나가 아니다** (본 웨이브의 계기 소득)

링 중앙값을 (A,D) 축의 결함 3씬에 걸자 결과가 셋으로 갈렸다.

| 씬 | 링 기준 판정 | 무엇을 말했나 |

| scene02 | `instr_one_off` · 팔 **A** · devA **2.8286** / devD 0.0050 | **결함이 A 팔로 국소화**됐다 — W1-D 가 손으로 알아낸 그 사실 |
| sceneN1 | `instr_one_off` · 팔 **A** · devA **12.8000** / devD 0.0021 | 동상 · 관측 최대치 |
| scene10 | `instr_both_off` · devA = devD = **1.4665** | 두 팔이 **같은 자리**에 있다 — 즉 팔의 결함이 아니다 |

`scene10` 의 `both_off` 는 **기준의 정의역이 어긋난 것**이다. 링 중앙값은 **발자국 둘레**의

### 5.1 결함과 수리

`labeler.py:285` `_outward(XX, YY, eye)` 는 카메라 방향을 `np.rint(dx/n), np.rint(dy/n)` 로
**8방위 양자화**하고, `_near_boundary` 는 그 **한 이웃만** 탐침한다. 보행축과 **나란한**
축방향 립은 폐형 임계 `d ≤ −x₀ + √3·y_lip` 밖에서 양자화 방향이 립을 **따라가** 근접
경계 셀이 하나도 안 잡히고, `cells_kept = 0` 인 **거짓 음성 GT** 가 된다(D78 ③ · 실측
d 8.50 / 8.69 m).

수리는 **성분-경계 스캔**이다: 발자국 셀마다 8이웃을 전부 보고, 보행 가능(`¬fp ∧ ¬void`)
이면서 **카메라 향(向) 반평면**(이웃 방향과 카메라 단위벡터의 내적 > 0)인 이웃 중
**최대 내적**을 고른다(동점은 고정 `_NBR8` 순서). 결과는 셀별로 다른 `ox/oy` **필드**라
`step_gate` · `edge_points` 에 그대로 꽂힌다.

**옵트인**: `BOUNDARY_MODE` 기본 `quantised` · 플래그 `--boundary-mode` · 환경
`NEGOBS_LABELER_BOUNDARY`. 기본 인자값은 하나도 바꾸지 않았고, `synth_test.py` **175/175**
(3 gridspec)와 정본 라벨 바이트 동일 재현으로 회귀를 막았다.

**합성 시험**(`code/w1c_labeler_boundary.py --selftest`, 14/14): d = 8.50 m 에서

발자국 셀이기만 하면 어느 씬이든 그 셀은 근접 경계에서 탈락한다. v2 코퍼스에도 그런 셀이

- **9프레임은 상실만**(−9칸). 기전(scene02 실측): 경계 **집합**은 상위집합이지만 셀별

  타이브레이크는 성분 수준에서 단조가 아니다**.

**처분(지시대로)**: v2 코퍼스 라벨·매니페스트를 **다시 만들지 않았고**, 이 하위 작업을
**중단**했다. 신 모드는 옵트인으로 남고 기본값은 `quantised` 그대로다. 정본 GT 는
`quantised` 로 동결돼 있고 재라벨은 그 동결을 깨뜨린다.

**대조군이 결백을 증명한다**: `quantised` 재라벨 vs 정본 = 2,832/2,832 프레임 · 전 20필드

**미구현 대안(결재 대상)**: 양자화 이웃이 walkable 이면 **그것을 우선**하고 아닐 때만

구조적으로 불가능**해진다. 다만 경계 셀이 추가되는 것은 그대로이므로 **v2 불변은 여전히
성립하지 않는다** — 그것은 사각 수리의 정의상 불가피하다.

### 8.4 코퍼스 조립 준비 상태 (readiness statement)

**C팔은 훈련 코퍼스로 성립한다.** 근거를 순서대로 적는다.

1. **컷이 다 있다** — 816/816, 실패 0, 사이드카(깊이·세그·높이맵) 전량, `.STALE` 0.
2. **C 가 A 의 반사실이다** — 18/18 씬에서 C 프림 > D 프림. `keep_dressing` 이식이
   없었다면 결속 `HZ`·`HZ부분` 씬에서 C ≡ D(구off)가 됐을 것이고, 그 경우 (A,C) 반사실은
   통째로 무효였다.
3. **A 팔이 바뀌지 않았다** — 해시게이트 **15/15**(heightmap sha ∧ n_prims ∧ depth sha ∧
   포즈 Δ=0). 재활용 A 팔 816프레임의 계보가 온전하다.
4. **GT 가 정의돼 있다** — C 의 `polar_gt` 는 사양 상수(전 칸 음성)이고 라벨러 출력이
   그 자리에 들어가지 않는다(C3-2). C 높이맵은 A 계기 상속 · 독립 재융합(C3-1·C3-5)으로
   만들어져 z_off 참조와 게이트 입력으로만 쓰인다.
5. **쌍짓기가 산다** — VG-datum (A,C) 쌍 생존 33/34 · 컷 생존 813/816. (A,D)의
   35/38·897/912 보다 낫다. **데이텀 결함 3씬의 A↔C 무해성 주장은 scene02 에서 실증되고
   (구 계기 `datum_fail` 0), scene10 에서 반증된다** — 그 씬의 railing 이 구조 멤버이기
   때문이며 그 사실은 REPAIR-3 계기가 팔 수준으로 국소화해 인쇄한다.
6. **제외 회계가 인쇄돼 있다** — 계기판① 모집단에서 빠지는 (A,C) 쌍은 **4쌍**
   (`scene02·08·12·16` / base)이고 그 수가 표 C 에 있다. C3-7 은 격리를 벌점으로 보지
   않으며 **인쇄 누락만이 위반**이다.
7. **층화 입력이 준비됐다** — (A,C) 광학차 유닛 중앙값이 1.33…38.40 으로 **28.97배**
