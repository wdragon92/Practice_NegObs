## 용어 최소 사전 (이 문서를 읽는 데 필요한 것만)

| 용어 | 뜻 |
|---|---|
| **티어 V / E / H** | 낙차(drop-off, 떨어지는 단차)가 카메라에 얼마나 보이는가. **V** = 구멍 내부까지 보임 · **E** = 가장자리(림)만 보임 · **H** = 낙차 자체는 화면에 한 픽셀도 안 보이고 주변 맥락만 보임. **H가 이 연구의 핵심 티어**다. |
| **단서(cue)** | 낙차가 안 보여도 "여기 위험하다"를 암시하는 주변 물건 — 난간, 점자블록, 펜스 등. |
| **2×2 4팔 (A/B/C/D)** | 위험 유무 × 단서 유무의 2×2 렌더. 같은 카메라 포즈를 네 번 찍는다. **A** = 위험O·단서O · **B** = 위험O·단서X · **C** = 위험X·단서O · **D** = 위험X·단서X. 위험과 단서를 서로 떼어내는(직교화) 장치. |
| **polar grid (극좌표 격자) 20칸** | 정답지(GT) 형식. 카메라 앞을 부채꼴 5구역(A–E) × 거리띠 4개(1/2/3a/3b) = 20칸으로 쪼개고 칸마다 "위험 있음/없음"을 적는다. 정식명 PROVISIONAL-GRID-V1. |
| **GT** | ground truth, 정답지. |
| **계기판 ①②③** | 결과를 보기 전에 미리 등록해 둔 **판정 잣대 3개**. ① 트윈-조건부 recall · ② CUE-OFF 용량-반응 · ③ N-cue 함정 오경보. |
| **트윈-조건부 recall** | A팔(위험O·단서O)에서 울리고 **같은 포즈의 C팔(위험X·단서O)에서는 안 울렸을 때만** 정답으로 세는 recall. "단서가 아니라 위험 때문에 반응했나"를 재는 잣대. |
| **FA / FA_C / FA_D / FA-정합** | FA = 오경보(false alarm). **FA_C** = 단서만 있고 위험은 없는 팔에서의 오경보 · **FA_D** = 단서도 위험도 없는 팔. **FA-정합** = 모델마다 문턱 τ를 달리 잡아 오경보율을 같게 맞춘 뒤 recall을 비교하는 것. |
| **프레임축 / 칸축** | 성적을 "몇 장의 사진에서 울렸나"로 세는가, "20칸 중 몇 칸을 맞췄나"로 세는가. **두 축이 서로 다른 답을 준 자리가 여럿**이라 항상 둘 다 적는 것이 규약. |
| **CUE-OFF** | 단서만 지우고 다시 렌더해서 모델 반응이 어떻게 변하는지 보는 개입 실험. |
| **test-core / test-ext** | **test-core** = v2부터 쓰던 기존 시험 7씬(v2/v3 공통 잣대) · **test-ext** = v3 창에서 새로 지은 4팔 전용 시험 무대. |
| **사전등록(PREREG)** | 결과를 보기 **전에** 판정식·문턱·금지 목록을 고정해 해시로 얼리는 것. 정본 = `experiments/v3_0823/PREREG_V3.md`. |
| **판정 불가 / 미달 / 악화** | 사전등록의 세 술어. **판정 불가** = 방향은 맞는데 시드마다의 산포(σ)를 못 넘음 · **미달** = 개선을 증명 못 함 · **악화** = 등록한 부호의 반대로 σ를 넘어 움직임. |
| **D번호 (D1–D101)** | 결정 원장 `experiments/mainrun_0819/DECISIONS.md`의 항목 번호. 이 문서에서 "(D97)"은 그 원장 97번을 보라는 뜻. |
| **GT-58 … GT-129** | 씬 라이브러리 쪽 작업 라운드 번호(다른 원장). 캠페인의 D번호와 별개 체계다. |
| **worktree** | 같은 git 리포를 다른 폴더에 다른 브랜치로 하나 더 펼쳐 놓은 것. 여기서는 `Practice_NegObs_edge`. |
| **corpus** | 학습·시험에 쓰는 렌더 이미지 묶음 전체. |
