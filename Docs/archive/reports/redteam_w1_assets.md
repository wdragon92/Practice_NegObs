## §3 적발 — 사실 오류·과장 (본문은 옳고 요약/문장이 어긋난 것 포함)

1. **[낙엽 top_action 8] "행 삭제 시 룩v1 게이트가 깨진다" — 코드상 거짓.**
   `veg_available()`은 `VEG_TREES[:1]`의 파일 존재만 검사하므로, 벚 행을 지우면 [:1]이
   White_Pine.usd(디스크 존재, 848KB)가 되어 게이트는 **True 유지**. 본문(:399)은 "판정 기준이
   바뀐다"로 정확하게 써 놓고 요약에서 "깨진다"로 과장했다. → **A의 "행 삭제" 지시는 안전하다.**
   차기 웨이브는 이 경고 때문에 P0 삭제를 미루지 말 것(가중치 0안도 동등하게 유효).
2. **[D_urban 요약·E top_action 4] "infra_kit 33씬 import 0건" — 부정확.** `sceneN4_downhill_ramp.py:725`가
   LOOK_V1 게이트 안에서 import해 옹벽 상세를 빌드한다. D_urban 본문(:170)은 "유일한 예외 sceneN4(1건),
   담당 16씬=0건"으로 정확 — 요약과 E의 재인용이 예외를 떨어뜨렸다. 실질 논지(지면 요소 미와이어)는 유효.
3. **[B] "28씬이 grass=4.0" — 27씬.** 전수 grep 27(+scene10은 grass=2.6, 5씬 미사용). A1 수정 지시가
   "28씬의 4.0→1.4"로 나가면 scene10(2.6)이 누락된다 — 교체 시 scene10 별도 처리 필요.
4. **[C1 요약] "scene02·03·05 볼라드 근거/간격/높이" 묶음 중 scene03 높이는 오적발.** scene03은
