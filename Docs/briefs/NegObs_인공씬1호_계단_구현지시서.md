## 1. 배경 (3분 요약)

- 연구(NegObs): RGB 이미지의 **맥락 단서**로, 가려져 안 보이는 negative obstacle(낙차·구덩이류)의 **존재와 심각도**를 추정할 수 있음을 보이는 논문. AISP 2026 제출(8/30), 실험 freeze 8월 중순.
- 씬 조립 공식 [고정]:

  > **씬 = ① 길(보행로) + ② 위험(낙차) + ③ 맥락 단서(토글 가능: 난간·점자블록·재질 경계 등) + ④ 은폐 기전(grazing angle)**

- 이 씬의 역할: **인공(구조물) 계열 1호 씬.** 자연 지형 계열(침식 도랑)과 별도 트랙. 목적은 (a) 캠퍼스 보행로처럼 보이는 외형, (b) 낮은 시점에서 계단이 사라지는 현상(grazing angle 은닉) 재현, (c) 단서 토글 구조 완성 — 이 셋의 검증이다.
- 왜 계단이 1호인가: 기하가 단순(박스 반복)하고, 맥락 자산이 저렴(난간·점자블록)하며, 하행 계단은 낮은 카메라에서 모서리 직전까지 안 보이는 grazing angle의 교과서 사례이고, 배달로봇 계단 추락이라는 실제 사고 유형과 직결되기 때문.
- **중요:** 주변 환경(보도·화단·벽)은 장식이 아니라 **단서 ③(장면 수준 맥락) 그 자체**다. "여기는 캠퍼스 보행로다"라는 정보가 위험 추정의 prior가 된다. 따라서 계단만 덩그러니 만들면 이 씬은 실패다.

## 3. 참고 사진 [최우선 기준]

- 승용이 프로젝트 폴더에 넣어둘 실사진: `refs/campus_step.jpg` (파일명은 실제 폴더 기준으로 확인). **작업 시작 전에 이 이미지를 직접 열어 볼 것.**
- 사진에서 재현해야 할 포인트 (기록 기반 요약):
  1. 캠퍼스 보도(블록 포장)가 진행 방향으로 이어지다가 **하행 낙차(계단)** 를 만남
  2. 낙차 경계에서 **포장 패턴이 불연속**으로 끊김
  3. 상부와 하부 사이에 **명도 차이**가 존재
  4. 사람 눈높이에선 평범한 계단이지만, **낮은 시점에선 모서리 직전까지 하부가 보이지 않음**
- 이 문서의 묘사와 실제 사진이 다르면 **사진을 따르고**, 차이점을 완료 보고에 기록할 것.

## 4. 씬 레이아웃

좌표 규약: Z-up, 단위 m. 로봇 진행축 = +X. **계단 상단 모서리 라인 = x=0** 기준선.

| 구역 | 위치(기본값) | 내용 |
|---|---|---|
| 상부 보도 | x −12 → 0, 폭 3.0 (y −1.5~+1.5) | 보도블록 포장, 접근 경로 |
| 계단 | x 0 → +1.8 | 하행 6단 (§5) |
| 하부 광장 | x +1.8 → +10, 폭 8~10 | 다른 재질의 포장(아스팔트 톤) |
| 좌측(y−) | 보도 옆 | 화단/잔디 띠 + 경계석 (§6) |
| 우측(y+) | 보도 옆 | 건물 벽 힌트 (§6) |

전체 풋프린트 약 22 × 10 m. 치수는 전부 파라미터화(§10).

## 5. 위험 요소 — 하행 계단

| 항목 | 값 | 구분 |
|---|---|---|
| 단수 `N_STEPS` | 6 | [기본값] |
| 단높이 `RISER` | 0.16 m | [기본값] (국내 옥외 계단 관행 범위) |
| 디딤면 깊이 `TREAD` | 0.30 m | [기본값] |
| 계단 폭 | 상부 보도 폭과 동일 (3.0 m) | [기본값] |
| 총 낙차 | N_STEPS × RISER = 0.96 m | 파생값. **연구 최소 위험 깊이 0.3 m 이상일 것 [고정]** |

- 계단·상부 보도·하부 광장 모두 **static 콜라이더 부착** (이후 레이캐스트/GT 모듈 대비).

## 6. 주변 환경 (캠퍼스 드레싱) — "계단만 덩그러니" 금지

각 요소는 단순 프리미티브 + 재질로 만든다. **외부 대용량 에셋/Nucleus 다운로드에 의존하지 말 것** — 필요하다고 판단되면 먼저 보고.

1. **상부 보도 재질**: 보도블록 느낌 — 밝은 회색 + 격자 타일 패턴(절차적 UV 격자 라인 또는 타일 텍스처). 사진의 "포장 패턴"에 해당.
2. **하부 광장 재질**: 상부와 **다른** 재질(어두운 아스팔트 톤). → 패턴 불연속 + 명도차 단서가 자연스럽게 발생.
3. **좌측 화단 띠**: 잔디색 지면 띠(폭 1~1.5 m) + 보도와의 경계석(높이 0.15 m) 또는 낮은 옹벽(0.4 m) 중 택1. [기본값: 경계석]
4. **우측 건물 벽 힌트**: 높이 3 m, 보도를 따라 이어지는 단순 벽(밝은 벽 재질). 창문 표현은 [선택]. "실외 캠퍼스 통로" 인상을 만드는 핵심 요소.
5. 가로등·수목 [선택 — v1 제외 권장]: 넣는다면 프리미티브 조합으로만.

## 7. 맥락 단서 자산 + 토글 시스템 — **이 씬의 핵심 요구**

목적: 이후 실험의 **위험 판별 대응쌍**(위험 기하는 동일, 단서만 켜고 끈 렌더 쌍)을 만들 수 있도록, 단서를 처음부터 토글 가능한 구조로 만든다. 지금 단계에서는 렌더 쌍 생성까지는 하지 않고 **토글 구조만 완성**한다.

파일 상단에 다음 형태의 설정을 둘 것:

```python
SCENE_CONFIG = {
    "hazard_stairs":      True,   # [선택] False → 계단 구간을 평지로 (위험 토글의 씨앗)
    "cue_railing":        True,   # 난간
    "cue_tactile":        True,   # 점형 점자블록
    "cue_material_break": True,   # 상/하부 재질 불연속
    "cue_sign":           False,  # [선택] 주의 표지판
    "cue_scene_dressing": True,   # [선택] 화단·벽 등 드레싱 일괄 토글
}
```

단서 사양:

- `cue_railing` — 계단 양측 난간. 높이 0.9 m [기본값], 원기둥 포스트 + 상단 레일. 계단 구간 + 상단 1 m까지 연장.
- `cue_tactile` — **점형 점자블록**: 계단 상단 모서리에서 0.3 m 앞, 보도 폭 전체를 덮는 노란색 띠(깊이 0.3 m, 두께는 시각적으로만 살짝 돌출). 높이 변화 지점에 표준 설치되는 경고 표식이라 강력한 맥락 단서다.
- `cue_material_break` — 끄면 상·하부를 **동일 재질**로 통일(불연속 단서 제거).
- `cue_sign` [선택] — 판 + 기둥, 주의 표지 텍스처.

**불변 규칙 [고정]:** 어떤 `cue_*` 토글도 위험 기하(계단·보도·광장의 메쉬/트랜스폼)를 변경해서는 안 된다. 단서 자산의 존재 여부와 재질만 바뀐다. (`hazard_stairs`만 예외 — 이건 정의상 기하 토글이며, False일 때 계단 구간을 상부 보도와 같은 재질의 평지로 매끈하게 대체한다.)

## 8. 재질·조명

- 재질: PBR(albedo/roughness 파라미터화). 타일링 티가 나지 않게 스케일 조정 또는 약한 노이즈 믹스.
- 조명: 돔라이트(기본 스카이 또는 단색+강도) + 태양(DistantLight). `SUN_ELEVATION`, `SUN_AZIMUTH` 파라미터 [기본값: 오후 광. 그림자가 계단 하부에 드리워 명도차가 강조되는 방향으로 초기값 설정].

## 9. 카메라·확인 흐름

- 지상 시점 밴드 [고정]: **높이 0.3~2.0 m, 피치 −15°~+5°.** 모든 프리셋은 이 밴드 안에서.
- 기본 흐름: 씬 로드 후 **GUI를 유지**하고, 승용이 자유 비행으로 직접 확인한다. `S` 키로 현재 뷰 수동 캡처 → `look_check/`에 저장.
- 프리셋 자동 캡처 [기본값 ON, 플래그로 끔]: 보도 중심선(y=0) 위에서 높이 {0.3, 0.9, 1.8} m × 계단 상단 모서리까지 거리 {2, 5, 10} m = 9장, 피치 −10°, 계단 방향(+X)을 바라봄. 파일명에 높이·거리 포함(예: `preset_h0.3_d5.png`).
- 캡처는 Path Tracing 모드로.

## 11. 성공 기준 (검수 체크리스트)

1. **외형**: 프리셋 캡처가 참고 사진의 캠퍼스 보행로처럼 읽힌다 — 보도 패턴, 상/하부 명도차, 난간, 점자블록이 식별된다.
2. **현상 재현**: 높이 0.3 m · 거리 5~10 m 뷰에서 계단 디딤면이 시야에서 사라져 낙차를 인지하기 어렵다(grazing angle 은닉). 반대로 높이 1.8 m · 근거리에선 계단이 명확하다.
3. **토글 무결성**: `cue_*` 전부 ON인 씬과 전부 OFF인 씬에서 계단·지면 기하가 동일하다(프림 트랜스폼/메쉬 변화 없음). 단서 자산만 다르다.
4. **품질**: v9 렌더 설정 기준으로 계단 모서리 앨리어싱이 심하지 않고, GUI 조작이 원활하다.
5. **실행**: §2 시퀀스 한 번으로 씬 로드 + GUI 표시가 된다.
