## scene03_riverbank — 사행 하천 재구성

### 1. 좌표 규약 (핵심)

하천 평행 요소의 PARAMS `x` 는 이제 월드 X 가 아니라 **횡단면 좌표 s**(중심선
오프셋)다. 월드 X = s + `river_dx(y)`.

```
dx(y)  = A1·(cos(2πy/L1) − 1) + A3·(y/40)³     A1=6.0 · L1=110 · A3=−2.0
dx′(y) = −A1·k1·sin(k1 y) + 3A3 y²/40³         k1 = 2π/L1
yaw(y) = −atan(dx′(y))                          [세그 rotZ]
```

설계 구속과 근거:

- **dx(0)=0 · dx′(0)=0** — 코사인항은 y=0 에서 값·기울기가 동시에 0이고,
  삼차항은 y³ 이라 기울기가 0. 따라서 계단 회랑(y ±0.95)에서 변환이 항등이 되어
  계단·트림·스퍼·회랑의 트랜스폼이 v5 와 **비트 단위로 동일**하다. (사행을
  단일 사인으로 주면 dx′(0)≠0 이라 계단이 제방에 비스듬히 박힌다.)
- 세그 19개(`seg_dy` 5.0, y −47.5..47.5) — 요구 "10세그 이상" 충족.
- |yaw|max **23.2°**, 인접 세그 yaw 변화 ≤6.5° — 접선 불연속으로 인한 각진
  이음이 눈에 띄지 않는 상한.
- 측방 진폭 **14.8 m**. 수로폭을 22.5 → 15.8 m 로 좁혀(far_bank s 40→34,
  water s1 40→36) **진폭/수로폭 = 0.94**, 브리프 요구 "1~2배"의 하한.
  더 키우지 않은 이유: 진폭 2배(30 m)를 95 m 시야 안에 넣으려면 제방 접선각이
  45~60° 가 되어 하천이 아니라 우각호·지그재그 수로로 읽히고, 밴드 간 겹침
  lip 이 (폭합/2)·(1/cos−cos) 로 폭발한다(45°에서 대역쌍당 1.7 m).

### 2. 밴드 조립기 `river_band` / `river_segments`

각 세그 = `build_rot_group`(피벗 (세그 상면중심 x, yc), yaw) 안의 축정렬
`build_slope` 박스. **전단(shear) 배치**라 접힘·자기교차가 원리상 불가능하다
(법선 오프셋 방식은 곡률반경보다 먼 밴드에서 반드시 접힌다 — far_bank s=70,
κ=0.016 에서 s·κ>1).

- 세그 로컬 `run = 폭/cos(yaw)` → 상면의 **월드 X 투영 = 폭**.
  이 보정으로 이웃 밴드의 경계면이 항상 `(폭합/2)·(1/cos−cos)` 만큼
  **겹친다**(부호가 음수 = 개구 불가). 겹침은 높이가 같은 이웃에선 불가시,
  높이가 다른 이웃(둑마루↔사면)에선 어깨 lip 이 되므로 어깨측 서브밴드 폭을
  2.5 m 로 잘라 lip 을 yaw 10°에서 0.09 m, 회랑에서 0 으로 묶었다.
- 경사 밴드도 같은 식으로 처리: 로컬 경사각 `atan2(drop, 폭/cos)` 이므로
  **월드 X 로 run 7.0 · drop 3.2** 가 정확히 보존된다(사면-둔치 정합).
- **전 밴드 동일 y 분할**. 초안은 회랑을 y 분할 자체로 처리했는데, 분할이 다른
  밴드끼리 같은 y 에서 현(chord)의 각도가 달라져 **최대 2 cm 실틈**이 생겼다
  (검증 스크립트 실측). 지금은 분할을 공유하고 회랑은 해당 세그를 **길이방향
  으로 잘라내기만** 한다 — 회전축과 폭방향 에지선이 불변이라 정합이 유지된다.
- 잘린 끝에는 종방향 겹침(`over` 0.8)을 붙이지 않는다. 초안은 붙였다가 사면
  밴드가 회랑 안쪽 y=0.37 까지(계단 측면 0.75 침범) 밀고 들어왔다 — 검증에서
  잡아 수정. 현재 사면 밴드 코너 최소 |y| = **0.88**(트림 0.75..0.95 밑으로
  0.07 물림, 계단 침범 0).
- 코플래너 겹침의 Z파이팅은 세그·서브밴드 인덱스 홀짝 1.5 mm 스태거 +
  밴드별 `z_bias` 로 회피.

**검증**(독립 스크립트로 상면 폴리곤을 회전 재현 → y −47.5..47.5 를 0.5 m
간격 191 라인 스캔, 밴드 9종의 x 커버리지 병합):
`|y| ≤ 46 전 구간 개구 0.000 m` (계단 회랑 x 0..7 만 비어 있고 이는 계단이
채운다). 세그 총수 515(rot_group 515 + Cube 515).

### 3. 수변 부유 차단 (감사 v4 최다 결함)

- 수면 두께 0.2 → **0.4**(top −3.35), s 범위 16.5..36 으로 확장 →
  둔치(top −3.2, s 7..18)·사석(−3.2→−3.35, s 17..18.2)·건너편 둔치
  (top −3.2, s 34..) 밑으로 항상 물린다. 세 접합 모두 "위 물체가 아래 물체를
  덮는" 방향이라 어느 yaw 에서도 틈이 노출되지 않는다.
- 사석 띠 `z_bias` −3 mm — 둔치와 동일 z 시작이라 코플래너였던 것을 분리.

### 4. 그 외 (전역 규약)

- **원경 수목 라인**: 7본 등간격 10 m → 8본 불규칙 간격·x 오프셋 ±2.4,

  구현이 여기 남아 있었다. 접지 조건 `rz·embed ≥ rx·구배(0.457)`

- **틴트 지터**(규약 4): 수관 4종(기저 2색 ×±5 %)·관목 3종. 나무마다 다른

## scene04_parktrail — 길 사행 + 풀숲 사이 침목계단

### 1. 길 사행 강화

구 폴리라인은 y 가 단조 드리프트(상부 −4.6→0)라 세그 yaw 가 8~12° 로만 변하는
"완만히 휜 직선"이었다. 사인 사행(파장 21/23 m · 진폭 1.5/1.55) + 절점 지터
±0.18 로 재생성:

- 상부 7→**13절점**, 세그 yaw −18.5°~+32.4°, 인접 세그 yaw 변화 최대 21.2°
- 하부 7→**11절점**, 세그 yaw −20.6°~+24.8°, 최대 변화 27.5°
- 세그 폭 **±10 %** 지터(`width_jit`), 이음 겹침 0.5→**0.7**
  (꺾임 절점의 바깥 쐐기 깊이 = (w/2)·tan(δ/2) ≤ 0.33 m 를 겹침이 덮는다)
- 양끝 절점은 배경 울타리 개구 안(상부 y −6.5..−2.5 / 하부 −1.5..3.5)에
  유지, 계단 접속점 (0,0)·(5.55,0) 고정 → 접근/탈출로 절단 없음.

**재사행에 따른 소품 재배치**(길 반폭 0.99 안쪽에 서 있게 된 것들):
- 안내 게시판 (−6.0,−2.6) → (−8.5,−4.15) : 구 위치는 노면 한복판(중심선 0.17).
- 이정표 (−3.5, 2.2) → (−2.3,−1.95) : 구 위치는 길에서 3.5 m 떨어진 허허벌판.
- 쓰레기통 3기 → 전부 노면 가장자리 0.1~0.5 m.
- 낙엽 무더기 4 → 노면 위/가장자리(다져진 길에 쌓여야 길로 읽힌다).
- 벤치 5 → 전부 앵커(나무 그늘·관목 군락·길 가장자리) 옆, yaw 비정수각.
  좌판 끝과 줄기/관목의 최소 이격 0.62 m(관통 0), 길 중심선 최소 1.18 m.

### 2. 풀숲 사이 침목계단

노출 흙사면(구 dirt 밴드 |y| 1.15~3.0)을 **1.7 로 축소**(0.55 m 어깨만 잔존)
하고 그 위를 3열 타원체 군락으로 덮는다:

| 행 | cy | rx·ry·rz | 간격 | 재질 |
|---|---|---|---|---|
| A 초지 융기 밴드 | ±1.82 | 0.70·0.62·0.42 | 0.85 | grass 텍스처 + hedge 틴트 2종 |
| B 관목 | ±2.62 | 0.62·0.70·0.34 | 1.15 | shrub 상수색 3종 |
| C 관목(성긴) | ±3.70 | 0.55·0.62·0.30 | 1.90 | shrub 3종 |

총 38개, 위치 ±0.22 · 크기 ±18 % 좌표 시드 지터(결정적).

- **계단 침범 0** — 최악 내측단 = 1.82 − 0.154 − 0.732 = **0.934 > 0.90**
  (계단 반폭). 실측 최소 1.043.
- **부유 0** — 접지 조건 `rz·embed ≥ rx·구배(0.261)` 를 세 행 모두 만족
  (A 0.210≥0.183, B 0.170≥0.162, C 0.150≥0.144). 실측 하류측 최대
  −0.006 m(항상 매입).
- 형상을 타원체로 고른 이유: v5 판정이 같은 씬에서 "경사 슬래브 3장 중첩 =
  각진 판떼기"를 폐기시켰다. 구배는 형상이 아니라 **배치 높이**(`slope_z`)
  로만 반영한다.
- 부수 효과로 v4-D8 `slope_understory`(build_slope 경사 판 4장)를 폐기 —
  같은 결함 계열이고 B/C 행이 같은 영역을 대체한다.

### 3. 전역 규약

수관 4종·관목 3종·초지 2종 ±5 % 틴트 지터(기저색 불변, 변종 수만 증가).
