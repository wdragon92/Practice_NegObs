   높이 0.8~1.0m·지름 0.1~0.2m·간격 1.5m 내외·밝은 반사띠(상단 백색 밴드 재질)·

   yaw ±3~8° 지터. 사인은 실제 부착 방식(기둥 지주 h2.2 or 벽부착)만.
4. **재질**: 인스턴스별 틴트 지터 ±5%, 기단 오염 밴드(h0.3 암화) 선택, 순백(>0.8)
   대면적 금지.

   진폭 = 폭의 1~2배) + 둔덕/성토 라운딩.
