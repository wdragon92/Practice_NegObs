# F3 — Adapter-free YOLO detection metric (RED-TEAM RESPONSE, D35 / R1-F3)

Generated by `rt_response/code/f3_adapter_free_yolo.py` · CPU · read-only.

**Why.** The published YOLO row reads E/H recall = 0.000, and the draft called that a property of *the detection paradigm*.  R1-F3 showed the 0 is produced by our bottom-edge ground-projection adapter: feeding the amodal GT boxes themselves in as conf-1.0 detections also yields E = H = 0.000 (`METRICS_NOTES_yolo.md` §3).  This file removes the adapter entirely and asks the detector question directly in image space.

**Metric.** A hazard-ON frame is an *image-space hit* iff some stored detection (conf ≥ τ_conf) has IoU > t with some amodal GT box of that frame.  Frames with no stored detection file count as zero boxes.  Detector: yolov8n, seeds 42/43/44, the same frozen `pred_test` dumps that fed the published row.
