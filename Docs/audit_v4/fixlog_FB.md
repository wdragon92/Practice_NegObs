### ① [주의] 볼라드 y=0 3본이 화면 정중앙 관통

**결함**: 볼라드 배치가 (−1.2, y −3/0/3) · (6.4, y −3/0/3) 인데 `color_front` ·
`lower_lookback` · `wave_raking` · 프리셋 3×3 카메라가 **전부 y=0 축** →
어두운 원통 1본이 항상 화면 중앙을 세로로 지난다.

**조치**: y=0 본을 **y = ±1.5 로 분할**(열당 4본, 총 6 → 8). 좌우 대칭과
"볼라드 열" 판독을 유지하면서 시선축(y=0)을 완전히 비운다.

### ② [주의] 계단 측단(|y| = 4) 무마감

**결함**: 물결 세그먼트 24개의 끝면이 |y|=4.0 에서 그대로 노출돼 스커트(−2.57)
위 2.57 m 측면이 격자·공동처럼 읽혔고(`oblique_down` 우측), 동시에 계단 →
스커트 2.57 m 측면 낙차가 무방호였다.

**조치**: 단마다 그 단의 전·후연 x 를 그대로 쓰는 **계단식 치크월**
`Cheek_{S|N}_{i}` 를 |y| 4.0..4.3 에 32매(16단 × 2측) 신설. 상면 = 그 단 디딤면
**+0.14**, 저면 −2.72(스커트 상면 −2.57 아래 0.15 매입). 재질 `M["upper"]`.

**검산**
- y = ±4 에서 물결 위상은 `sin(k·(±4) + i·φ) = sin(±2π + i·φ) = sin(i·φ)` 로 **양측이 동일** → 한 쌍의 x 구간으로 좌우를 같이 만들 수 있다(수치 확인 완료, 오차 < 1e−9).
- x 구간은 `_front_x(i−1, 4)` ~ `_front_x(i, 4)` 로 세그먼트 끝면과 **정확히 일치** → 틈·중첩 0. 전체 x −0.136 ~ 5.342.
- x < 0.5 구간(1~2단분)은 상부 보도 `Walk_upper_S/N`(|y| 4..9, 상면 0, 솔리드) 안에 묻히므로 시각 영향 없음. 파라펫(x 0.2..0.5, z 0..1.05)과는 z 가 겹치지 않는다(치크 최상단 −0.02).
- **위험 기하 불변**: 계단 폭(|y| ≤ 4) 밖에만 덧대는 마감. 높이가 인접 디딤면 +0.14 이므로 h0.3/h0.9 grazing 에서 낙차 실루엣을 만들지 않아 은닉 특색 유지.

**남긴 것(범위 밖)**: `wave_raking` eye z, `oblique_down` 좌측 파라펫, A2 디딤폭 요동(감독 결정 대기).

## scene21_monumental_selfocclude — 파라펫 Z파이팅 · d10 크러시

### ① [중대] 파라펫–계단 측면 Z파이팅

**결함**: 파라펫 y 대역 ±3.5..4.0 의 **외면이 계단 외측면(y = ±4.0)과 정확히 동일
평면** → `oblique` 200 % 크롭에서 백색/석재가 단 피치로 교대하는 빗살 무늬.

**조치**: `parapet.out_off = 0.02` 신설. `build_parapets` 에서 **외면만**
N: y1 = 4.02, S: y0 = −4.02 로 2 cm 돌출. 내측 경계(±3.5) · 상면(+0.85) ·
두께(1.6) 불변 → B2 접지·유효 계단폭 검산 그대로 성립. 기하 리포트 출력도
실제 대역을 찍도록 갱신.

**돌출(3.98 후퇴가 아니라 4.02)을 택한 이유**: 후퇴시키면 계단 외측 2 cm 띠가
파라펫 옆에 계단식 슬리버로 남아 같은 크롭에서 또 다른 미세 무늬가 된다.
돌출은 계단 측면을 완전히 덮는다.

### ② [중대] d10 프리셋 열 전체가 흑색 크러시

**진단(판정과 다름 — 원인 재특정)**: 판정은 열주(col_x −10)를 지목했지만 실제
지배 요인은 그 뒤의 **전폭(y −9..9) · 높이 8.5 m 파사드 벽**이다.

정오 태양(elev 49.79°)에서 그림자 길이는 `h/tan(49.79°) = 0.845h`, 수평 방위는
`atan2(cosφ, −sinφ)`, `φ = SUN_AZ_OFFSET + 123.5` (= `noon_dome_rot −110`
`+ hdri_sun_rotz_offset 233.5`). 구값 `SAO 171.5 → φ 295° → 그림자 방위 25°`
(거의 +X)라 x 성분이 `0.766h`:

| 그림자원 | 구 위치 | 도달 x (구) |
|---|---|---|
| 파사드 벽 앞면 (z 8.5) | x −10.9 | **−4.39** |
| 열주 (z 7.0) | x −10.0 | −4.64 |

→ 테라스 x −10.9..−4.4 가 통째로 그림자. d10 eye(x −10) 은 전경 전체,
d5 eye(x −5) 는 하단이 그 안에 들어간다(판정 관측과 일치).

**프리셋 원점 이동은 불가**: 그리드는 `eye_x = −d` 로 낙차 모서리(x=0)까지의
거리를 정의한다. 판정 제안대로 +4 시프트하면 d2 eye 가 x = +2 —
**계단 솔리드 내부**(그 x 의 디딤면 −0.9)로 들어간다. 그래서 그림자원 자체를
물리고 태양 방위를 트는 쪽(판정의 두 번째 선택지)을 택했다.

**조치 3건**
- `facade.col_x` −10.0 → **−13.2** / `facade.wall_x` −11.2 → **−14.4** (서측 3.2 m 이설)
- `terrace.x0` −12.0 → **−15.2** (기단 확장 — 상면 z=0 · x1=0 불변)
- `SUN_AZ_OFFSET` 171.5 → **206.5** (φ 330° → 그림자 방위 **60°**, x 성분 `0.766h → 0.423h`)

**검산**

| 그림자원 | 신 위치 | 도달 x (신) |
|---|---|---|
| 파사드 벽 앞면 (z 8.5) | x −14.1 | **−10.51** |
| 열주 (z 7.0) | x −13.2 | −10.24 |
| 인방 (z 7.8) | x −12.7 | −9.40 |

d10 프리셋 프레임 하단(pitch −10°, vfov ≈ 35° → 부각 27.5°)의 지면 x:
h0.3 **−9.42** / h0.9 **−8.27** / h1.8 **−6.54**. 벽·열주 그림자는 전부 그
**뒤**에 끝나므로 전경 크러시 소멸. d5(h0.3 기준 하단 x −4.42)도 완전 이탈 →
판정의 "h0.3_d5 하단 40 %" 도 함께 해소.

**부작용 관리**
- 돔과 DistantLight 가 같은 `rot` 로 함께 도므로 HDRI 태양 정합 유지.
- −X 향 원경 건물(B·D)의 직사 cos 성분이 0.585 → 0.323 으로 낮아지지만 실루엣·접지 판독에는 영향 없음. −Y 향 건물 C 와 남측 파라펫은 밝아진다.
- 파사드 +X 면은 구·신 모두 역광(−0.585 → −0.112)이라 변화 없음 → `facade_front` 의 판독(열주 실루엣 + 대계단)은 보존.
- 확장된 테라스(깊이 15.2 m)에서 기존 소품(`bollards_terrace` x −1/−6, y ±6/±8.2)은 전부 범위 안, 지반(cx 14, size_x 110 → x −41..69)도 여유.

**남긴 것(범위 밖)**: 단코 띠 과채도, 파라펫 알베도 0.90, `oblique`/`railing_line` 깃대 관통 — 이번 지시 항목 외.
