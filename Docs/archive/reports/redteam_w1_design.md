## 2. 반증 — 설계 내부 모순 (공격 지점 1)

### 2.1 ★[ground_kit·중대] C-1 교정 좌표가 자기 게이트 B7(GT-E2)과 d10에서 상충한다

GT-E2: "E 대역 내 신규 전폭 횡단선의 투영 행은 에지 투영 행에서 ≥12행 이격"(B7, 위반 0).
d10 프리셋에서 재계산 `[계산 — f=1662.769·h=0.3·pitch −10°]`:

```
에지(x=0, X=10):        row = 540 − 1662.77·tan(10°−atan(0.03))  = 297.97
트렌치(x=−0.95, X=9.05): row = 303.28   →  Δ = 5.31행  <  12행   → B7 위반
12행 경계를 만족하는 위치: x ≤ −1.91 m  (d10에서 x∈[−1.91, 0] 전체가 12행 이내)
```

즉 **§5.1·§5.2가 배치한 계단 상단 트렌치 3건(01·02·14, 전부 x=−0.95)은 스펙 자신의 frame_budget dry-run에서 전부 FAIL**한다. d5에서는 Δ23.6행으로 통과 — d10만의 문제다. E 대역 소속도 확인: d10 E대역 x∈[−3,+12] ∋ −0.95 `[실측 — GRAZE_KN/KF]`.

- 게이트가 있으니 구현 중 발각은 되지만, "W1 좌표 3건을 교정했다"(§0-5)는 문서의 자기 완결 주장은 깨진다. 넷째 교정이 필요하다.
- **선택지**: ⓐ 트렌치를 x≈−2.1로 이설(d5·d10 창 전용이 됨 — d2 창은 X<0.56이라 어차피 프레임 밖) ⓑ 삭제하고 이산 요소(맨홀)로 대체 ⓒ B7에 "에지보다 근경 쪽(화면 아래) 방향 완화" 예외 신설 — ⓒ는 "에지 흉내" 방지라는 B7 취지를 정면으로 훼손하므로 **비권장**. 권고 ⓐ.

### 2.2 ★[ground_kit·중대] §7.2 S1(전 요소 차폐 전수, 위반 0)과 §5의 잡초·자갈 처방은 동시에 성립 불가

S1 판정식 `z_e > h·(−x_e)/d`를 스펙 예외 3종에 적용하면 `[계산]`:

| 요소 | 높이 | 안전 이격(−x ≥ z_e·d/h) d2 / d5 / d10 |
|---|---|---|
| 잡초 | 0.12 | 0.80 / 2.00 / **4.00 m** |
| 산포 자갈 | 0.06 | 0.40 / 1.00 / **2.00 m** |
| GT_DELTA 요소 | 0.020 | 0.13 / 0.33 / 0.67 m (→ EDGE_STANDOFF 0.80 유도의 전제) |

- §5.4 15-8은 잡초를 줄눈선(x=−3)에 두는데 d10에서 0.12 > 0.09 → **S1 위반**. §5.7 04·07의 산포(노출 0.06)도 x∈[−2,−0.8] 대역에서 d10 위반.
- S1을 문자대로 걸면 스펙 자신의 식생·산포 처방 다수가 킬. 예외로 풀면 d10 에지선의 국소 은닉이 **무게이트**로 남는다(S2의 "에지 행 ±20행 대역 점유 ≤3 %"만 잔존 — 잡초 6~10포기가 정확히 이 대역에 걸린다: x=−3 잡초는 행 290.7~319.7로 에지 행 298을 관통 `[계산]`).
- **근본 원인**: EDGE_STANDOFF=0.80은 z=0.020 전제에서 유도됐는데(§6.2) 예외 3종이 그 전제를 3~6배 초과한다. 유도와 예외가 비정합.
- **권고**: S1 적용 대상을 "비식생·비산포 강체"로 한정 명문화 + 식생·산포는 S2 3 % 상한으로 일원화 + 잡초 높이를 x 조건부로 클램프(`h_weed(x) ≤ 0.75·h·(−x)/d_max`, 즉 x=−1 m에서 h≤0.0225, x=−4 m부터 0.12 허용). 이러면 처방과 게이트가 화해하고 은닉도 정량 상한 안에 갇힌다.

### 2.3 [ground_kit·소] GT-E2 "12행"의 산술 근거 오류

괄호 근거 "(GRAZE_HW 3 + SMOOTH 3 + SLACK 2)의 2배"는 **16**이지 12가 아니다 `[계산]`. 필터 footprint 논리대로면 16행으로 상향해야 하고(§2.1의 위반은 더 커진다), 12를 유지하려면 근거를 (HW+SMOOTH)×2로 고쳐야 한다. B7은 하드 게이트이므로 값-근거 불일치를 방치하면 안 된다.

### 2.4 [ground_kit·소] 시그니처·참조·스테일 수치 4건

1. §4.2 `build_ramp_curb` 호출 규약의 **`offset` 인자는 실존하지 않는다** — 실제 시그니처는 `(kit, prefix, profile, y_neg, y_pos, mtl, height=0.12, width=0.30, sides, embed, margin, ...)` `[실측 — infra_kit.py:778-781]`. 문자대로 구현하면 TypeError.
2. §5.1 sceneN1 행의 "**§7.3**" 참조는 댕글링 — §7은 7.1·7.2뿐 `[실측 — grep]`. N1 "밴드 불변식"의 실체(전폭 횡단 그림자 밴드와 맨홀의 간섭 판정)를 frame_budget 어느 게이트가 담당하는지 명시가 사라져 있다.
3. §5.4 15-2 "d2 창, 폭 269 px"는 **d5 폭**(x=−1.15, X=3.85에서 280 px)의 스테일 병기다. d2(X=0.85)에서는 1,268 px = 프레임 폭 66 % `[계산]` — 의도된 그림인지 자체를 결재받아야 한다(근경 프레임 하단을 맨홀이 지배).
4. scene02 지하 좌표(트렌치 6.55~6.85·측구 x 7~11)는 **코드 PARAMS와 일치**함을 확인했다(landing 6.4~7.0·tunnel x0 7.0, depth 4.0 `[실측 — scene02:126·:131]`). 단 scene02 **docstring 검증표는 "하류 이동 +1.20(랜딩 7.6·터널 8.2)"라고 적어 코드와 상호 모순** `[실측 — scene02:43·:59-62]` — 스펙 책임은 아니나 W2가 이 씬을 만질 때 어느 쪽이 진실인지 렌더로 재확인해야 한다(문서 좌표 하드코드 금지, §8-4 권고 참조).

### 4.2 단서-라벨 결정론화 — "깨끗한 띠" 규칙성

GT-E1은 에지 전방 0.80 m에서 **proud>0 전면 금지**다. 그런데 유도(§6.2)가 실제로 요구하는 것은 z_e 조건부 하한뿐이다: 오염 데칼(+0.6 mm)의 차폐 필요 이격은 d10에서 **0.02 m** `[계산 — 0.0006·10/0.3]`. 즉 0.80 m 전면 금지는 데칼류에 대해 40배 과잉이고, 그 대가로 **전 33씬의 낙차 에지 앞에만 "양각·데칼 없는 띠"가 일정 폭으로 생기는 라벨 상관 규칙성**을 만든다(음각·flush는 허용되므로 완전 공백은 아니나, 실세계에서 흔한 "계단 상단 물때·드립 라인"이 계통적으로 소거된다). 여기에 01·02·14의 계단 상단 트렌치가 전부 동일 오프셋(−0.95)이면 "트렌치 → 0.95 m 뒤 에지" 템플릿이 겹친다.

**권고**: ⓐ GT-E1을 z_e 함수로 완화 — `x_e ≤ −max(0.10, 1.2·z_e·d_max/h)` (데칼은 에지 10 cm 앞까지 허용, 잡초는 자동으로 4.8 m 밀림 → §2.2 클램프와 동일 효과) ⓑ 트렌치 오프셋을 씬별 결정적 지터(0.95~1.4 m, §2.1 이설과 병합 시 1.95~2.4 m) ⓒ 스펙 §11이 이미 인정한 대로 **에지 신호의 최종 심판은 hazard-off 쌍둥이** — §6 참조.

### 4.3 정상 확인

- GT 불변 원장(§1.3·§6.1)은 자체 정합 — 음각 상한·예외 3종 선언·데크 틈 −20 mm=GT_DELTA 경계 선언 일치. `apply_ground`의 생성 전 예외 규약도 옳다.

- P-A 자체는 결정 타당: 스킨 매몰의 3중 확증(감사 레드팀)과 본 검증의 +16.5 mm 재계산이 정합하고, 음각 구현 가능한 유일안이라는 논증에 반례를 찾지 못했다. P-B 폴백 시 폐기 목록을 정직하게 명시한 점도 인정.
