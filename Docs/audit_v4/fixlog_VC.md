### 점형블록의 토글 귀속 (판단 근거)
§2 의 볼라드 전면 점형블록은 **황색 경고 포장 = 단서 계열**이다. 이를 드레싱으로
상시 생성하면 `cue_tactile=False` 컷에도 점자블록이 남아 **토글 무결성이 깨진다**.
→ 16/20/21 의 볼라드 점형블록은 전부 `cfg["cue_tactile"]` 게이트 안에 넣었다
(기본 True 이므로 정상 렌더에서는 §2 완전 준수, 어블레이션 컷에서만 생략).
**scene14 는 점형블록 자체를 두지 않았다** — 볼라드 열이 계단 발치(x 21.6)라
토글 밖 황색 띠가 "참만 보여 평탄해 보인다"는 본 씬의 은닉 착시에 상시 단서를
섞기 때문(이유를 코드 주석에도 기재).
