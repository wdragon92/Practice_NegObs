## 2. 고칠 수 있는 것 vs 물리적으로 옳은 것

이 절이 이 보고서의 핵심이다.

### (A) 고쳐야 하고 고칠 수 있는 것 — 25.24 + 1.35 + 0.54 = **27.13**

| 항목 | 점유율 | 왜 "고칠 수 있음"인가 |
|---|---|---|
| 아스팔트 차도 | 25.24 | 실제 아스팔트는 **골재 입도 3~13 mm 의 고대비 미세 텍스처**다. 완전 평면인 것이 물리적으로 **틀렸다**. 같은 씬의 잔디·벽돌이 dead 0 % 인 것이 조달만 하면 된다는 증거 |
| 그늘진 측구 내벽 | 1.35 | 텍스처는 이미 붙어 있고 양지에서는 살아 있다. 음영에서만 죽는다 = **대비/노출 문제**이지 재질 문제가 아니다. 실사는 최암부에서도 국소std 0.046 (임계의 12배) |
| 내벽 잔여 | 0.54 | 위와 동일 프림 |

### (B) 물리적으로 옳은 것 — 손대면 안 됨 = **0.88 (하한)**

| 항목 | 점유율 | 왜 건드리면 안 되는가 |
|---|---|---|
| 차선 도색 (실선·파선) | 0.72 | `scene_common._CONST_MDL_CLASSES` 가 `paint` 를 **의도적으로 제외**했다(v5.1 §4). 노면표시는 균일해야 시각 단서로 기능한다. 여기에 절차 노이즈를 얹는 것은 규약 위반 |
| 박스 컬버트 내부 암색 | 0.16 | L 0.016 의 **깊은 공동 내부**. 빛이 거의 안 들어가는 영역이 평탄한 것은 물리적으로 옳다. 텍스처를 얹어도 이 밝기에서는 보이지 않으며, 밝게 만들면 "낙차 공동이 어둡다"는 GT 단서를 훼손한다 |

즉 **불가피 하한은 약 0.9**. 목표 3.0 대비 **2.1 의 여유**가 있다.

> 유보: 실사에서는 차선 도색조차 타이어 자국·마모·먼지로 국소std 가 임계를 넘는다.
> 다만 그것은 "노이즈를 넣어라"가 아니라 "마모 텍스처를 넣어라"이며, 0.72 는 예산
> 안이므로 **이번 라운드에서는 손대지 않는 것이 옳다**. [추정]

### (C) 하늘은 범인이 아니다

하단 2/3 안에서 하늘/대기로 분류된 죽은 픽셀은 **0.010 %프레임**(죽은 픽셀의 0.04 %).
P1 에서 확인된 "죽은 픽셀의 67~74 % 가 하늘" 은 **전체 프레임 `flat_pct`** 이야기이고,
`flat_gnd` 에는 해당되지 않는다. sceneD3 의 지평선은 14컷 모두 y=h/3 선 위에 있다.

## 3. 룩 레이어가 왜 노면에 안 걸렸는가

### 판정: **분류는 정확하다. 처방이 대역을 못 맞춘다.**

`_look_spec("/World/Scene30/Looks/Asphalt")` 를 추적하면

```
LOOK_ROLE["Asphalt"] = "asphalt"
LOOK_CLASS["asphalt"] = dict(bevel=0.006, sat=0.90, mdl="ground", patch=1.0, detail=True)
"asphalt" ∈ _CONST_MDL_CLASSES        → 상수색 MDL 경로 진입 ✓
```

**분류 오류는 없다.** 상수색 MDL 도 정상적으로 걸렸다(측정 증거: off→on 에서 노면
평균 L 이 0.6826 → 0.6740 으로 약 2/255 이동 = `base_color` 경로가 실제로 동작).
그런데 dead 는 77.6 % → 77.6 % 로 **단 한 픽셀도 안 바뀌었다.**

### 원인 — `_make_ground_pbr(diff=None)` 이 만드는 변조는 전부 미터급 저주파다

`scene_common.py:_make_ground_pbr` 의 상수색 모드 파라미터를
`assets/NegObsGround.mdl:negobs_layer` 와 대조하면:

| 입력 | 값(상수색 모드) | 실제 기여 |
|---|---|---|
| `diffuse_texture_a` | **미바인딩** | `s1.alb` = 흰색 상수. **albedo 고주파 성분이 0** |
| `normalmap_texture_a` | **미바인딩** | `L.nrm` = 평면 법선. **셰이딩 변동 0** |
| `patch_mix_a` | 1.0 | `lerp(s1.alb, s2.alb, patch_m)` — s1 ≡ s2(둘 다 흰색) → **기여 0** |
| `macro_amp_a` | 0.07 | 유일한 albedo 변조. 그런데 **`macro_wavelength_a = 14.0 m`** |
| `rough_noise_a` | 0.22 @ **1.2 m** | roughness 변조. 확산 지배 표면에서 외형 기여 미미 |
| `desat_bright_a` | 0.0 | 무영향 |
| `tri_dither` | **0.0** (상수색 모드에서 의도적으로 끔) | 무영향 |
| 디테일 노멀 | **적용 안 됨** — `scene_common.py:824` 의 디테일 노멀은 **OmniPBR 분기 안에 있고 `diff is not None` 조건까지 걸려 있다**. ground MDL 로 간 재질은 `detail=True` 여도 절대 못 받는다 | 무영향 |

즉 상수색 MDL 이 노면에 실은 것은 **파장 14 m 의 명도 변조와 파장 1.2 m 의 거칠기
변조뿐**이다. 반면 `flat_gnd` 는 **1024 폭 화면의 5×5 픽셀 창** 안의 표준편차를 본다.
근거리에서 5 px ≈ 수 cm, 원거리에서 수십 cm. **14 m 주기 신호가 5 px 창에 남기는
변동량은 정의상 0 에 수렴한다.** 실측이 정확히 그 값이다 — 국소std 1×10⁻⁶.

> **한 줄 요약**: 상수색 MDL 은 "얼룩"을 만들고, `flat_gnd` 는 "결"을 본다.
> 대역이 다르다. 얼룩을 아무리 세게 줘도 결이 되지는 않는다.
> (게다가 코드 주석대로 macro 를 세게 주면 "얼룩으로 보인다"는 부작용이 있어
>  amp 상향은 막다른 길이다.)

## 4. 실사는 왜 0.1 % 인가

| 항목 | `1784886529634.jpg` | `everytime-...380.jpg` |
|---|---|---|
| 하단 2/3 국소std **중앙값** | 0.0425 | 0.0508 |
| 1 퍼센타일 | 0.0088 | 0.0068 |
| 5 퍼센타일 | 0.0133 | 0.0111 |
| **최암부 10 % 에서의 중앙값** | 0.0457 | 0.0588 |
| 32×32 블록 평균의 **최솟값** | 0.0194 (임계의 **4.9배**) | 0.0148 (임계의 **3.8배**) |
| flat_gnd | 0.027 % | 0.133 % |

두 장 다 **대형 화강석/콘크리트 포장 광장** — 렌더가 만들려는 "넓고 균일한 평면"의
가장 불리한 실사 대응물이다. 그런데도:

1. **분포 자체가 임계 위에 통째로 떠 있다.** 가장 평탄한 32×32 블록조차 임계의
   3.8~4.9 배. 실사에서 `flat_gnd` 가 0.1 % 인 건 "간신히 통과"가 아니라
   **애초에 임계 근처에 분포가 없다**는 뜻이다.
2. **최암부에서 오히려 값이 크다**(0.046~0.059 > 중앙값). 밝기와 무관하게 대비가
   유지된다 = 이건 텍스처가 아니라 **밝기 독립 성분**(센서 노이즈 · JPEG 블록
   경계 · 색수차 · 렌즈 회절)이다. 렌더에는 이 성분이 **전혀 없다**.
3. 5712×4284 원본을 1024 로 **5.6배 다운샘플**(면적 31배 평균)했는데도 남았다.
   즉 원본의 노이즈·미세대비는 여기서 관측되는 것보다 훨씬 크다.

기여 성분 분해 [추정]: 미세 텍스처(골재 반점·줄눈·오염·습기 얼룩)가 지배적이고,
센서 노이즈·JPEG 는 최암부에서만 바닥을 떠받친다. 어느 쪽이든 **도달 가능한 한계는
0.1 % 이며, 우리가 그 근처에 가야 할 이유는 없다 — 목표는 3.0 이다.**

| **3.1/255** | **7.14** |
| 5.1/255 | 0.03 |

임계 근방에서 반응이 **절벽처럼 가파르다**(2.0→3.1 구간에서 25.8 → 7.1). 이건
`flat_gnd` 가 "분포가 임계에 딱 붙어 있는 렌더"에 대해 **매우 불안정한 지표**임을
뜻한다. 동시에 **센서 노이즈 후처리로 지표를 통과시키는 것은 자명하게 가능하고,
자명하게 부정행위**다 — 노면은 여전히 시각적으로 평면이다. 이 표는 "지표 통과"와
"사실성"이 갈라지는 지점을 기록해 두기 위한 것이다.

### P1 — 노면 광택 억제 · 면적 25.24 와 동일 영역 · 실현가능성 높음 · [추정]

노면이 **아스팔트치고 너무 밝다**: L=0.66. 같은 프레임의 차선 도색(알베도 0.72)이
L=0.921 인데, 알베도 0.16 인 노면이 L=0.66 이다. 선형값으로 환산하면
알베도→복사휘도 비가 도색 1.15 배 vs **노면 2.46 배** — 확산만으로는 설명되지 않는다.
`roughness_const=0.85` 의 **넓은 GGX 로브가 하늘 돔을 통째로 긁어모으는** 그레이징
광택으로 보인다(카메라 높이 0.3→1.8 m 로 갈수록 노면 평균 L 이 0.629→0.662 로
단조 증가하는 것과 정합). 매끈한 하늘의 반사는 **완벽하게 매끄러운 장**이라
디퓨즈 텍스처를 얹어도 상당 부분을 씻어낼 수 있다.

- `M["asphalt"]` 에 `specular_level=0.15~0.25` 명시 (현재 미지정 = OmniPBR 기본값)
- P0 의 `rough` 맵이 붙으면 `rough_mult_a` 경로가 살아나 광택 자체가 공간 변조된다
- **단, `roughness_const` 를 계속 넘기면 `rough_mult_a=0` 으로 강제되어 rough 맵이
  통째로 무시된다**(`scene_common.py:_make_ground_pbr` 의 `roughness_const` 분기).
  P0 적용 시 `asphalt_rough` 인자를 **빼거나**, 넘기려면 이 분기를
  "floor 이식" 대신 "floor 하한 + 맵 유지"로 바꿔야 한다. → **P0 와 세트로 처리할 것**

### P2 — ground MDL 상수색 경로에 디테일 노멀 부여 · 면적 = 전 씬의 상수색 지면 · 실현가능성 중

`scene_common.py:824` 의 디테일 노멀은 `diff is not None` 조건 + OmniPBR 분기 안에
갇혀 있다. `LOOK_CLASS` 가 `paving/concrete/brick/stone/soil/gravel/asphalt/nosing/curb`

  (MDL 에 입력을 신설해야 함 — MDL 개정 필요, 그래서 중간 난이도)
- 파장 8 cm 는 5 px 창 대역에 정확히 들어온다. **이것만 있었으면 상수색 MDL 이
  `flat_gnd` 를 실제로 움직였을 것이다.** 텍스처 조달이 불가능한 재질(사인 뒷면,

### P3 — 그늘진 측구 내벽 대비 회복 · 면적 1.89 · 실현가능성 중

## 6. 방법 (재현용)

```python
rgb = imgstats.load(path)              # 긴 변 1024 LANCZOS, RGBA→RGB
g   = imgstats.lum(rgb)
ls  = imgstats.local_std(g, 5)
dead = ls < 1/255
dead[:g.shape[0]//3] = False           # 하단 2/3 만
```

- 연결성분: 4-이웃 런렝스 union-find (numpy only)
- 재질 귀속: 정규화 RGB(색도) + 밝기 임계. 렌더는 램버트 지배라 **색도가 albedo
  상수색의 sRGB 인코딩을 그대로 보존**한다는 성질을 이용
  - `asphalt` : |cr−0.3305|<0.006 ∧ |cg−0.3300|<0.006 ∧ cb>0.334 ∧ 0.35<L<0.80
  - `paint`   : L>0.82 ∧ |cr−0.334|<0.010 ∧ cb<0.336
  - `dark`    : L<0.06
  - `veg`     : cg>0.36 ∧ cg>cr+0.02
  - `sky_atm` : cb>0.355 ∧ L>0.35
  - `warm_dark`: cr>0.345 ∧ L<0.35
- 시각 검증: `look_check/diag_d3/cls_*.png` (분류 결과를 원본 위에 색칠) 로
  전 14컷 육안 대조 완료. 적=노면 / 자홍=그늘 내벽 / 노랑=차선 / 시안=컬버트 /
  주황=내벽 잔여

산출물:
- `on_*.png` / `off_*.png` (14+14): 원본 위 죽은 픽셀 오버레이.
  하단 2/3 = 빨강(측정 대상), 상단 1/3 = 파랑(측정 제외·참고), 노란 선 = y=h/3 경계
- `cls_*.png` (14): 재질 분류 색칠
- `deadpix.json`: 컷별 flat_gnd · 연결성분 상위 12개(면적·평균RGB·bbox·중심)

### 판정: **조건부 가능 — P0(노면 텍스처) 단독으로 통과. 단 P1 을 세트로 해야 한다.**

- **P0 만**: 28.10 → **2.86** (목표 3.0 통과, 여유 5 %). 다만 `culvert_far` 8.01,
  `channel_reveal` 7.28 같은 개별 컷은 여전히 높다 — 이 두 컷은 측구 내벽이
  화면을 크게 차지하는 뷰다
- **P0 + P3**: 28.10 → **0.98**. 안전 마진 3배
- **불가피 하한 = 0.88** (차선 도색 0.72 + 컬버트 암색 0.16). 이 아래로는
  규약을 깨지 않고는 못 간다. 실사 0.1 % 에는 **도달 불가이며, 도달할 필요도 없다**

### "조건부" 인 이유 (= 실패할 수 있는 경로)

1. **`roughness_const` 분기 함정.** P0 만 넣고 `asphalt_rough=0.85` 를 그대로 두면
   `rough_mult_a=0` 으로 rough 맵이 무시된다. 디퓨즈·노멀은 살지만 광택 변조가
   빠져 개선폭이 줄 수 있다. → **P1 과 반드시 함께**
2. **그레이징 광택 세척.** §5-P1 의 [추정]대로 노면 밝기의 절반 이상이 하늘 돔
   반사라면, 디퓨즈 텍스처의 대비가 그만큼 희석된다. `oblique_cross`(노면 68.5 %)
   처럼 노면이 화면을 뒤덮는 컷에서 위험. `specular_level` 하향이 보험
3. **원거리 MIP 소실.** 다만 잔디 버지가 최원거리 밴드에서 dead **0.0 %** 인 것이
   반례다 — 4k 텍스처 + 1024 다운샘플 조합에서 원거리 소실은 관측되지 않았다.
   위험 낮음
4. **`flat_gnd` 지표 자체의 불안정성.** §4 노이즈 실험에서 σ 2.0→3.1/255 사이에
   25.8 → 7.1 의 절벽이 있었다. 개선 후 값이 임계 근처(2.5~3.5)로 착지하면
   렌더 시드·해상도만 바뀌어도 판정이 뒤집힐 수 있다. → **P3 까지 넣어 0.98 대에
   착지시키는 것을 강력히 권장.** "간신히 통과"는 통과가 아니다
