  프레임 안에 있고 기하 오류(주택 솔리드 관입 등)는 없다. 어두울 뿐 **판독 정보가

* **결론: `narrow_up` 은 PT 재캡처 후 재판정 대상.** (`NEGOBS_CAPTURE_MODE=pt`
  `NEGOBS_VIEWS=narrow_up`) 코드 수정 없음.

### 3-1. 램프 성토 블록 → 잔디 동재질 + 강측 잔디 배터 (판정 ㉠, 최대 잔여 억지 요소)

조치(노면·경사·폭·시종점 = 위험 기하는 불변, **마감만** 변경):

1. `Fill` 재질 `M["rock"]` → **`M["grass_b"]`** (사면 잔디와 동재질·동틴트 계열).
2. **강측 잔디 배터 3단 신설** — 폭 0.50 × 낙차 0.42 (구배 84% ≈ 1:1.19, 잔디 성토
   어깨 관행), 잔디 재질 교대(grass/grass_b)로 단 경계가 띠로 도드라지지 않게.
   `margin 0.30` 으로 성토체와의 이음 틈 차단.

스모크 검산(`NEGOBS_SMOKE=1`):

```
[강측 잔디 배터] 3단 × 폭 0.50 × 낙차 0.42 = 폭 1.50 · 낙차 1.26 (구배 84% ≈ 1:1.19)
  덮어야 할 노면 밑 최대 노출 = 최대석축 1.530 − 노면두께 0.35 = 1.180 m → OK
  s  0.0 배터 끝 (x 4.64, y  3.25) 상면 -1.610 · 지반 -2.320 → 잔여 잔디면 0.710
  s  6.0 배터 끝 (x 5.60, y  9.17) 상면 -2.090 · 지반 -2.800 → 잔여 0.710

  s 20.0~40.0                                              → 잔여 0.000 (전부 매몰)
  잔여 최대 0.710 m (구 수직 절단면 1.530 m 대비 −54%) · 전 구간 잔디 재질
  배터 풋프린트: x ≤ 11.04 < 산책로 x0 11.5 → OK · y ≥ 3.25 > 계단 y1 1.5 → OK
```

현 조치로 남는 것은 **잔디 재질의 0.71 m 단**(구 1.53 m 갈색 수직 절단면 대비 −54%)
이며, 주변 사면과 동재질이라 "블록"이 아니라 지형 접힘으로 읽힐 것으로 본다.
