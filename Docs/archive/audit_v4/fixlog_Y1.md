## 2. ② 원인 확정 — 정반사 가산분 (렌더 없이 3중 수치 분리)

### 전제 정리 : park_vista 에서 지붕은 **면 2군**만 보인다

카메라 `eye(-10.2, 22.0, 3.8) → tgt(4.0, 0.0, -1.8)`, 정자 중심 `(-4.2, 8.8)`.
카메라가 정자의 **−X · +Y 쪽**에 있으므로 가시 지붕면은

| 면군 | 면 | 직달 램버트 |
|---|---|---|
| +Y 군 | face0, face1 | 0.8125 / 0.8681 (평균 **0.840**) |
| −X 군 | face2, face3 | 0.4896 / 0.5264 (평균 **0.508**) |

실제로 v8 PNG 지붕 영역의 계조 히스토그램은 **정확히 2봉**이다(176–191 에 5.7만 px,
128–143 에 3.5만 px). 나머지는 하늘·처마밴드.

### ⓐ 실측 응답 = 선형값 / 알베도

| 표본 | sRGB | 선형 | 응답(선형/알베도) |
|---|---|---|---|
| 지붕 +Y면 | (180.2, 183.1, 189.9) | (0.4575, 0.4741, 0.5143) | **2.95 / 2.87 / 2.78** |
| 지붕 −X면 | (130.0, 134.0, 144.0) | (0.2232, 0.2384, 0.2789) | 1.44 / 1.45 / 1.51 |
| 포장(수평) | 193.5 | 0.5364 | 1.79 (= `_ALBEDO_GAIN` 1.77 과 일치) |

지붕만 응답이 **1.6배 초과**한다. 포장은 씬 모델과 정확히 맞으므로
**조명 리그·톤매핑·노출은 무죄**다.

### ⓑ 확산만으로는 수치가 성립하지 않는다 (결정적)

가시 2면을 `resp = S·lam + K` (S=직달, K=천공/간접, 둘 다 ≥0) 로 적합하면

```
S = +4.549 ,  K = −0.870      ← 음의 앰비언트
```

**K<0 은 물리적으로 불가능**하다. 즉 두 면의 대비가 램버트 스프레드(0.840 vs 0.508)
로 낼 수 있는 것보다 **크다** ⇒ 램버트로 설명 안 되는 **시선의존 항**이 반드시 있다.
이것이 "알베도/법선 계열"을 전부 배제하는 단일 근거다.

### ⓒ 로브 밖 면을 앵커로 잡으면 초과분이 "가산 반사항"으로 떨어진다

−X 면(하프벡터에서 멀다)과 수평 포장을 **확산 앵커**로 다시 적합:

```
S = +1.360 ,  K = +0.749      ← 정상
⇒ +Y면 확산만 예측 응답 = 1.892   (씬 _ALBEDO_GAIN 1.77 과 일치)
⇒ +Y면 확산만 예측 sRGB = (147.3, 151.6, 159.7)
   실측                    (180.2, 183.1, 189.9)
   실측 − 예측(선형)       (+0.1643, +0.1619, +0.1643)
```

**초과분이 3채널 모두 +0.164 로 동일**하다. 알베도 오차라면 채널별로 **비례**해야
하는데 **가산**으로 붙었다 — 반사(정반사) 성분의 서명 그대로다.
(판정이 단서로 든 "R<G<B 청백"은 오히려 알베도 자체의 색비 1:1.064:1.194 가
그대로 보존된 것이고, 초과분은 거의 무채색이었다.)

### ⓓ GGX 하프벡터가 정확히 +Y 군만 때린다

`L`(태양, elev 49.79 / az 33.5) 과 `V`(park_vista 시선)의 하프벡터 `H` 에 대해

| 면 | N·H | 각 |
|---|---|---|
| face0 (+Y) | **+0.796** | 37.3° |
| face1 (+Y) | **+0.805** | 36.4° |
| face2 (−X) | +0.411 | 65.7° |
| face3 (−X) | +0.499 | 60.1° |

`roughness 0.72` (α≈0.52) 의 로브는 37° 를 넉넉히 덮고 65° 는 거의 못 덮는다.
**밝은 면군 = 로브 안, 어두운 면군 = 로브 밖** — ⓑ의 "음의 앰비언트"와 정확히 대응.

### ⓔ 절병통이 어두웠던 이유도 같다 — 판정 "1.6배"는 비교 대상이 어긋나 있었다

절병통은 원기둥이라 법선이 연속 스윕한다 ⇒ 로브에 드는 것은 **가느다란 한 열**뿐.
v8 PNG 절병통 가로 스캔 실측:

```
… (157,161,169) (124,129,139) (44,51,64) (28,35,48) (27,34,47) …
        ↑밝은 열                    ↑확산 몸통 → 그늘
```

판정이 쓴 절병통 값 111 은 **확산 몸통의 평균**이고, 지붕 178~180 은 **정반사 가산면**
이다. 같은 성격끼리 비교하면 지붕 +Y면(0.4575) : 절병통 밝은 열(163→0.3719) =
**1.20배**로, `roof_normal_selfcheck` 이 계산한 기하 상한비 1.10배와 사실상 같은 대역이다.
⇒ "같은 재질인데 1.6배"라는 관측 자체가 **표본 오설정**이었고, 두 라운드를 여기에 썼다.

### ⓕ 결정적 정황 — 이 씬에서 `specular_level` 이 빠진 무광 재질은 지붕뿐

```
M["reed"]      … specular_level=0.0
M["far"]       … specular_level=0.0
M["canopy_a"]  … specular_level=0.0
M["canopy_b"]  … specular_level=0.0
M["pav_roof"]  … (미지정)   ← 유일
```

`make_pbr` 은 `specular_level=None` 이면 입력을 아예 만들지 않으므로 **MDL 기본값
0.5(F0 0.04)** 가 그대로 산다. 무유약 한식 기와는 무광이므로 애초에 0.0 이어야 했다.

## 5. 폴백(_oriented_box 4장 + 용마루)을 채택하지 않은 이유

판정이 대안으로 지정한 재구성은 **이 버그를 고치지 못한다**:

* 폴백의 명분은 "법선·바인딩 문제 원천 회피"인데, §1·§1-b 로 **둘 다 무죄**가 확정됐다.
  메시는 이미 평면 셰이딩이고 바인딩도 정상이다.
* 원인은 **재질의 정반사 항**이다. 박스 4장으로 바꿔도 같은 재질·같은 면방위를 쓰는 한
  같은 하프벡터에 같은 로브가 걸려 **초과분 +0.164 가 그대로 남는다**.
* 반대로 잃는 것은 확정적이다 — 귀솟음(모서리 lift 0.16)과 밴드-슬로프 연속 솔리드가
  사라져 `fixlog_X1` 이전의 "웨딩케이크 층단 / 모서리 삼각 공동" 문제로 되돌아간다.

⇒ 폴백은 **원인이 메시였을 경우에만 유효한 처방**이었고, 원인이 확정된 지금은
비용만 남는다. 3라운드째를 피하라는 지시는 "원인 규명 없이 또 굴리지 말라"는 뜻으로
읽고, **원인을 수치로 확정한 뒤 최소 수정**으로 응답했다.
