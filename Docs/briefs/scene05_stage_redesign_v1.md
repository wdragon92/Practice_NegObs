## 0. 결론 3줄

1. **"조잡"의 물리적 실체는 무대 단(podium)이 아니라 그 승강 계단이다.** θ130–160 / 200–230 의
   30° 짜리 2조 스텁 계단 + 3.2° 마구리 4장이, 관람석이 바라보는 정면 사분면에 **분리된 곡면
   콘크리트 조각 2개 + 검은 나이프 에지**로 렌더된다 `[실측: facade/pt_noon_preset_h0.9_d2.png,
   rim_view, side_arc]`.
2. **"원형이 아니다"의 실체는 동심 링 위계의 붕괴다.** 무대 단 r3.00 이 에이프런 r4.90 안에
   면적비 0.375 로 앉아 있고(폭 1.90 m 도넛), 상면 재질이 에이프런·티어와 **완전히 동일**
   (렌더 RGB ≈ 190/255)이라 원형 실루엣이 지워진다 `[실측: 픽셀 샘플]`.
3. **권고 = R2 "동심 원형 무대 + 전주(全周) 3단 스텝링".** 스텁 계단·마구리 53 프림을
   **동축 실린더 3개**로 대체하면 쐐기·나이프 에지가 원리적으로 소멸하고, 무대가 완전한 원이
   되며, GT·진입계단·티어 좌표는 한 줄도 바뀌지 않는다. 여기에 **목재 데크 재질 + 무대 캐노피**를
   더하면 "무대로 읽힌다"가 성립한다. 무대고는 0.354 → **0.450 권고**(§4.4, 사용자 결정 사항).

**여기서 확정되는 사실**:
- 고전 극장에서 **원형인 것은 "오케스트라(바닥)"이고, "무대(프로스케니온/풀피툼)"는 직사각형**이다.
- 우리 씬의 현행 구성(원반 r4.9 + 그 안의 작은 원형 단 r3.0)은 **그리스형도 로마형도 아니다**.
- 프로스케니온 면적/오케스트라 면적 = (19.5×6.1)/(π·9.75²) = 119/299 = **0.40** — 무대는 오케스트라의 약 4할.
  → 우리 오케스트라 75.4 m² × 0.40 = **30 m² 가 무대 규모의 문헌 기준선**. 현행 28.3 m² 는 **이미 규모는 맞다**.
  즉 **문제는 크기가 아니라 형태·재질·접근계단**이다. 이것이 본 안의 방향을 결정한다.

### 2.4 "무대는 원형/반원인가" — 근거 확정

> **확정 명제**: *원형인 것은 오케스트라(연기 바닥)이고, 무대(연단)는 직사각형 또는 아크 전면의 D형이다.*
> 단, **한국 근린공원 소규모 야외무대**에서는 **원형 융기 무대 + 전주 저계단** 형식이 관행적으로 존재하며
> (마당놀이·버스킹 무대 계열 `[관행]`), 이 경우 **반드시 전 둘레에 연속 계단**이 돌고 **지붕**이 얹힌다.
>
> ⇒ 우리 씬은 **오케스트라 원(r 4.90)을 명확히 유지**하되, 무대 융기부는
> **(a) 전주 스텝링을 두른 동심 원형 연단**(R2, 권고) 또는
> **(b) 배후벽 쪽으로 물린 D형/직사각 연단**(R1, 대안) 중 하나여야 한다.
> **현행처럼 스텁 계단 2조만 붙은 섬형 플린스는 실제 사례 0/3 · 문헌 근거 0** 이다.

### 3.2 **권고안 R2** — 동심 원형 무대 + 전주 3단 스텝링 (실린더 3개)

핵심: **아크 박스(build_arc_steps) 를 쓰지 않는다.** 동축 `UsdGeom.Cylinder` 를 반경 감소·상면 상승
순으로 3개 겹치면, 보이는 결과가 그대로 **3단 원형 지구라트**가 된다.
쐐기 틈·호끝 슬리버·마구리가 **원리적으로 존재할 수 없다**(경계면이 아예 없음).
프림 수 **53 → 3**(구 = 아크 2조×2단×seg12 = 48 + 마구리 4 + 단 실린더 1 = 53 /
신 = 스텝 실린더 2 + 단 실린더 1 = 3. C-3 전면 연석을 채택하면 +1 = 4).

```
       ┌─ r 3.00  top −0.757   무대 상면 (deck)
   ┌───┴──── r 3.34  top −0.907   스텝 1 (석재)
┌──┴──────── r 3.68  top −1.057   스텝 2 (석재)
────────────────── −1.207        오케스트라 바닥 (r 4.90)
```

|---|---|---|
| 무대 반경 | **3.00 (현행 유지)** | 면적 28.3 m² = 문헌 기준선 30 m²(§2.1) 대비 0.94 ✓ |
| 무대 상면 | **−0.757** (융기 **0.450**) | 127석 가이드 대역 0.41–0.51 ✓ (§2.3) |
| 스텝 | 3단 × riser **0.150** · 디딤 **0.340** | 2R+T = 0.64 (권장 0.60–0.65) ✓ · 옥외 riser ≤0.20 ✓ · tread ≥0.26 ✓ `[법령]` |
| 스텝링 외경 | 3.68 | 오케스트라 가장자리 4.90 까지 **통로 폭 1.22 m** ✓ |

| 배후벽까지 | 스텝링 3.68 → shell 내면 4.75 = **1.07 m** | 백스테이지 통로 확보 ✓ |
| 승강 방향 | **전 둘레(360°)** | `[통계 ②]` 전면 전폭 연속계단과 동일 규칙 ✓ |

왜 R2 인가:
- "**원형**" 요구를 문자 그대로 충족(무대·스텝·오케스트라가 전부 동심 원).

- **진입 아크계단·티어·shell·cut_wall·backyard·lip·seat 좌표를 한 줄도 건드리지 않는다.**
- GT 변경분이 **반경 3.00–3.68 밴드의 깊이 0.15/0.30 단차뿐**(§4.4-a).

### 4.4 GT / 사용자 결정 변경분 (별도 표기)

**a. GT 델타 (R2 채택 시)** — 티어 낙차 1.2 및 riser 0.4 는 **불변**.
바뀌는 것은 오직 보울 바닥의 낙차 맵 중 **반경 3.00–3.68 밴드**:

| 반경대 | 구 GT 깊이(광장 0 기준) | 신 GT 깊이 | Δ |
|---|---|---|---|
| r < 3.00 | 0.853 | 0.757 | **−0.096** |
| 3.00 ≤ r < 3.34 | 1.207 (에이프런) | 0.907 | −0.300 |
| 3.34 ≤ r < 3.68 | 1.207 | 1.057 | −0.150 |
| 3.68 ≤ r < 4.90 | 1.207 | 1.207 | 0 |
| r ≥ 5.00 (티어) | 1.200 / 0.800 / 0.400 | **불변** | 0 |

영향 면적 = π(3.68² − 3.00²) = **14.3 m²**(오케스트라의 19 %). 판정 1순위 h0.3·d5/d10 에서는
**전 구간이 보울 안에 은닉**되어 프레임에 나타나지 않는다(§5).
무대고를 **0.354 로 유지**하면 위 표의 −0.096 이 0 이 되고 스텝은 2단 × 0.177 (radii 3.68/3.34,
tops −1.030/−0.853) 로 조정하면 된다 — **GT 델타는 스텝 밴드만 남는다**.

**b. 감독 판단 필요 2건**
1. **무대고 0.354 → 0.450** — 0.354 는 v5.2 에서 **사용자가 직접 정한 값**("가볍게 폴짝").
   0.450 근거: 127석 옥외무대 가이드 0.41–0.51 `[가이드]`, 장미공원 실측 ≈0.6 `[통계 ②]`,
   그리고 3단 × 0.15 완경사 스텝이 "폴짝" 의도를 **오히려 더 잘 충족**. **사용자 승인 전 변경 금지**.
2. **`cut_wall` top +1.00 → +0.55 (C-5)** — 마당(−0.06)→티어3(−1.20) 낙차 **1.14 m** 를
   현재 1.06 m 벽이 단독 차단 중. 0.61 m 앉음벽 + 폭 0.9 m 관목대로 대체하면 방호는 약해진다
   (v6 ㉠ 에서 `shell` 을 1.40→0.70 으로 낮출 때와 **동일 성격의 절충**). 감독 결정 사항.
