작성: 상수색 텍스처 매핑 담당 · 2026-07-28
대상: `scenes/main/*.py`(21) + `scenes/batch1/*.py`(12) = **33씬**
기준 코드: `scene_common.py` @ `27d8d12` (P2 승격 커밋 반영본)

> **이 문서의 한 줄 결론**
> 상수색 재질은 make_pbr 호출의 **65.8%**(435/661)이고, 남은 `flat_gnd` 를 실제로
> 만드는 대면적은 **① 눈(sceneC1, 지면프레임 88.5%) ② 수면 5씬 ③ 밝은 파라펫·
> 건물 셸 ④ 금속(그레이팅·난간)** 네 덩어리다. 이 중 **신규 조달이 필요한 것은
> 눈 1종과 아연도금 금속 1종뿐**이고, 나머지는 **기존 TEX 레지스트리에 `tex=` 키를
> 연결하는 것만으로 조달 0**으로 해결된다.

## 0. 측정 방법 (재현 절차 · GPU 미사용)

Isaac Sim 은 **한 번도 실행하지 않았다**. 세 단계 정적 측정이다.

1. **상수색 전수 추출 (AST)** — 33씬을 `ast` 로 파싱해 `make_pbr`/`PBR` 호출 중
   `diff` 인자 없이 `diffuse_color` 만 주는 호출을 전부 수집. 색상값은 모듈을
   import(=`PARAMS` 만 평가, `main()` 미실행)해 `mp["..."]` 참조를 실값으로 해소.
2. **프림 인벤토리 (스텁 조립)** — `pxr`/`omni`/`carb`/`isaacsim` 을 MagicMock 으로
   대체하고 `sc.add_box/add_cylinder/add_sphere/_oriented_box/make_pbr` 를 기록
   스텁으로 갈아끼운 뒤 각 씬의 `main()` 을 `NEGOBS_CAPTURE=1` 경로로 돌려
   **모든 프림의 중심·치수·회전·바인딩 재질**을 받아냈다(33/33 성공, 재질이
   바인딩된 프림 **23,360개**).
   GPU·USD·렌더러 전무.
3. **화면 기여도 (레이캐스트)** — 각 씬의 `build_views()` 프리셋 **전부**(그리드
   9 + 미장센, 씬당 13~16뷰)에서 160×90 레이를 쏘아 프림 로컬 프레임에서
   박스/원기둥/타원체 **정확 교차**로 최근접 재질을 결정. 지표는
   **하단 2/3 프레임 점유율(`gnd%`)** — `scripts/imgstats.py` 의 `flat_gnd`
   영역 정의와 동일하다.

> 검증: sceneD3 의 상수색 아스팔트 `gnd% = 27.0` vs 실측 `flat_gnd = 28.1`.
> 다른 에이전트의 D3 정밀 진단("죽은 픽셀의 89.8%가 상수색 아스팔트")과
> **독립적으로 같은 결론**에 도달했다. 측정 파이프라인의 교차 검증으로 본다.

**한계(정직 고지)**: ① 회전 박스는 로컬 프레임 교차라 정확하나 `build_hedge` 의
crown 블롭·`_ground_skin` 은 스텁에서 제외됐다(스킨은 상수색 판정에 무관).
② 조명·그림자·투명 미반영 — 점유율은 **기하 가시성**이지 밝기가 아니다.
③ `flat_gnd` 는 국소표준편차 지표라 점유율이 곧 죽은 픽셀은 아니다(상수색은
정의상 국소표준편차 0 이므로 **점유율이 상한**이다).

### 3-3. 경고 — `concrete_wall` 승격의 색 왜곡 (신규 발견)

`_promote_const_to_texture` 는 `base_color = 의도색 / 텍스처평균` 에
`min(2.5, …)` 클램프를 건다. `concrete_wall` 의 실측 평균은
**(0.265,0.237,0.160)** 으로 **R:B = 1.66 의 따뜻한 색**이다. 밝은 중성 회색
파라펫에 걸면:

| 대상 | 요구 배율 R,G,B | 결과 |
|---|---|---|
| scene19 `Parapet` 0.90,0.90,0.87 | 3.40 / 3.80 / **5.44** | 전 채널 클램프 → 실효색 **(0.663,0.592,0.400)** — 의도보다 26% 어둡고 **누렇게 편향** |

⇒ **밝은 콘크리트는 `plaster`(0.407,0.366,0.350, 거의 중성)로 분기**하면
배율 1.5~2.5 로 클램프 없이 색이 보존된다. 신규 조달을 감수한다면 ambientCG
**`Concrete034`**(실측 (0.482,0.482,0.482) **완전 중성**, sd 0.037,
https://ambientcg.com/a/Concrete034, CC0)가 최적이다 — 배율 1.24~1.87.

### 3-4. sRGB 지각 경고 (프로젝트 확립 교훈 준수 확인)

- 선형 0.15 ≈ 표시 sRGB 107~127. 아래는 **표시값 200 이상 = 백색 지각** 구간이다.
- **sceneC1 `Snow` 0.72~0.78 → sRGB 221~229**: 지면프레임의 **88.5%** 가 이 값이다.
  overcast HDRI 조명까지 곱해지면 상당 면적이 톤매핑 상단에서 **클리핑**되고,
  클리핑된 픽셀은 텍스처를 붙여도 국소표준편차가 **다시 0** 이 된다.
  ⇒ 텍스처만으로는 불충분. **의도 알베도를 0.72 → 0.55~0.62 로 하향**한 뒤
  승격해야 결이 살아남는다(실제 다져진 도시 적설의 반사율 대역이기도 하다).
- **scene19 `Parapet` 0.90,0.90,0.87 → sRGB 244**: v5.1 §4 "순백(>0.8) 대면적
  금지"의 **명백한 위반**이며 1,046 m²·gnd 10.0% 다. 색 하향이 우선, 텍스처는 그 다음.
- sceneC1 `Parapet` 0.86,0.87,0.88 / `Rail` 0.72,0.74,0.78,
  sceneN5 `BollardBody` 0.78,0.80,0.83, scene02/16/20/21 `Rail` 0.80,0.82,0.85 도
  같은 대역이다(면적은 작다). 반사띠(`BollardBand` 0.88)는 **의도된 백색이므로 예외**.
- 반대 방향 경고: 텍스처 평균이 의도색보다 **밝으면** 배율<1 이라 안전하지만,
  **어두우면 배율>2.5 에서 클램프**되어 의도보다 어두워진다(§3-3, wood 도 해당).

## 4. 텍스처화 **금지** 목록 검토 (누락·과잉)

기준: 균일해야 낙차/보행 단서로 기능하는 것 + 물리적으로 균일한 것.
현재 `_CONST_MDL_CLASSES` 제외 = `paint · sign · glass · water · misc`.

### 4-1. 금지 유지가 옳은 것 (검증 완료)

| 클래스/재질 | 근거 | 해당 예 |
|---|---|---|
| `paint` — 차선·정지선·반사띠·점자블록 | 도색은 실제로 균일. 노이즈는 **cue 신호를 오염**시킨다 | D1 `BandBlack`(gnd 4.9) · D3 `Paint` · 11 `LineYellow` · N5 `Tactile` · N5 `BollardBand` |
| `glass` — 창·상점 유리 | 알베도가 아니라 반사가 색을 만든다 | 15 `Window` 4.2 · 11/C1 `Glass` |
| `sign` — 사인 면·백면 | 인쇄면. 실제 사인 텍스처는 `TEX["sign_*"]` 로 별도 존재 | 11/06 `Panel`(단, §4-2 예외) · 21 `SignBack` |
| `water` — 수면 | 디퓨즈 균일이 물리적으로 옳음(§3-2③) | 09/12/17/C4/03/18 |
| 발광 패널 | `make_pbr` 의 `emission_color is not None` 분기에서 룩 레이어 자체가 스킵됨 — **이미 안전** | D4 발광 |

### 4-2. **과잉 제외(누락) 3건 — 수정 권고**

1. **`misc` 에 갇힌 `Snow` (C1, gnd 88.5%) — 최우선.**
   `LOOK_ROLE` 주석은 "Bag/Emit/Rubber/Snow 는 의도적으로 misc"라고 적었지만,
   Snow 는 **미상 재질이 아니라 명확한 대면적 지면**이다. 33씬 통틀어 단일
   재질 최대 점유율이며 현재 **상수색 MDL도 텍스처 승격도 전혀 못 받는다**.
   ⇒ `LOOK_ROLE["Snow"]="snow"` + 신설 클래스(`mdl="ground"`, `tex="snow"`).
   `Bag/Rubber` 는 소품이므로 misc 유지가 옳다.

2. **`Panel` 이 sign 으로 분류되어 제외 (11 gnd 6.0 · 06 gnd 5.4).**
   실제 지오메트리는 사인이 아니라 **데크 난간의 불투명 패널(1.8×0.95 m ×47매)**
   과 **쉘터 지붕(6×4 m)** 이다. 사인 규약으로 보호할 대상이 아니다.
   ⇒ 이름 변경(`DeckPanel`→`RailPanel`) 또는 `_LOOK_RULES` 의 `"panel"` 키워드를
   `"signpanel"` 로 좁힐 것. 현행 규칙은 `panel` 이 통째로 sign 으로 빨려든다.

3. **`Verge*` 가 curb 로 오분류 (scene04, 3재질 합 gnd 13.6%).**
   `_LOOK_RULES` 의 curb 키워드에 `"verge"` 가 있어 잡히는데, scene04 의
   `Verge_*` 프림 99개는 **초지·관목 블롭**(색 0.078,0.096,0.037 = 진녹)이다.
   현재 연석용 베벨 10 mm + `_W_EDGE` 오염 밴드를 받고 있다 — **식생에 연석
   처방**이라 물리적으로 틀렸다. ⇒ 색상 기반 예외 또는 이름 변경 권고.

### 4-3. 금지 목록에 **추가**할 것 (과소 제외 = 위험)

- **`nosing` (현재 `_CONST_MDL_CLASSES` 포함)** — 노징은 **낙차 에지 단서 그 자체**다.
  텍스처 승격은 결을 주지만 12 mm 폭 띠에 무늬가 들어가면 에지 대비가 흐려질 수
  있다. 점유율도 4.8%p(21 `Nosing` 1.7 최대)로 이득이 작다.
  ⇒ **`tex=` 부여 금지**(현재 없음 = 유지). MDL 변조만 허용.
- **`Joint`/`CutLine`(신축줄눈·절단선, asphalt 로 분류)** — N3 gnd 5.6 · N1 3.9.
  실물은 폭 3 cm 실런트로 **균일한 흑색**이 옳다. asphalt 클래스에 `tex=` 가
  붙은 지금 **줄눈에 아스팔트 결이 얹힌다**. ⇒ `Joint`/`Seam` 계열을 `paint`
  (또는 신설 `sealant`)로 재분류 권고. 폭 3 cm 라 회귀 위험은 낮지만 논리가 틀렸다.

## 5. `scene_common.py` 이식용 초안

> 감독 확인 후 적용. **이 담당은 코드를 수정하지 않았다**(쓰기 권한 1파일 원칙).

```python
# ── [1] TEX 레지스트리 추가 (신규 조달 2종) ────────────────────────────
TEX["snow"] = dict(dir=S1_DIR, diff="snow_diff.jpg",
                   nor="snow_nor_dx.jpg", rough="snow_rough.jpg")
#   출처: Poly Haven `snow_01` (CC0 1.0, 2.0 m 타일)
#         https://polyhaven.com/a/snow_01
#   실측 선형평균 (0.488,0.474,0.466) · 휘도 sd 0.074 · 발자국 요철
TEX["metal_galv"] = dict(dir=S1_DIR, diff="metal_galv_diff.jpg",
                         nor="metal_galv_nor.jpg", rough="metal_galv_rough.jpg")
#   출처: ambientCG `Metal038` (CC0 1.0, 2K-JPG)
#         https://ambientcg.com/a/Metal038
#   실측 선형평균 (0.118,0.123,0.123) 중성 · 아연도금 스팽글 + 스크래치
#   ※ ambientCG zip 접미사는 기존 ACG_SUFFIX 매핑 그대로:
#      _Color.jpg→diff / _NormalDX.jpg→nor / _Roughness.jpg→rough

# ── [2] LOOK_ROLE — Snow 를 misc 에서 구출 ─────────────────────────────
LOOK_ROLE["Snow"]     = "snow"
LOOK_ROLE["SnowCap"]  = "snow"     # C1 난간/식생 눈 캡(이름 실측 확인 후)
LOOK_ROLE["DeckPanel"] = "metal"   # §4-2②: 난간 패널은 사인이 아니다

# ── [3] LOOK_CLASS — tex 키 확장 ───────────────────────────────────────
LOOK_CLASS["snow"] = dict(bevel=0.000, sat=0.85, mdl="ground", patch=1.0,
                          detail=True, tex="snow", bump=1.3, spec=0.15)
LOOK_CLASS["wood"]["tex"]  = "wood_dark"        # 기존 파일 — 조달 0
LOOK_CLASS["veg"]["tex"]   = "leaf_ground"      # 기존 파일 — 조달 0
LOOK_CLASS["curb"]["tex"]  = "plaster"          # 기존 파일 — 조달 0
LOOK_CLASS["metal"]["tex"] = "metal_galv"       # 신규
# concrete 는 단일 tex 로 부족하다 — §3-3 참조. 밝기 분기를 권고:
#   휘도(diffuse_color) >= 0.45 → "plaster"(중성·밝음)
#   그 외               → "concrete_wall"(현행)
_CONST_MDL_CLASSES |= {"snow"}                  # 승격 경로 진입 조건

# ── [4] 밝기 분기가 필요한 이유를 코드로 (concrete 예시) ───────────────
def _tex_role_for(cls, spec, diffuse_color):
    """의도색이 밝은 중성 회색이면 따뜻한 concrete_wall 대신 plaster 로.
    concrete_wall 실측 평균 (0.265,0.237,0.160)은 R:B=1.66 의 난색이라
    0.9 급 파라펫에서 base_color 배율이 3.4/3.8/5.4 가 되어 min(2.5) 클램프에
    걸리고, 결과가 26% 어두워지며 누렇게 편향된다(측정 근거: 보고서 §3-3)."""
    role = spec.get("tex")
    if cls == "concrete" and diffuse_color is not None:
        lum = (0.2126 * diffuse_color[0] + 0.7152 * diffuse_color[1]
               + 0.0722 * diffuse_color[2])
        if lum >= 0.45:
            role = "plaster"
    return role

# ── [5] 클램프 상한 재검토 ────────────────────────────────────────────
#   현행 min(2.5, …) 에서 wood(의도 0.30 ÷ wood_dark 0.082 = 3.66)가 걸린다.
#   → 실효색 (0.205,0.145,0.110) 로 32% 어두워진다. 3.8 로 완화하거나
#     wood 계열 의도색을 0.20 대로 하향하는 것 중 택일 필요.
```
