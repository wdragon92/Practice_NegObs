## 4. 주요 발견 (이번 런의 지식 자산)

- **ⓐ 정오 노출 기구**: 씬별 노출 게인 1.77~2.46 실측. 표시 클립선이 실효 알베도
  **0.21~0.27** 에 온다 — 클래스 천장 0.34 이 클립선 **위**라서 "대역 내" 값도 정오에
  순백으로 탄다(s14/s05/s18/s09 의 공통 기전, 3기 병렬 교차 확인). 처분 선택지 =
  천장 재예산(≈0.26) vs 노출/톤맵 조정(코퍼스 광학 동결 해제) — **사용자 판정**.
- **ⓑ GT-125·127 부정 결과 2연**: Oren-Nayar 확산(GT-125)도, 판정창 대역 알베도
  마이크로 옥타브(GT-127 — RMS 3 %·7.5 % 2점, 디노이저 OFF 대조까지)도 slope 를
  못 움직였다. 대신 **디노이저 자체의 slope 비용 +0.09~+0.15 를 실측**(2×2 분해,

  설정(디노이저) 층**. 채택은 spp 예산과 묶여 사용자 판정(§5-12). asphalt 한정
  grazing 0.25 만 재질측 미래 후보.
