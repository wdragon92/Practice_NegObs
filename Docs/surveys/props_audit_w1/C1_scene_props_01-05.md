# C1 — 씬 소품 전수 감사 (scene01~05) · 입식 소품

작성 2026-07-29 · 담당 범위 = **입식 소품**(벤치·볼라드·가로등·조명·팻말/간판·펜스·
쓰레기통·화분/화단·차양·정자·구조물 장식·게이트). 지면 부착 인프라(측구·맨홀·연석·
노면표시·줄눈·패치)는 **존재 여부만** 기록(근경 프로파일 팀). 나무·관목·낙엽·텍스처는
에셋 팀. 무대 본체(scene05)는 존재만 기록(무대 재설계 에이전트).

## 방법·판정 규약

1. **코드 실측** — AST 로 `PARAMS` 를 부팅 없이 평가(`ast.parse` → 모듈 레벨 Assign 만
   exec)하고, 빌더 본문을 읽어 프림 구성(박스/실린더/구 개수)·치수·재질 상수를 실측.
   `scene04.verge_instances()` 는 실제로 돌려 개체 수를 셌다.
2. **화면 실측** — 각 씬 `look_check/<scene>/{v8_pt|v7_pt}/pt_noon_preset_h0.3_d{2,5,10}.png`
   3컷 + 미장센 컷(beauty/approach/oblique/anchor 등)을 직접 열람. 화각은 매니페스트
   eye/tgt + 기본 뷰포트 카메라(수평 화각 60.1°, 반각 30°)로 방위각 검산.
   ※ 이 렌더는 P3(나무 실물 USD)·P4 이전본이라 블롭 나무가 보이는 것은 정상.
3. **실물 대조** — `Docs/surveys/_dimension_index.md` 의 법정/KS 치수와 대조.
   색인에 없는 항목은 웹·법령 원문을 별도 확인하고 태그를 붙였다.
4. **판정어** — `유지` / `치수교정` / `형태재작` / `제거` / `신규필요`.
5. **우선순위** = h0.3 프레임 점유율 × 작위성. `P0`(다음 웨이브 즉시) `P1` `P2`.
6. 모든 수치에 근거 태그 `[실측]` `[법령]` `[통계]` `[논문]` `[관행]` `[추정]`.
   `[관행]`은 법정 근거는 없으나 국내 표준품·조달청 규격·시공 관행으로 확인되는 것.
