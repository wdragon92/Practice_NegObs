## 0. 이 표를 읽는 법

- **수치는 전부 씬 파일 AST 파싱값이다.** 추정치 없음. 각 행의 출처는 §3 에 명시.
  모듈 상수(`RISERS`, `_RISER_CYCLE`, `_RISER`, `_NRISER`)도 실제로 해석해서 넣었다.
- 불균등 계단은 **가장 불리한 값**(riser = 최대, tread = 최소)으로 판정한다.
- "참 현재" 는 **중간** 계단참만 센다. 계단 상·하단의 평지(에이프런·하단 참)는 제외.
- "중간난간 현재" 는 **계단면을 가로질러 서는 중간 열**만 센다. 측면 난간은 별도 판정(R2).
- `*(면제)*` = 폭이 3 m 를 넘지만 §15①3 단서(단높이 ≤150 **그리고** 단너비 ≥300)로 면제.

### 판정 기준 (전부 법령 원문)

| 코드 | 등급 | 요건 | 근거 |
|---|---|---|---|
| **L1** | P0 | 계단참 : 높이 **3 m 초과 → 3 m 이내마다** (주택단지 **2 m**) | 피난방화 §15①1 / 주택기준 §16②1 |
| L2 | P1 | 계단참 깊이 **≥1.20 m**(진행방향) | 〃 |
| **R1** | P0 | 중간난간 : 너비 **3 m 초과 → 3 m 이내마다**. 면제는 `riser ≤0.150` **AND** `tread ≥0.300` | 피난방화 §15①3 |
| R2 | P1 | 양옆 난간 : 계단 높이 **1 m 초과** 시 의무 | 피난방화 §15①2 |
| **D1/D2** | P0 | 옥외계단 단면 : 단높이 **≤200**, 단너비 **≥240** | 주택기준 §16① |
| D3 | P1 | 옥외계단 유효폭 **≥900** | 〃 |
| H1~H3 | P1 | 손잡이 φ32~38 · h850 · 끝단 수평연장 ≥300 | 피난방화 §15④ |

> **R1 의 "그리고" 가 판정을 뒤집는다.** 조사 배경 문서는 scene05/14/21 을 광폭 중간난간
> 누락 사례로 지목했지만, 조문 단서를 **AND** 로 정확히 적용하면 **scene14(0.150/0.340)·
> scene20(0.150/0.340)·scene21(0.150/0.320)·C4(0.150/0.350)·scene01(0.150/0.380) 은 전부 면제**다.
> 실제로 R1 이 걸리는 것은 **riser 가 0.150 을 넘는 광폭 계단**(scene02·05·08·09·18) 뿐이다.
> 이 구분이 이 진단의 핵심 산출이며, `stair_kit.mid_rail_lines()` 가 유일한 판정 지점이다.

> **R2 의 임계는 "높이 1 m 초과" 다.** 옥외 riser 0.20 기준 **5단 이하**, 0.15 기준 **6단 이하**
> 계단은 난간 의무가 아예 없다. 무난간 씬을 정당화하는 근거이기도 하다
> (해당 조건을 만족하는 씬: scene01 낙차 0.60 — 난간 3선은 법정 의무가 아닌 **초과 설비**).

`SCENE_CONFIG` 기본값이 `cue_railing=False` 인 씬은 **기본 구성에 난간이 없는 것**으로 셌다.

## 4. ★ 계단참 도입이 **낙차 GT 를 바꾸는 씬** — 별도 보고 대상

중간난간·손잡이는 계단면 **위**에 서는 부재라 지형 z(x,y) 를 건드리지 않는다 → **GT 불변**.
계단참만이 z(x) 프로파일 자체를 바꾼다. 아래 **5 레코드**는 P0-L1 시정 시 낙차 라벨이
바뀌므로, 기존 낙차/뎁스 GT 캐시를 **반드시 재생성**해야 한다.

| 씬 | 현재 | `stair_landings()` 계획 | run 변화 | 참 상면 z | GT 영향 |
|---|---|---|---|---|---|
| **scene02 지하보도** | 20단 직통 −3.20 | 10 + **참** + 10 | 6.40 → **7.60** (+1.20) | −1.600 | 참 상면 = 국지 낙차 0 띠, 참 전연 = 잔여 낙차 −1.60 의 새 에지. 하단 광장·`landing`(x 6.4..7.0)·`stair_rail` x 전부 +1.20 이동 |
| **scene03 하천 호안계단** | 20단 직통 −3.20 | 10 + **참** + 10 | 7.00 → **8.20** (+1.20) | −1.600 | 계단 하단이 수면 쪽으로 1.20 m 더 나간다 → **수위선·물때 밴드 재산정 필요** |
| **scene06 나선 상행계단** | 26단 연속 나선 −4.99 | 13 + **참** + 13 | sweep 300° → **참 1개분 각도 추가** | −2.496 | 나선이라 참이 **부채꼴 참**이 된다. 각도 배분·기둥 위치·페시아 곡선 전부 재설계 — 5건 중 **작업량 최대** |
| **scene08 선큰광장** | 26단 직통 −4.50 | 13 + **참** + 13 | 7.80 → **9.00** (+1.20) | −2.249 | 남·북 2련 모두. 보울 폭이 1.20 m씩 커지므로 **하부 광장 평면 자체가 확장**된다 |
| **scene17 한강 램프-계단쌍** | 20단 직통 −3.20 | 10 + **참** + 10 | 6.40 → **7.60** (+1.20) | −1.600 | 대조 램프(길이 40.0)와의 **대비쌍 정렬이 깨진다** — 램프 기하도 함께 조정해야 쌍이 유지됨 |

**GT 가 바뀌지 않는 시정**(부재만 추가, 지형 불변):

- **R1 중간난간 추가** — scene02(1열) · scene08(1열) · scene09(**3열**) · scene18(2열) · [scene05 티어 8열, 유보]
- **R2 측면 난간 / 손잡이 추가** — scene03·04·08·09·12·14·15·17·18·19·21·C1·C2
- **손잡이 규격 전면 도입**(φ32~38 · h850 · 끝단 수평연장 ≥300) — 현재 33씬 전부 미구현.
  끝단 수평 연장 ≥300 은 **실루엣에서 눈에 띄는 한국적 특징**이므로 룩 개선 ROI 가 높고
  낙차 GT 는 전혀 건드리지 않는다 → **가장 먼저 착수할 항목**.

### 참고 — 계단참이 단코 실루엣을 파괴하지 않는 이유

`stair_landings()` 는 참 상면 z 를 **직전 flight 마지막 디딤면과 동일**하게 잡는다
(= 마지막 디딤면이 1.20 m 연장된 형태). 따라서 상류 단코 선의 z 사다리는 그대로 보존되고,
새로 생기는 것은 "긴 디딤면 1개 + 그 전연의 에지" 뿐이다. 이 연구의 핵심 단서인
**계단코 선의 주기적 반복 구조는 유지**되며, 참 구간에서만 주기가 1회 끊긴다.
`stair_kit.flight_nosing_lines()` 로 도입 전/후 에지 집합을 diff 해서 GT 변경 범위를 정량화할 수 있다.

## 5. `stair_kit.py` API 요약

| 함수 | 역할 | GT 영향 |
|---|---|---|
| `stair_landings(total_drop, riser, tread, max_rise=3.0, landing_depth=1.20)` | 순수 계산. flight/참 분할 계획(결정적, 난수 없음) | **변경** — run 연장 + 평지 띠 + 새 에지 |
| `build_stair_landing(stage, path, landing, y0, y1, base_z, mtl, add_box, ...)` | 계단참 판 생성(`add_box` 주입) | **변경** — 상면 낙차 0, 전연 새 에지 |
| `mid_rail_lines(y0, y1, max_span=3.0, riser=None, tread=None)` | 중간난간 y 리스트. **면제 = AND** | 불변 |
| `build_handrail(stage, prefix, y, x_top, run, drop, mtl, add_cylinder, ...)` | φ32~38 · h850 · 끝단 수평연장 ≥300 · 벽 이격 50 mm | 불변 |
| `check_stair_compliance(...)` | 위반 목록 dict (이 표의 생성기) | 무생성 |
| `flight_nosing_lines(plan)` | 단코 (x, z) 목록 — GT diff 검산용 | 무생성 |

- `scene_common` 을 import 하지 않는다. `add_box` / `add_cylinder` 는 **인자 주입**
  (scene_common 과 동일 시그니처).
- 좌표계 **Z-up · 단위 m**. 법령 mm/cm 값은 `stair_kit.K` 클래스에서 **1회만** 환산.
- `python stair_kit.py` 로 **USD/GPU 없이** 24개 검사 그룹 자기검사가 돈다.
