1. **렌더를 한 장도 보지 않았다.** "가짜로 읽힌다"의 판정은 사용자의 것이고, 이 문서는
   **그 판정과 코드 상태를 대조**했을 뿐이다. 화면 기여 추정은 전부 기하 산술이다.
2. **USD 에셋을 열어보지 않았다.** `pxr` 이 프로젝트 venv 에 없다(`process_spec` §2.7).
   에셋의 tri·치수·z 원점은 전부 `[매니페스트]` 인용이며 재검증하지 않았다.

   §4-14 에 따라 instance 수를 이유로 기각한 항목은 없다.
4. **fixqueue 라운드가 진행 중이다.** GT-64(S13 마스터플랜)·GT-67(S01 건물 재도입)이 OPEN 이므로
   13·01 의 건물 좌표는 이 문서 작성 시점 이후에 움직인다. 씬별 제안은 **좌표가 아니라 방식**이다.

## 4.2 진행 규칙

1. **§2.3 준수** — `scene_common`/`facade_kit`/`building_kit` 변경은 **1씬 렌더로 먼저 확인** 후 확산.
   §3.1 의 "파일럿 1씬" 열이 그 씬이다.
2. **A/B 는 같은 prim 끼리** — `sc.build_building` → `bk.build_korean_building` 전환은 prim ROOT 경로를
   유지해야 비교가 성립한다(`{ROOT}/Building_{key}` 불변).
3. **GT 선신고** — 건물 셸은 `collider=True` 다. 유형 전환은 **셸 치수를 바꾸지 않는 한** R-3 이지만,
   `kind` 변경이 셸을 2개로 쪼개는 경우(`build_mass` 의 setback)는 **collider 변경 선신고 대상**이다.
4. **LOOK_GEO=0 팔 불변** — 신규 기하는 전부 `LOOK_GEO` 게이트 안. 현행 `build_building` 은 이미
   `if not LOOK_GEO: return prims` 로 갈라져 있으므로 그 위치를 지킨다.
5. **§4-14** — 에셋 건물은 `instanceable=True` + `treatment` 래퍼가 전제(scene19 템플릿).
   instance 수를 이유로 기각하지 않는다.
6. **근거 태그 의무** — `[추정]`/`[근거 없음]` 항목은 구현 시 코드 주석에 그대로 남긴다.
