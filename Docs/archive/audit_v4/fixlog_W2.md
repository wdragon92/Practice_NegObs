### 태양 재선정의 계산 근거 (두 씬 공통)

`sc.setup_lighting` 은 DistantLight 에 rotZ(dome_rot + offset + 233.5) → rotX(90−elev) 를
건다. 결과 **태양 방향 단위벡터**(태양 쪽) = (cos az·cos el, sin az·cos el, sin el),
az = 33.5 + offset, el = 49.79° → 수평성분 0.6456 / 연직성분 0.7636.
면 법선 N 의 직사광 강도 = dot(N, L). 그림자 수평 변위 = 낙하고 × 0.8455.
**이 식으로 v6 의 두 암부 사망 원인이 그대로 재현된다**(아래 각 절 ①).

### ② "자연석이 벽돌 판석" 해소 (판정 §2 ⑤ 최우선)

원인 2겹을 분리해 잡았다.

1. **재질**: `stone_worn` = 정형 벽돌 + 몰탈 줄눈 텍스처. → **`rock_face`**(무줄눈
   자연암 diff/nor/rough)로 교체. `ASSET_ROLES` 에서 `stone_worn` 제거.
2. **월드 스페이스 투영**: `sc.make_pbr` 는 `project_uvw=True, world_or_object=True`
   라 **전 배석이 하나의 줄눈 격자를 공유**한다 → 돌 경계를 가로질러 줄눈이
   연속되어 "단일 타일이 박스에 매핑된" 인상(= 판정문 지적)이 나온다.
   → **돌별 재질 풀 8종**(`PARAMS["stone_mtl"]`, seed 7071):
   `texture_scale` U(0.55,1.35) m · `texture_rotate` U(0,360)° ·
   `texture_translate` U(−4,4)² · tint 지터 ±6 % · 3개마다 이끼 톤.
   `texture_rotate/translate` 는 OmniPBR.mdl 의 표준 입력(project_uvw=True 시 유효)
   이며, **scene_common 을 고치지 않고** 씬 로컬 `tex_xform()` 이 셰이더에 입력만
   추가한다. `bump_factor` 1.0 → **1.5**(요철 강화).
3. **직사각 실루엣**: 돌마다 **캔트 노브** 1개(`PARAMS["knob"]`, seed 7072) —
   주석과 다른 yaw(±10~20°)·tilt(±3~9°)를 가진 부속 덩어리를 Y 로 0.33·w 밀어
   윤곽을 깬다.
   - **GT 불변 검산**: 노브 최고점 = top + (dy/2)·sin|rx| 로 계산하고 주석 상면과의
     여유 min **+0.0287 m > 0** → 보행면(배석 상면)은 그대로. drop 하한을 0.050 으로
     둔 것이 이 여유의 근거.
   - **간격 불변 검산**: 회전 후 X 반폭 − 돌 깊이/2 = 최대 **+0.0145 m ≤ 0.02** →
     인접 돌과의 간격(min 0.050 m) 구조 유지.
   - 노브 하면−회랑면 최대 **−0.135 m**(전량 매입 = 부유 0).
