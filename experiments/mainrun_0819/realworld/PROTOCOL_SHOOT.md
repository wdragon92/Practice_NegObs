# PROTOCOL_SHOOT.md — 실사 촬영 프로토콜 (negative obstacle / hidden drop)

## ① 목적 / 원칙
- 모델은 Isaac Sim 합성 데이터로만 학습함. **이 사진들은 학습용이 아니라 sim-to-real 평가용.**
- 위험 정의: 깊이 **0.3 m 이상 하강**(하행 계단·제방·승강장 엣지·도랑). **연석 0.10–0.25 m 는 위험 아님** → 하드 네거티브로 일부러 찍는다.
- **하행 계단 최우선**(학습 도메인 일치). 그 외 유형은 전부 `탐색(exploratory)` 라벨 — 성능이 낮게 나와도 실패로 보지 않음.
- sim에 사람·차량이 없으므로 **한산한 시간대**를 고른다. **주간 전용.**
- 진행 순서: **파일럿 20장 → 훈련 완료 모델 통과 → 신호 확인 → 본 촬영.** 파일럿 없이 본 촬영 들어가지 말 것.

## ② 장비 / 설정
- 스마트폰 **후면 메인 렌즈, 가로(landscape) 고정**. 초광각·망원·디지털 줌 금지(sim 화각 밖).
- **노출은 자동(AE/AWB) 그대로 둔다. 수동 고정 노출 금지.** 화면 탭으로 AE/AF-Lock이 걸렸으면 해제. HDR·야간모드·미화(beauty) 필터는 끈다.
- **EXIF 유지**: 원본 그대로 보관. 편집앱·메신저(카톡 등) 경유 전송 금지(리사이즈/회전/EXIF 삭제됨). PC로는 **케이블 또는 "원본 보내기"** 로만 옮긴다. 크롭·회전 금지.
- 해상도: 최대 해상도, **긴 변 최소 1920 px**. 촬영 시작부터 끝까지 같은 설정 유지.
- **카메라 높이 1.5–1.8 m**(눈높이). 매 부지 첫 장에 실제 높이를 재서 기록.
- 피치 **−15°~+5°**: 수평보다 살짝 아래까지만. 계단을 위에서 내려다보듯 크게 숙이지 말 것.
- 보조: 레이저 거리계(있으면), 줄자 1개, 기록용 노트/폰 메모.

## ③ 부지 선정 기준
- **1순위 — 하행 계단**: 선큰광장, 지하보도 입구, 지하철 출입구, 건물 외부 계단. **전체 부지의 절반 이상**을 여기서 채운다.
- **2순위 — 유형 다양성**(각 1–2 부지, 전부 `탐색` 라벨): 제방, 승강장 엣지, 도랑/배수로, 하역장.
- 한 부지의 조건: **V·E·H 세 지점을 실제로 걸어서 확보 가능**할 것. 접근 경로가 하나뿐이라 후퇴/우회가 안 되면 부지로 부적합.
- **안전 우선: 난간·펜스 밖으로 절대 넘어가지 않는다.** 엣지에서 최소 1 m 이격. 승강장은 황색 안전선 안쪽에서만.
- 통행 방해 금지. 삼각대 없이 손으로 들고 촬영.

## ④ 부지당 촬영 절차 (V → E → H)
1. **V 지점** — 위험 내부(계단면·바닥면)가 보이는 **가장 가까운 안전 지점**에 선다. 3–5장(좌우·거리 살짝씩 변화).
2. **E 지점** — 뒤로 물러나거나 옆으로 이동해서 **내부는 안 보이고 지면이 꺾이는 엣지선(rim)만** 보이는 지점. 3–5장.
3. **H 지점** — 더 후퇴하거나 가림물(펜스·식재·벽·지형 마루) 뒤로 이동해 **위험이 픽셀로 전혀 안 나오는** 지점. 3–5장.
   - H에서는 **컨텍스트 단서가 프레임에 반드시 들어가야 함**: 난간 라인, 지형 꺾임, 경고 표지, 눈높이 아래로 잘린 식생 상단.
4. **무위험 대조 프레임** — 같은 부지에서 **몸만 돌려** 위험이 전혀 없는 방향으로 2–3장. 조명·재질·시간대가 같아야 대조의 의미가 있음.
5. 매 장 촬영 직후 sites.csv 한 행씩 기록(나중에 몰아서 쓰면 거리·방위를 못 맞춘다).

**티어 판정은 V → E → H 계층 순서**로 한다: 내부가 조금이라도 보이면 무조건 **V**, 아니면 엣지선이 보이면 **E**, 둘 다 아니면 **H**.

**거리 기록법** (우선순위 순, 쓴 방법을 notes에 적을 것)
- (a) 레이저 거리계로 카메라→엣지 실측
- (b) **보폭**: 촬영 전에 10 m를 몇 걸음인지 미리 재두고 환산 (예: 14보 = 10 m)
- (c) 지도(카카오맵/네이버지도 거리재기)로 사후 검증 — 큰 부지에서만

## ⑤ 기록 규약
**sites.csv 필드** (`realworld/sites.csv`, 예시 12행은 `EX_` 접두사 — 실제 촬영 때는 지우고 새로 부여)

| 필드 | 의미 |
|---|---|
| `site_id` | 부지 식별자 (예: `SUNKEN01`). 같은 부지의 V/E/H는 **같은 site_id**로 여러 행 |
| `type` | `descending_stairs` / `embankment` / `platform_edge` / `ditch` / `loading_dock` / `curb_only` / `none` |
| `dist_m` | 카메라 → 위험 엣지 **수평 거리**(m). 대조 프레임은 `na` |
| `azimuth` | 광축 기준 각도(deg), **왼쪽 음수 / 오른쪽 양수**. 대조는 `na` |
| `cam_height_m` | 지면~렌즈 높이(m), 1.5–1.8 |
| `gt_cells` | 정답 셀, 세미콜론 구분 (예 `A2;B2`). 위험 없으면 `none` |
| `tier` | `V` / `E` / `H` / `N`(무위험 대조) |
| `notes` | 자유 기술. **쉼표 절대 금지**(CSV 깨짐) — 구분은 ` / ` 로. 탐색 유형이면 `탐색` 명시 |

**셀 명명 규약 — ⚠ 잠정(PROVISIONAL). 레포의 실제 grid 상수가 확정되면 그 값으로 교체할 것.**
- 방위 **A–E**: 프레임을 세로로 **5등분, 왼쪽부터 A B C D E** (A = 화면 맨 왼쪽)
- 거리 **1–3**: `1` = 0–3 m(근), `2` = 3–7 m(중), `3` = 7–15 m(원)
- 셀 = 방위+거리 → `A1`…`E3`, 총 **15칸**
- 개구부가 두 섹터에 걸치면 **둘 다** 기록 (`B2;C2`). 두 밴드에 걸쳐도 동일 (`C1;C2`).

**파일명 규약**: `site_id__tier__idx.jpg` (언더바 **2개**, idx는 두 자리)
- 예: `SUNKEN01__V__03.jpg`, `SUNKEN01__H__01.jpg`, `CTRL08__N__02.jpg`
- 원본은 `raw/`에 손대지 말고 그대로, 리네임한 사본만 `frames/`에 둔다.

## ⑥ 파일럿 20장 절차
- 구성: **V 5장 / E 5장 / H 5장 / 무위험 대조 5장 = 20장**. 최소 2개 부지, **하행 계단 부지를 반드시 포함**.
- 촬영 즉시 sites.csv 20행을 채우고 **훈련 완료 모델에 그대로 통과**시킨다(리사이즈·크롭 없이).
- **본 촬영 진행 판단 기준**
  - **(a) 핵심** — 무위험 대조 프레임의 예측값이 위험 프레임보다 **눈에 띄게 낮은가?** 이게 sim-to-real 신호의 최소 조건.
  - (b) V 프레임에서 정답 셀 **부근**(같은 섹터 ±1, 같은 밴드 ±1)에 반응이 뜨는가? 정확히 그 셀일 필요는 없음.
  - (c) 반응 세기가 **V ≥ E ≥ H** 경향을 보이는가? **H에서 반응이 0이어도 실패 아님**(원래 어려운 조건).
- **(a)가 안 보이면 본 촬영을 중단하고 보고**할 것. 사진을 더 찍는다고 해결되는 문제가 아니라 모델/도메인 쪽 문제임.

## ⑦ 안전 / 법규
- **야간 촬영 금지** — 이 연구 스코프는 **주간 전용**(sim도 주간만 렌더).
- **사유지 무단 진입 금지**: 아파트 단지 내부, 상가 지하, 공사장. 관리자가 있으면 먼저 물어볼 것.
- **촬영 제한 구역**: 군사·보안시설 금지. 지하철 역사·승강장은 촬영을 제한하는 역이 있으므로 **역무원 안내에 따를 것**.
- **인물이 식별되는 프레임은 피한다.** 들어갔으면 삭제 후 재촬영(초상권 + sim 도메인 불일치).
- 차도·철도 궤도 진입 금지. **우천·결빙 시 계단 촬영 금지**(미끄러짐).
- 가능하면 2인 1조. 조금이라도 위험하면 그 부지는 포기한다 — **데이터보다 안전이 우선.**
