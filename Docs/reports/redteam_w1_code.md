| (없음) | 없음 ✓ | — |

### 2.6 독립 스윕이 찾은 잔여 구멍 2건 (평결을 뒤집지 않는 이유 포함)

**A. perfloor × 1층 건물 = 관통 재발 경로가 남아 있다.**
`_attachments` 의 1층 제외는 `len(levels) > 2` 일 때만 작동한다. floors=1 이면
levels 길이 2 → 미발동 → fk 가 옥상만 떼고 1층에 실외기 → **AcPipe 하단
base_z − 0.550** 재현 [실측]:

```
bd kind="villa"·floors=1·d14         → 최저 −0.550 (/AcPipe_0)
bd ac_mode="perfloor"(화이트리스트)·1층 → 최저 −0.550 (kind=low_shop)
```

추론(infer_kind)은 1층을 low_shop(eaves)으로 보내므로 **명시적 bd 덮어쓰기로만
도달**하고, 씬 통합 자체가 아직 0건이다. 다만 `_BD_SWITCHES` 가 `ac_mode` 를
노출하므로 "지반 아래는 ShopStep 뿐" 은 **현실 층수 격자 안에서만 참**이다.
→ 인계: perfloor 에서 `len(lv) <= 2` 면 실외기 생략(또는 eaves 폴백)이 안전하다.

**B. eaves 실외기 상단이 low_shop 간판 밴드를 관통한다 — 주석의 산술 오류.**
`eaves_z = base_z + clamp(ground_h−1.30, 1.60, 2.30)` 의 근거 주석은 "실외기
상단(+0.55)이 간판 밴드 하단(ground_h−0.85)을 넘지 않게" 라고 적었는데, 그
계산이면 상단 = ground_h−0.75 로 **인용한 그 밴드보다 0.10 위**다. −1.30 이
지키는 것은 shop_house 밴드(ground_h−0.70, 지터 포함 0.70+0.594≈1.294)뿐이다.
실측 [실측]:

```
low_shop 단층 H=3.0/3.2/3.4/3.6 → AcUnit–SignBand z겹침 0.059~0.135 m (각 2대)
H=3.74 부터 겹침 0 · shop_house 는 전 스윕에서 겹침 0
```

수정 전(eaves_z=2.30 절대)에는 같은 사례의 겹침이 ~0.30 m 로 **더 컸다** —
즉 회귀가 아니라 불완전한 개선이고, 지반 관통(이번 수정 대상)과는 별개 축이다.
→ 인계: 상수를 1.45(= 0.85+0.594)로 내리거나 밴드 하단을 유형별로 받는다.
