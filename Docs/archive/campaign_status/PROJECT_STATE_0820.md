## 0. 한 줄 요약
RGB 맥락 단서(난간·점자블록·그림자 등)만으로 **완전히 가려진 낙차(negative obstacle)** 를
예측할 수 있음을 보이는 논문. **제36회 AISP(9/17–18, 고려대), 마감 8/30, 실험 동결 8/24.**
1저자 승용(경북대 K-VIS Lab URP), 지도 이종택 교수님.

## 1. 과제 정식화 (확정 — 재논의 금지 축)
- **출력**: 카메라 전방 폴라 위험 그리드. **V1 = 5섹터(±31.1°) × 4밴드 [0,2)/[2,5)/[5,8)/[8,12)m
  = 20칸** (8/20 교수 피드백 "셀이 너무 넓다"로 V0 15칸의 원거리 밴드를 2분할 — V0에 중첩).
- **위험 정의**: 깊이 ≥0.3m 낙차(4도메인 삼각검증: 건축·NWS·Spot·UGV). 연석(10–25cm) 비위험.
- **V/E/H 티어** (증거의 '출처' 기준, 프레임 속성): V=낙차 내부면 픽셀 가시 / E=내부면 없이
  개구 경계(림)만 가시 / **H=낙차 기여 픽셀 전무, 맥락 단서만** ← 연구의 핵심 대상.
  strict-H(기여 픽셀 0)는 문턱 무민감(9조합 불변) 검증됨.
- **헤드라인**: H recall + 오경보율(FA, hazard-off 트윈으로 측정) + 트윈 인과 Δ. 세트로만 인용.
- **데이터**: Isaac Sim 33씬(계단 21 + batch1 12, 하드네거티브 포함) × 조명 3 × 캠 8 ×
  **hazard on/off 트윈**(seed 고정, 카메라 포즈 바이트 동일) = 1584컷 + depth·높이맵 사이드카.
  HOLD 4씬(D4·11·13·19) 제외 → 유효 29씬 1392프레임. 티어: V438·E36·H45.
- **분리**: 씬 단위 + 같은 씬의 모든 토글 변형 동반(누수 방지 제1원칙). test 7씬(s14 강제
  포함 — H 최다), test 불가침.

## 2. 어젯밤(8/19→20) 야간 자율 사이클 결과 — v1 실험
Claude Code가 밤새 자율 수행(브리프 OVERNIGHT_BRIEF_0819_v3 체제): 데이터 전체 신규 렌더,
라벨러 3세대(v0→v2: 경사 씬 가짜 양성 74,793셀→0), 분리, RGB/Depth U-Net 훈련·평가 완료.

| 모델(seed42, V0 그리드, τ0.5) | V | E | **H** | FA↓ | 비고 |
|---|---|---|---|---|---|
| RGB U-Net | 0.667 | 0.444 | **0.333** | 0.274 | ⚠선택 실패 정황(아래) |
| Depth U-Net(클린 depth) | 0.919 | 0.333 | **0.714** | 0.161 | 이상적 상한 |

- **가장 깨끗한 증거 = 트윈 인과**: 같은 자리에서 위험만 제거 시 확률 하락 Δ — RGB 0.348,
  **H 티어 한정 0.240(CI 0.156–0.331, 0 제외)**. 낙차 픽셀이 양팔 어디에도 없는데 반응이
  떨어짐 = 맥락 사용의 인과 증명. (캐비앗: N3 장식 동반 토글에도 0.252 반응 — 논문에 병기.)
- **RGB 숫자는 아직 하한**: val에 H가 0장이라 체크포인트 선택이 H에 눈멂 → seed43에서
  H 0.048로 붕괴(시드 불안정). 이건 모델 한계가 아니라 **선택 설계 결함**으로 진단됨.
- **band3 사전확률 문제**(승용 발견): 원거리 밴드가 증거 없이 상시 발화 경향(오경보 4장 전부
  sceneC2에 0.98 확신, s14 히트도 먼 밴드 한 줄 전체). 메커니즘 = 셀 BCE의 한계 양성률 후퇴
  + 원거리 단서 픽셀 최소 + (가설) 0.3m 심각도 혼동. → v2 처방의 표적.

## 3. 오늘(8/20) 결정 사항과 진행 중 작업
**교수 미팅 반영** (승용·Claude 합의된 해석):
- 픽셀 vs 그리드 → **"dense하게 배우고 coarse하게 답한다"**: 출력·평가는 그리드 유지
  (H의 픽셀 GT는 amodal이라 부적절 + 실측 평가 가능성 + det/seg 공통 화폐), 학습 신호로
  amodal 픽셀 마스크를 aux 손실로 흡수.
- **YOLOv8n 부활**: 본 표 4행째(재학습 기반, 검출→셀 매핑 명문화). H 구조적 0이 예상 결과.
- **발전 서사 채택**: v1 진단→v2 수정→결과를 논문의 한 단락으로.
- **E 제2 기둥 승격**(승용 제안 흡수): 단 헤드라인은 H 유지 — E 중심 전환은 novelty 공백
  주장·YOLO 비교 구도·서론 재료를 무너뜨려 기각. E는 test 9프레임뿐이라 보강 렌더로 30+ 목표.

**Claude Code 실행 중 (DAYRUN_BRIEF_0820)**: 그리드 V1 재라벨(티어 불변 검증 게이트) →
E/H 보강 렌더(양팔) → 진단 3종(사전확률 히트맵·밴드별 트윈 Δ·C2 분해) → **레시피 v2 재훈련**
(val에 H 씬 이동 + 선택지표에 val H recall + strict-H 오버샘플 ×4 + bias 사전확률 초기화 +
hflip 섹터순열, 3모델 × 3시드) → YOLO 트랙 → aux 1런 → 교수 브리핑 1p → 파일럿 추론 도구.

**승용 몫**: 캠퍼스 실측 파일럿 20장(하행 계단 우선, 높이 1.5–1.8m, `realworld/PROTOCOL_SHOOT.md`)
→ 본촬영은 파일럿 신호 확인 후. DAYRUN_REPORT의 승인 대기 일괄란 결재. 유리 씬(s06·08·12)·
C2 육안 확인.

## 4. 논문 골격 (합의된 형태)
- 서론: 캠페인 소거법 사슬(기성 모델은 가려진 위험을 안전한 바닥으로 확신 → 감독으로 설치
  가능(53배) → 인공 패치는 진짜 가림에 전이 실패 → ∴ 진짜 폐색 기하 + 가려진 GT = 합성 씬).
  probe 수치(낙차 0.2–0.6% vs 단서 21%, 트롱프뢰유 5.4%) 인용 — 전량 CITATIONS.md에 출처 검증됨.
- 방법: 트윈 합성 감독, V1 그리드, V/E/H 층화, 0.3m.
- 실험: 4행(RGB U-Net·Depth U-Net·B2·YOLOv8n) × V/E/H recall + FA, 다중 시드 평균±범위,
  트윈 Δ 표, 스펙트럼 서사(V→E→H에서 각 방법의 퇴화), 발전 서사 단락, 실측 정성(파일럿).
- 한계(정직 항목): H는 기존 씬 카메라 보강이라 씬 다양성 한정 / Depth는 클린 시뮬 상한 /
  N3 장식 반응 / 낙차 유형 4종(HOLD) 시험 부재 / PROVISIONAL 상수들(그리드 V1·τ·±0.35m 등).
