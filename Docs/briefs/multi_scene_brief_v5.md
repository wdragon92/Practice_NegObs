## 공통 레이어 (감독 인프라 — 구현 씬은 사용만)

- `sc.build_sign(stage, prefix, cx, cy, base_z, yaw, tex_key, w, h, pole_h)` — 한글 사인
  패널(텍스처 = assets/signs/*.png, TEX 등록: sign_warn_fall("추락주의")·sign_exit("출구")·
  sign_info("안내")·sign_caution_step("계단주의")·sign_no_entry("진입금지")).
  경고판은 낙차 인접 배치 → 설비 역추론 단서(계열①).
- TEX `paving_interlock`(인터로킹 보도블록) — 도시 보도면 표준 재질.
- cue_tactile: 도시 관행 씬은 기본 True(01/02/05/13/14/16/20/21 + 신규 R1/R3/R6).
  비관행(산사/공원 흙길/수변 데크)은 False 유지.

## R1. scene06_overpass_spiral — 보행육교 나선 진입 계단 (구 나선석탑 교체)

- 무대: 왕복 4차로 교차부 보행육교의 원형 나선 진입부. 육교 데크(z=+5.0, 폭 3,
  x −20..20) + 나선 계단(helix_steps r_in 1.5/r_out 3.3, 300°, 26단, riser 0.192,
  중앙 기둥 r0.5) + 지상 보도(z=0, 인터로킹) + 차도(아스팔트 0.045, 차선, 연석 0.15).
- 위험: 나선 외측 난간(파이프)이 상부 90° 구간에서 **탈락**(포스트만 잔존) — 개방 에지
  4.2m 낙차. 지상 grazing 시 나선 하강이 원통 실루엣에 은닉.
- cue: railing(훼손 변주), tactile(진입부), sign_caution_step. 태양 171.5 기본.
- 카메라: 지상 접근 그리드(+X축) + spiral_up(내부 상행) + deck_entry(데크에서 진입) +
  broken_rail(훼손 구간 클로즈) + overview.

## R2. scene07_temple_stone_path — 산사 자연석 듬성 계단 (구 사원 마모석 교체)

- 무대: 산사 진입 산길. **자연석 배석 계단**: 큰 판석(0.5~1.1m 불규칙 폭, 두께 0.12~
  0.25)이 사면(경사 ~20°)에 듬성듬성 박혀 계단 대용 — 돌 간 간격 0.05~0.35 불균일,
  상면 요철(rz 랜덤 ±4°), 사이는 흙/낙엽(leaf_ground 재질). 총 상승 ~4m, 22~26석.
  worn_stone 빌더를 "이산 배석 모드"로 개조(돌별 개별 박스, seed 고정 랜덤).
- 드레싱: 일주문(기둥 2+맞배지붕), 석등 2, 돌담(낮은 석축) 양측, 소나무 4~6, 상부에
  법당 실루엣(기단+기둥열+지붕), sign_info(사찰 안내). 태양 0(정면 관람).
- 위험: 배석 간격/단차 불균일(디딤 리듬 파괴) + 측방 사면 낙차 1.5~2m 무방호 + 낙엽이
  돌 에지 부분 가림. GT: 배석 경로 외 사면 낙차 양성.
- 카메라: 하부 접근 그리드 + stone_rhythm(배석 클로즈) + gate_frame(일주문 프레이밍) +
  side_slope(측방 낙차).

## R3. scene08_sunken_plaza — 도심 선큰 광장 (구 스텝웰 교체)

- 무대: 지하상가/지하철 연결 선큰 가든. 상부 보행 광장(인터로킹, 40×30) 중앙에
  12×9 사각 피트(깊이 4.5 = 지하 1.5층), 남·북 양측 광폭 계단(폭 4, 26단 riser 0.173)
  하강, 피트 바닥은 화단 2 + 벤치 + 지하상가 유리 파사드(발광 약). 개구 4박스 분할.
- 위험: 상부 grazing 시 피트 은닉(스텝웰의 강점 계승). 동측 에지는 화단 뒤 파라펫
  **부분 개방**(1.8m 구간 공사 철거 — 임시 표지만) → 무방호 낙차. sign_warn_fall.
- cue: tactile(개구 둘레), railing(파라펫+개방 변주). 태양 60(사광 유지 — 피트 내
  명암 대비). PT 판정 필수(피트 하부).
- 카메라: 상부 그리드 + pit_edge + underground_look(피트 바닥에서 올려봄) +
  open_gap(개방 구간).

- 무대: 왕복 6차로 위 보도육교. 철제 계단 2련(폭 1.8, 22단×2, 중간참, 그레이팅 디딤 —

## R7. scene12_riverside_deck — 한강 수변 캔틸레버 데크길 (구 절벽 잔도 교체)

- 무대: 한강/하천 수변 목재 데크 산책로(scene17 세계관 공유 — 재질·수면·아파트 원경
  재사용). 데크(폭 2.5, 목판, z=0)가 호안 위 캔틸레버(수면 −1.8 위로 1.2m 내밈) +
  접속 계단(데크→둔치 잔디, 8단) + 호안 사석(rock 박스 잡석).
- 위험: 데크 에지 난간이 **한 스팬(2.4m) 훼손**(수리 테이프 표시 = sign 변주) + 난간
  하부 킥플레이트 부재(로봇 시점 수면 직행) + 데크 끝 계단 하강이 grazing 은닉.
- 드레싱: 갈대·억새, 벤치 2, 가로등 2, 자전거도로 인접(아스팔트 밴드), 원경 교량
  실루엣(scene17 bridge 재사용), sign_warn_fall(훼손 스팬).
- 카메라: 데크 종주 그리드(+X) + edge_void(에지 너머 수면) + broken_span + stair_join.
