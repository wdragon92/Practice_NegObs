## scene14_grandstair_illusion.py — 헌치 봉합 + 깃대 이설

### ① 헌치 이음부 쐐기 슬릿 — **원인 재규명 후 봉합**

판정은 원인을 "확폭(3.0→5.0)으로 참마다 헌치가 ±Y 로 조그(jog)"로 추정했으나
**그 기전은 이 씬에 없다**. 파라펫 밴드 y 는 `yb = w_bot + 0.05 = 5.05`, `+width 0.5` 로
전 구간 상수여서 Y 조그가 발생하지 않는다.

실제 원인은 `sc.build_slope` 회전 박스의 **끝면이 사면에 수직**이라는 점이다.
상면 길이 = `hypot(run, drop) + margin` 이므로 끝면 상단 모서리는 margin/2 만큼
내리막으로 튀어나오고, 두께 `cap_t` 를 따라 내려가면서 오르막으로 후퇴한다:

```
ang     = atan(0.15/0.34) = 23.806°   sin 0.4036   cos 0.9149
후퇴량  = cap_t·sin(ang) − (margin/2)·cos(ang)
        = 1.4×0.4036 − 0.03×0.9149 = 0.5651 − 0.0274 = 0.5376 m
```

참 헌치 박스는 정확히 x_b 부터 시작(수직 끝면)하므로 x ∈ [x_b − 0.538, x_b] 구간의
끝면 아래가 비어, 본체 상면(z_step − 0.03)까지 최대 0.9 m 높이의 **삼각 공동**이 남았다.
fixlog_VC 의 "이음부 Δz = 0.0" 검산은 **상면 z 만** 본 것이라 이 평면 방향 공백을
잡지 못했다(= 판정이 본 3~6 px 어두운 쐐기).

**봉합(판정 수정안 ①: 평면 오버랩)**

```python
_ang = math.atan2(st["riser"], st["tread"])
lap  = pa["cap_t"] * math.sin(_ang) + 0.15      # 0.7151 m  (> 필요분 0.5376)
```
참 헌치 박스를 오르막으로 `lap` 연장(`x_a2 = xa − lap`). 검산 2건:

- **매몰성** : 같은 x 에서 사선 상면은 `z_a + rail_h + (x_a − x)·tan(ang)` 로 연장부
  상면(`z_a + rail_h`)보다 항상 높다 → 연장부는 실루엣을 만들지 않는다.
- **두께 여유** : `lap·tan(ang) = 0.3155 < cap_t/cos(ang) = 1.5302` → 연장부 상면이
  사선 슬래브 밑면보다 위 = 슬래브 내부에 완전히 들어간다.
- 연장부의 ±Y 면은 사선 슬래브의 ±Y 면과 **동일 평면·동일 법선·동일 재질**이라
  Z 파이팅이 나도 음영 차 0.

실제 연장 시작점(모두 직전 사선 구간 안):

| 참 | 참 x 범위 | 연장 시작 x | 직전 사선 x 범위 |
|---|---|---|---|
| 1 | 3.400 ~ 5.800 | 2.685 | 0.000 ~ 3.400 ✓ |
| 2 | 9.200 ~ 11.600 | 8.485 | 5.800 ~ 9.200 ✓ |
| 3 | 15.000 ~ 17.400 | 14.285 | 11.600 ~ 15.000 ✓ |

반대쪽(참 → 사선) 이음부는 사선의 오르막 끝이 참 박스 안으로
`cap_t·sin + (margin/2)·cos = 0.594 m` 파고들어 **원래부터 공백이 없다**(무수정).

**폴리라인 양 끝**도 같은 결함이라 함께 봉합했다(신규 프림 2×2):
- `ParapetNewel_{N,S}` — 머리 끝(x −0.716..0, top z 0.95, bottom −0.30 = 테라스 매입).
  판정 [잔여] "terrace_read 좌·우 하단 헌치 끝단 백색 삼각 매스"가 이 쐐기였다.
  → **엄지기둥(端柱)** 직육면체로 대체. 상면이 사선 상단과 정확히 일치.
- `ParapetEndCap_{N,S}` — 발치 끝(x 20.084..20.800, top z −5.05) 수직 마구리.
  x 20.084 에서 사선 상면은 −4.734 로 마구리 상면(−5.05)보다 위 → 매몰 ✓.

둘 다 |y| ∈ [5.05, 5.55] = 계단 폭(w_bot 5.0) **밖** → 계단·참 트랜스폼 불변,
`terrace_read` 착시 무영향(엄지기둥은 eye(−4,0,0.9) 기준 방위 ±55.5° 로 화각 밖).
