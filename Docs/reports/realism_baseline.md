## 1. 측정 도구 — 재현성 검증 완료

모드·T1 게이트 자동판정을 추가한 것이다. 의존성은 numpy + PIL 뿐.

**동일성 확인**: 실사 레퍼런스 2장에 대해 조사 보고서
`00_supervisor_direct_diagnosis.md` 의 기록치와 **소수점까지 일치**했다.

| 지표 | 00 보고서 기록 | 본 도구 재측정 | 판정 |

| slope | −2.10 | **−2.10** | 일치 |
| flat% | 3.9 | **3.9** | 일치 |
| sat_mu | 0.158 | **0.158** | 일치 |

## 3. 지시서와 다르게 한 것 (승인 요청)

**브리프 Phase 0-3은 "3씬을 PT *수정* 설정으로 렌더해 기준선을 잡으라"고 하지만,
PT 수정 설정은 Phase 1-6에서 비로소 확정된다** — 순환이다.

해소: 기준선을 **기존 최종 PT 렌더**(scene01 `v7_pt` / scene07 `v8_pt`)로 잡았다.

- 근거 ①: 이것이 실제로 "21/21 합격" 판정을 받은 산출물이고, 6팀 조사가 측정한
  바로 그 이미지다. 기준선이 조사 결론과 같은 대상을 가리켜야 한다.
- 근거 ②: GPU 3씬 × PT 512spp 재렌더를 절약(약 15분).
- **부채**: Phase 1-6에서 PT 수정 설정이 확정되면, 그 설정으로 같은 3씬을 다시
  측정해 **기준선 수치가 재현되는지 확인해야 한다**. 재현되지 않으면 게이트 비교가
  설정 차이에 오염되므로, 그때는 수정 설정 기준으로 기준선을 재작성한다.
  → Phase 1 보고에 이 검산 결과를 포함한다.

## 4. 기준선에서 즉시 나온 발견 3건

### 4.1 채도 전역 하향(Phase 2-9)은 **그대로 적용하면 안 된다**

scene01 의 `sat_mu` 는 이미 **0.146** 으로 목표 하한(0.15) *아래*다.
과채도는 전역 현상이 아니라 **석재·자연물 계열의 국소 현상**이다(07: 0.320, D3: 0.306).

| 씬 | sat_mu | 목표 대비 |
|---|---|---|
| scene01 (인공 포장·유리·금속) | 0.146 | **이미 하한 미달 — 더 내리면 탈색** |
| scene07 (석재·수목·흙) | 0.320 | 1.5배 초과 |
| sceneD3 (아스팔트·잔디·측구) | 0.306 | 1.4배 초과 |

**처방 수정**: 전역 채도 계수 대신 **역할별 캘리브레이션**으로 간다. 대상은 초목·
흙·석재 계열이고, scene01 계열은 손대지 않거나 오히려 chroma 변동(chroma_sd)을
키우는 방향이다. 이 항목은 Phase 2 에서 재설계한다.

### 4.2 `grad_k`(그래디언트 첨도)가 그레이박스 지문을 가장 선명하게 짚는다

렌더 **19.3** vs 실사 **11.9**. 방향이 중요하다 — 우리가 실사보다 **더 heavy-tail** 이다.
= "대부분 완전 평탄 + 가끔 아주 날카로운 에지". 프리미티브 블록아웃의 정확한 서명이다.
flat% 와 독립적으로 움직일 수 있으므로 **보조 지표로 계속 추적**한다.
(T1 게이트 항목에는 넣지 않는다 — ZZ 가 정한 3항목을 유지.)

### 4.3 `ori_axis`(축정렬 에지 비율)는 이 표본에서 **판별력이 없다** — 추적 중단 권고

| | 값 |
|---|---|
| scene01 | 0.331 |
| 실사 | 0.332 |
| scene07 / D3 | 0.224 / 0.236 (실사보다 **낮음**) |

ZZ §1이 인용한 "본편 축정렬 에지 0.407 vs TerrainGen 0.127"과 부합하지 않는다.
원인 [추정]: 실사 레퍼런스 2장이 건축물 위주라 축정렬 에지가 원래 많고, 표본 n=2 라
분산이 크다. **이 지표로 개선을 주장하지 않는다.** 실사 표본을 확대하기 전까지 보류.

## 5. 실사 레퍼런스 표본의 한계 (명시)

실사 그룹은 **n=2** (`Docs/reference_photos/`) 다. 게이트 기준치 자체는 ZZ §6이
정한 고정값(flat<8 / slope −2.0~−2.2 / sat 0.15~0.22)을 쓰므로 판정은 유효하지만,
**실사 쪽 수치를 "한국 보행환경의 참값"으로 인용해서는 안 된다.**

- E팀 독립 측정(n=36)의 slope 는 **−1.94** 로 여기 −2.10 과 다르다 → 실사 분산이 크다.
- 향후 실사 표본 확대 시 후보: SANPO(Google, CC-BY 4.0 — `curb`/`stairs`/`hand rail`
  주석 보유 [ZZ §10.7]), Wikimedia, Mapillary. 로드뷰 3사는 약관상 불가.
- 표본 확대는 이 지시서 범위 밖(브리프 서두 "다음 일") — 여기서는 한계만 기록한다.
