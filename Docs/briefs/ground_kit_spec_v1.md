## 0. 결론 — W2 가 먼저 알아야 할 5가지

1. **★ 차단 항목이 하나 있고, W1 이 낸 수치가 틀렸다.** `_ground_skin`(룩 레이어)이 flush 지면
   요소를 묻는다는 진단은 맞다. 그러나 특수조가 계산한 스킨 최고점 **+21.5 mm 는 과대**다 —
   변위 노이즈가 `rng.random()−0.5` 라 진폭이 `±0.5·amp_m` 이고, 옥타브 필터(`_wl_min =
   spacing×2.5 = 0.30 m`)가 0.19·0.07 m 옥타브를 전부 잘라 **1옥타브만 남는다**.
   실제 최고점 = `0.0115 + 0.5×0.010` = **+16.5 mm** `[실측 — scene_common.py:820-841]`.
2. **그래서 `GROUND_PROUD_FLOOR = 22.5 mm` 로 전 요소를 띄우는 처방(특수조 A안)을 채택하지
   않는다.** 그 안에서는 **음각 요소(줄눈·균열·세굴 홈)를 원리적으로 만들 수 없고**,
   양각 22.5 mm 짜리 줄눈은 d=2 m 에서 세로면이 **15 px** 로 서서 "포장 위 융기 격자"로 읽힌다
   `[계산 — 0.0225×f/2, f=1662.77]`. 채택안은 **P-A: 대상 슬래브의 스킨을 끈다**(§1).
3. **채워야 할 곳은 카메라 앞 0.56~2.00 m 띠 하나다** — h0.3 프레임 세로의 **53.9 %**
   `[계산 — §2.2, 3개 조사 독립 수렴]`. 요소를 x ≥ 0(위험 기하 주변)에 두면 프레임 상위 8 %
   에만 걸린다. `sceneN2` 가 요소 9종을 갖고도 σ_LF 1.36 인 정확한 기전이다 `[실측]`.
4. **ground_kit 은 "새 요소 라이브러리"가 아니라 "씬 유형 프로파일 → 기존 빌더 배치
   오케스트레이터 + 신규 소빌더"다.** `infra_kit` 의 6빌더는 이미 구현·문서화돼 있는데
   33씬 중 `sceneN4` 1건만 쓴다 `[실측 — grep]`. 재구현 금지, `import infra_kit` 로 흡수한다.
5. **W1 좌표를 그대로 옮기면 안 되는 것이 3건 발견됐다** — 낙차 에지 앞 0.8 m 금지대 위반
   (01·02·15), scene13 램프 노면 요소의 프레임 진입 오판(d2 만 유효), scene10 이 3개 근경
   조사 어디에도 없음. §5 매트릭스에서 전부 교정했다.

## 1. ★ 차단 항목 — 스킨 간섭 해소 (W2 0번 작업)

### 1.1 스킨 기하 재실측 `[실측 — 코드 정독 + CPU 재계산]`

`scene_common.add_box()` 는 `LOOK_V1 and _skin_wanted(...)` 이면 슬래브 위에 변위 메시를 덮는다
(`:735`). `_skin_wanted` 통과 조건은 `sx,sy ≥ 4.0` · `sz ≤ 0.8` · 재질 클래스 ∈
`{paving, concrete, asphalt, soil, gravel, stone}` · 경로/재질명에 `_SKIN_DENY` 토큰 없음 (`:749`).

`_ground_skin` 상면 계산 (`:778-841`):

| 항 | 코드 | 값 |
|---|---|---|
| 기저 리프트 | `ztop = 슬래브상면 + max(0.0015, amp_m·1.15)` | **+11.5 mm** |
| 옥타브 필터 | `_wl_min = spacing·2.5 = 0.12·2.5 = 0.30` → `(0.55, 0.19, 0.07)` 중 **0.55 만 통과** | 1옥타브 |
| 변위 진폭 | `v ∈ [−0.5, +0.5]` (`g = rng.random(...) − 0.5` 의 이중선형 보간) → `v·amp_m·0.6⁰` | **±5.0 mm** |
| **스킨 표면 범위** | | **+6.5 ~ +16.5 mm** |
| 경계 테이퍼 | 슬래브 경계에서 변위 → 0, 안쪽 `edge=0.05 m` 들여깜 | 경계에선 정확히 +11.5 mm |

→ **특수조 §2.1 의 "+1.5 ~ +21.5 mm" 는 진폭을 2배로 본 값이다.** 결론(맨홀 매몰)은 동일하게
성립하지만 처방 수치가 바뀐다.

현행 flush 요소 proud 는 전부 이 아래다 — `sceneN5` 실측: 줄눈 0.6 mm · 맨홀 틀 1.2 / 뚜껑 2.0 /
보스 3.0 mm · 차도 파선 2.6 mm `[실측 — sceneN5_flush_grating.py:79-102]`.
A/B 렌더 근거(특수조 §2.1): 룩 ON 에서 맨홀 2개 암부 화소 5.88 % → **0.02 %**, |∇| p99 −82 %.

### 1.2 채택안 — **P-A: 대상 슬래브 스킨 OFF**

| 안 | 내용 | 판정 |
|---|---|---|
| **P-A ★채택** | ground_kit 이 장식하는 지면 슬래브를 `_skin_wanted` 에서 **명시 제외**. flush 요소는 물리적으로 옳은 proud/recess(0.6~3.0 mm, 음각 포함) 로 되돌린다 | **채택** — 음각 구현이 가능한 유일 안. 스킨이 하던 "평면감 파괴"는 ground_kit 요소 + T1 디테일 노멀이 대체한다 |
| P-B 폴백 | 스킨 유지 + `GROUND_PROUD_FLOOR = 0.018`(=16.5+1.5) 로 전 요소 양각 | 뚜껑·패치·도색만 산다. **줄눈·균열·홈파기는 포기**. P-A 가 회귀를 내면 이쪽 |
| P-C | `_ground_skin(amp_m)` 0.010 → 0.003 | **비권장** — 33씬 전 지면 픽셀 변화 + Phase1 E9 "정점 변위가 최대 시각 기여" 상쇄 |

**P-A 구현(코드 4줄, `scene_common.py`)**

```python
SKIN_EXCLUDE = set()          # 모듈 전역. 씬이 ground_kit 적용 전에 등록한다.

def skin_exclude(*paths):     # 공개 API — ground_kit 은 이 함수를 '주입'받는다
    SKIN_EXCLUDE.update(str(p) for p in paths)

# _skin_wanted() 첫 줄에 추가
    if str(path) in SKIN_EXCLUDE or any(str(path).startswith(p) for p in SKIN_EXCLUDE):
        return False
```

**`_SKIN_DENY` 에 토큰 1개 추가** — `"gkit"`. ground_kit 이 만드는 프림은 전부
`{ROOT}/GKit/...` 아래 두므로, ground_kit 산출물 자신이 **2차 스킨을 뒤집어쓰는 사고**를
구조적으로 막는다(도막·마모 띠처럼 4 m 이상 대면적을 만드는 빌더가 있다).

**ground_kit 쪽 규약**: `apply_ground(..., skin_exclude=None)` 로 콜백을 주입받는다
(scene_common 미의존 원칙 유지). 씬 코드는 `gk.apply_ground(..., skin_exclude=sc.skin_exclude)`.

## 3. 모듈 구조

### 3.1 규약 (`infra_kit` 승계, 예외 없음)

- **Z-up · m · 진행축 +X.**
- **`scene_common` 미import.** 프리미티브는 `Kit` 주입. `import infra_kit as ik` 는 **허용**
  (역참조 없음 — 순환 안 생긴다). `Kit`·`det_seed`·`det_rng`·`_bay_joints`·`kit_from_scene_common`
  는 **재구현 금지, 재수출**.
- **RNG 100 % 결정적** — `hash()` 금지, `zlib.crc32 → random.Random` 만.
- **모든 프림은 `{prefix}` 아래**, `prefix` 는 `{ROOT}/GKit` 고정(§1.2 스킨 방어).
- 각 함수 docstring 에 **`GT:` 줄** + **개당/미터당 프림 수** 명시.
- 치수는 **`GROUND_DIMENSIONS` 원장에만** 둔다. 원장에 없는 수치를 기본값으로 넣는 것 금지.
- **알베도 하드클램프 `≤ 0.30`** — 순백 대면적 금지 규약을 코드가 강제한다. 0.30 초과 요청은
  `ValueError`.
- **금지 API**: `build_tactile_pair` 호출(점자블록 기본 OFF) · `lid=False` 계열(무개구) ·
  볼라드 · 사람/차량 오브젝트 · 계절 특정 산포(단, 04·07 갈변 낙엽·C1 눈·C2 낙엽은 씬 정체성으로 예외).

**씬 통합은 2줄이다** (예: scene15):

```python
gp = gk.plan_ground("alley_concrete",
                    region=(-12.0, -0.9, 0.0, 0.9), z=0.0,
                    edges=[("stair_top", 0.0)], overrides=PARAMS.get("ground"))
gk.apply_ground(gk.kit_from_scene_common(sc, stage), f"{ROOT}/GKit", gp, M,
                skin_exclude=sc.skin_exclude)
```

`GroundPlan` 은 dataclass 유사 dict: `{"elements": [Elem, ...], "materials_needed": [...],
"prims": int, "instances": int, "gt": {...}, "budget": {...}}`.
`Elem` = `dict(kind, path, aabb=(x0,y0,z0,x1,y1,z1), proud, mtl_key, meta)`.
**`plan_ground` 만으로 프림 수·GT·프레임 예산이 전부 판정 가능해야 한다** — USD 접촉 전에
`python3 ground_kit.py` 로 33씬 계획을 검산하기 위함.

`apply_ground` 는 `gt_delta_max` 를 반환하고, `> GT_DELTA` 면 **생성 전에** 예외를 던진다.

### 6.2 낙차 에지 인접 대역 — 금지대와 GRAZE 정합

**(a) 하드 금지대 — 기하학적으로 유도** `[계산]`

프리셋 eye `(−d, gy, h)`, 낙차 에지 상단을 `(0, y, 0)` 이라 하면 에지를 향한 시선의 지면 위
높이는 `z_ray(x) = −h·x/d` (x<0). 높이 `z_e` 인 요소가 `x_e` 에 있으면
`z_e > h·(−x_e)/d` 일 때 **에지를 가린다**. `z_e = GT_DELTA = 0.020`, `h=0.3`, 최악 `d=10`:

```
−x_e > z_e·d/h = 0.020×10/0.3 = 0.667 m     →  안전여유 포함 EDGE_STANDOFF = 0.80 m
```

> **규칙 GT-E1**: 낙차 에지 전방 **x ∈ [−0.80, 0]** 에 proud > 0 인 요소 배치 금지.
> 음각 요소(줄눈·균열)는 허용하되 **에지와 평행한 전폭 횡단선은 금지**(에지 흉내).

**(b) GRAZE v2 와의 정합** `[실측 — regression_check.py:180-200]`

GRAZE v2 의 E 대역은 지면거리 `[0.7d, 2.2d]`, 즉 씬 좌표 `x ∈ [−0.3d, +1.2d]`.
d=2/5/10 을 합치면 `x ∈ [−3, +12]` — **근경 충전 영역과 거의 전부 겹친다.**
v2 는 등방 클러터(낙엽·자갈·오염)를 열 평균으로 상쇄하므로 안전하지만,
**화면을 가로지르는 새 직선**은 상쇄되지 않는다. 따라서:

> **규칙 GT-E2**: 각 h0.3 프리셋의 E 대역 안에 들어가는 **신규 전폭 횡단 직선 ≤ 1본**,
> 그 선의 투영 행이 에지 투영 행에서 **≥ 12행** 이격(= `GRAZE_HW 3 + SMOOTH 3 + SLACK 2` 의 2배).
>
> **규칙 GT-E3**: 신규 횡단선의 휘도 단차는 낙차 에지 단차의 **50 % 이하**.
> `frame_budget` 이 요소 알베도 비로 근사 검산한다.
>
> **규칙 GT-E4 (라운드 규칙)**: ground_kit 최초 적용 라운드는 **GRAZE before/after 비교를
> 유보하고 after 를 새 baseline 으로 삼는다.** 대신 **동일 라운드 hazard-off 쌍둥이**(승인 완료)
> 와 비교해 "낙차가 없는데 에지 신호가 생겼는가"를 본다 — 이것이 진짜 검사다.
> 선례: 낙엽 전역화가 FRAME·OCCL 을 같은 사유로 re-baseline `[실측 — leaf_globalization_budget_v2]`.
>
> **GRAZE 담당 이관**: 확산 완료 후 대조군 157컷 `spec` 상단(현행 24.79 = sceneC2 h0.3_d10)을 갱신.

### 6.3 공동 위 지면 평면 금지 · 개구 4박스 분할

> **규칙 GT-V**: `plan_ground(voids=[(x0,y0,x1,y1), ...])` 로 받은 개구·공동 위에
> **어떤 요소도 걸치지 않는다.** 풋프린트가 개구와 XY 교차하는 요소는
> ① 축평행 **≤4 박스로 분할**(`sceneD2` `Slab_W/E/S/N` 표준) 하거나 ② 드롭한다.
> `python3 ground_kit.py` 자기검산이 **전 요소 AABB × 전 void 교차 0** 을 어서션한다.

동일 규칙을 **낙차 에지**에도 적용한다 — 에지를 가로질러 이어지는 스트립(줄눈·측구·도색)은
에지에서 절단한다. 다리처럼 이어지면 "낙차가 없는 것처럼" 보이는 **가짜 연속 단서**가 된다.
