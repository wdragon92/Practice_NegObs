그런데 **형태가 없다** — 몸통 실린더 + 띠 실린더뿐. 실물에 반드시 있는
**상단 돔/챔퍼 캡·기초 플랜지·앵커볼트 커버**가 0. N1/N5 확대 판독 결과
"흰 플라스틱 막대" 로 읽힌다(§3 N5 크롭).

그리고 **더 큰 문제 2가지** :
1. **한국 실물의 96%가 부적정이다.** 한국시각장애인연합회 2023 전국 337개소
   전수 — **볼라드 부적정 96.0%**, 점자블록 적정 4.0% [통계]
   (`Docs/surveys/cue_arrangement_survey.md` §645~656). **41본을 전부 100 %
   규격대로 놓은 것 자체가 통계적으로 비현실적**이다.
2. **점형블록 소판이 v5.2 §7 "점자블록 기본 OFF" 와 충돌한다.** 본편 21씬은
   전부 껐는데 batch1 은 `build_bollard_v51(tactile=True)` 기본값 때문에
   41본 중 39본에 켜져 있다(D1 만 False). → §2.6 규약 충돌 ①.

- 판정 **형태재작(캡·플랜지 추가) + 규격 지터** — 41본 중 **8~12본(약 25 %)**만
  완전 규격, 나머지는 실측 부적정 유형(높이 0.6~0.7 로 낮음 / 간격 2.0~2.5 로
  넓음 / 반사띠 마모 / 점형블록 없음 / 1본 기울어짐)으로 갈라야 한다.
  우선 **P1**.
- 렌더 계측 : 점형 황색 픽셀 N5 beauty 0.0027 % (55 px) — **판독 불가 수준**.
  즉 지금은 "켜져 있으나 안 보이는" 최악 상태다.
