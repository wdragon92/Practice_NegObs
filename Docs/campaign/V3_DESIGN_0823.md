### 0.1 용어 최소 사전

| 용어 | 뜻 |
|---|---|
| **낙차(drop-off)** | 지면이 끝나고 아래로 꺼지는 음(-)의 장애물. 사방이 막힌 함몰(depression)과 구별한다 |
| **V / E / H** | 낙차 가시성 티어 — 내부 픽셀 보임 / 가장자리(림)만 / **기여 픽셀 정확히 0**(주변 맥락만 남음). H가 연구의 핵심 |
| **트윈 Δ** | 같은 카메라에서 위험만 지운 쌍(on/off팔)의 예측 확률 차 — "위험이 있어서 반응했는가"의 반사실 측정 |
| **FA / FA-정합** | False Alarm(오경보) — 위험 없는 프레임 발화율 / 모델별 문턱을 조정해 오경보율을 맞춘 뒤 비교(문턱 착시 제거) |
| **연합 vs 추론** | 그림 전체 인상↔정답의 동시출현을 외운 것 vs 단서를 증거로 맥락과 결합해 미관측 사실을 유도하는 것. 훈련 분포 안에서는 점수로 구분 불가 — **개입·반사실·미학습 분포에서만 갈라진다** |
| **계기판 3종** | ① 트윈-조건부 recall ② CUE-OFF 용량-반응 ③ N-cue 함정 FA (§7.1에 정의) |
| **2×2 팔 A/B/C/D** | {위험+단서 / 위험−단서 / 무위험+단서 / 무위험−단서} — v3 코퍼스의 핵 |
| **N-cue** | "단서는 있는데 위험은 없는" 장면(예: 화단 둘레 난간). ④층의 함정 표본 |
| **aux 아모달 헤드** | 주 출력(폴라 그리드) 곁의 보조 픽셀 마스크 출력 — 가려진 낙차의 전체 윤곽을 그리게 학습돼 있음. "이득 유의성" 주장은 철회됐으나(R6-d) 헤드는 살아 있고 진단·증거용으로 쓴다 |
| **보정(calibration)** | 출력 확률을 실제 빈도에 맞추는 후처리(temperature scaling). 검사는 신뢰도 곡선·ECE |
| **3a / 3b** | H 두 가족 — 발밑형(근거리 시야각 은닉·트윈 Δ≈0이 성질) / 전방형(단서 동반). H 주장은 3b 한정 |
| **맨-가림 H** | 단서가 하나도 없는 H(가림 주체와 무관 — **자기가림과 다른 개념**이니 혼동 금지). 훈련 지도에서 무시 마스크 대상이며, 올바른 목표는 발화가 아니라 보정된 낮은 확률(§2.5-5) |
| **test-core / test-ext** | 기존 test 7씬(v2/v3 A/B 공통 잣대·프레임 불변) / v3 신설 평가 씬(N-cue·측방·paired-H — 신규 지표 전용) |

## 1. 연구의 기원 — 왜 이 문제인가

**낙차는 왜 어려운가 — 신호의 기하학.** 높이 h의 전방 카메라가 거리 d의 장애물을 본다고 하자.
벽·기둥 같은 양(+)의 장애물은 자기 몸체가 배경과 다른 픽셀을 공급하며, 각크기는 거리에 반비례(≈ H/d)로
준다. 낙차(−)는 몸체가 없다 — 신호는 오직 **개구를 통해 내려다보이는 내부**뿐이다. 그런데 전방 카메라는
지면을 스치는 얕은 각(스침각 ≈ h/d)으로 보므로, 폭 w인 개구의 가시각은 두 반비례가 곱해져 대략
h·w/d² — **거리의 제곱으로** 사라진다(음의 장애물 문헌의 고전 결과; 우리의 7월 문헌 추적이 출발점으로
삼은 Heckman 계열). 여기에 두 성질이 겹친다. 낙차는 **자기 가장자리가 자기 내부를 가리는** 유일한
부류다(E 티어의 전형이 자기가림인 이유). 그리고 **위험의 크기와 신호의 크기가 비례하지 않는다** —
개구가 같다면 깊이는 가시 픽셀을 거의 늘리지 않고, 절벽처럼 가장 위험한 낙차일수록 내부 기여 픽셀은
0으로 수렴한다(= H 티어). 요약: 미리 알아야 하는 원거리에서 직접 신호가 먼저 꺼지고, 위험이 클수록
직접 신호는 오히려 빈약하다 — 직접 기하 측정의 원리적 상한이 여기 있고, 그 너머에 남는 정보 채널이
**맥락 단서**다.

**범위 명시 — 근거리는 별개 문제이며 본 연구 밖이다.** 반대로 낙차가 가까우면 스침각이 서면서 내부가
잘 보인다(V). 근거리에서 "안 보이는" 현상(band1 사각·3a 무반응)은 낙차의 성질이 아니라 **전방 고정
포즈라는 관측 규정의 시야각 인공물**이다 — 사람은 고개를 숙여 해결한다. 본 연구의 주장 범위는 원거리
전방의 E·H이고, 근거리의 해법은 시간축(직전 프레임 기억 — 동영상 전파, 승용 로드맵)으로 명시 이월한다(§3).

**기존 접근의 한계.** 주류 접근은 센서로 직접 잰 기하를 채우는 것이다. 위 기하학이 말하듯 이 접근은
신호가 1/d²로 꺼지는 바로 그 구간 — 멀고 가려진 위험 — 에서 원리적으로 약해지며, 7월 로봇 사고 기전
조사에서도 "스침각·가림으로 인한 존재 미탐"이 반복 기전으로 확인됐다(전수 단정이 아니라 조사 결과의 인용이다).

**사람의 해법이 힌트다.** 사람은 산길에서 펜스를 보면 너머를 재보지 않고도 "낭떠러지겠구나"를 안다.
펜스라는 **물체**가 아니라 "누군가 여기에 펜스를 세운 **이유**"를 읽는 것이다. 승용의 출발 동기도
이 지점이었다 — 자율주행이 barrier 너머를 추론하지 못해 나는 사고 유형(승용이 든 Tesla FSD류 사례)을,
맥락 추론으로 막을 수 없는가.

**7월 조사의 두 발견이 설계의 두 기둥이 됐다.**
1. 인공 단서(난간·경고블록·표지)는 다수가 **법정 의무 설치물**이다 — 즉 위험과 장식적 상관이 아니라
   **인과적으로** 연결돼 있다(방향 주의: **위험이 단서를 낳는다** — 그래서 단서에서 위험으로의
   역추론이 정당하다). 단서를 증거로 쓰는 추론이 원리적으로 성립하는 이유. (→ §2.1 ①층의 근거)
2. 그런데 **사고는 정확히 단서가 부재하거나 무력화된 곳에 몰린다** — 자연 지형, 관리 부실 구간, 철거·마모.
   즉 단서'만' 믿는 시스템은 가장 위험한 곳에서 침묵한다. (→ §2.4 ④층의 근거)

**연구 유형.** 새 방법(아키텍처) 연구가 아니다 — 모델은 도구고 **질문이 주인공**이다. 기여의 축은
① 문제 정의(4층 프레임워크) ② 그 정의를 담는 데이터셋(시뮬만 가능한 라벨: 깊이·하부표면·트윈·2×2)
③ 가설 검증(장치와 계기판). 이 정체성은 §6(아키텍처 동결 A/B가 왜 우선인가)까지 일관되게 흐른다.

**북극성(불변)**: "현실적인 맥락 단서들을 기반으로 낭떠러지를 이해할 수 있도록 시뮬레이션을 만들고,
그 학습 모델로 현실세계에서 정성평가까지 진행한다." (승용)

## 2. 4층 프레임워크 — 정본 해설 (승용 설계 · 2026-07)

**한눈 그림** — 사람이 낯선 길에서 실제로 하는 추론의 순서를 층으로 나눈 것이다:

```
 ③ 장면 사전   "여기는 제방길이다"          → 배경 확률을 깐다 (기저율)
      ↓
 ① 존재 단서   "난간이 있다, 지면 텍스처가   → 증거로 확률을 갱신한다
                저기서 끊긴다"
      ↓
 ④ 신뢰 저해   "그런데 저 난간은 화단        → 증거의 가중치를 조정하고,
                둘레일 수도 / 역광이라        확신의 크기를 정직하게 만든다
                잘 안 보인다"                 (= 보정된 확률)
      ↓
 ② 심각도     "있다면 얼마나 깊고, 아래는    → 위험의 크기를 매긴다
                뭐가 있나"
      ↓
   행동        감속 / 우회 / 추가 관측 / 정지
```

핵심 명제 두 개를 먼저 박아 둔다. **(가) 단서는 정답이 아니라 증거다** — 그래서 출력은 판정이 아니라
확률이어야 하고, ④층이 그 확률을 정직하게 만든다. **(나) 4층은 모델의 부품 구조가 아니라 데이터·지도·
평가의 설계 원리다** — v3에서 각 층은 신경망 모듈이 아니라 코퍼스 축·손실 규칙·계기판으로 구현된다
(구조로 강제하는 실험은 §6의 v3-B/옵션C뿐). 이 구분을 놓치면 "층별 모듈을 만들라"는 오독이 나온다.

### 2.1 ①층 · 존재 단서 — "위험이 있는가"의 증거

- **정의**: 미관측 낙차의 존재 확률을 올리거나 내리는 관측 가능한 신호.
- **두 갈래와 예시**:
  - 인공 단서 — 난간·핸드레일, 경고블록(점자블록), 표지판, 라바콘·바리케이드, 볼라드 열.
    성립 논리: 설치 규정 → "이것이 여기 있는 이유" 역추론. (전체 목록은 `Docs/reports/dropoff_cue_matrix_v1.md`의 13키가 정본)
  - 자연·기하 단서 — 지면 텍스처의 급단절, 스카이라인이 지면보다 먼저 끝남, **나무 꼭대기가 눈높이에
    보임**(= 그 나무의 뿌리는 한참 아래 = 큰 낙차; 승용 제안, 지면-평면 지각 논리), 낙차 상단 노출면, 그림자 패턴.
- **추론의 형식**: 관찰(난간) → 이유 역추론(낙차 방호) → 존재 확률 갱신. 관찰이 없으면 갱신도 없어야
  정상이다 — **단서 0인 프레임에서의 체계적 발화는 ①층으로 설명될 수 없다**는 판별 규칙이 여기서
  나온다(범인 후보는 ③층 사전 암기 또는 저수준 텍스처 반응 — §8.1의 FA 가족 분류가 그 둘을 가른다).
- **오류 모드**: 미탐(단서를 못 읽음) / 오탐(단서 없는데 발화 = ③ 침범, 단서만 보고 무조건 발화 = ④ 부재).
- **v2에서 무너진 방식**: 훈련 데이터에서 단서와 위험이 사실상 완전 동행(구off가 단서까지 지웠으므로
  동시 존재하거나 동시 부재). 상관이 1이면 **추론을 배울 유인이 0**이다 — 그림 인상만 외워도 만점이므로.
  증거: CUE-OFF 개입에서 단서 증거 0, 오경보가 단서 개수가 아니라 "화면이 광학적으로 얼마나 바뀌었나"를
  추종(단서 전부 보존한 scene17이 FA 최저 .042), Gazebo 위험-0픽셀 월드 발화.
- **v3 구현**: 2×2 직교 배치로 상관을 끊는다(목표 |r| ≤ 0.2, 실측 보고). C팔(무위험+단서)이 "단서=발화"에
  벌점을, B팔(위험−단서)이 "단서 없이는 함부로 확신하지 말라"를 공급한다.
- **검증**: 계기판 ①②(§7.1) + v3-B 어트리뷰션(발화 근거 픽셀이 단서 위에 있는가).
- **자율 확장 메뉴**: 단서 부분-가림 민감도 곡선(단서를 조금씩 가리며 용량-반응) · 단서 종류별 기여 분해
  (난간 vs 경고블록 vs 그림자 — 단서 하나씩만 남긴 팔) · 어트리뷰션 질량의 단서-내부 비율 지표화.

### 2.2 ②층 · 심각도 — "있다면 얼마나 위험한가"

- **정의**: 존재가 참일 때 결과의 크기를 매기는 단서·라벨 — 낙차 깊이, 하부 표면(물/콘크리트/흙·풀),
  낙하 후 갇힘 가능성.
- **왜 별도 층인가**: 존재≠대응. 10cm 연석과 3m 옹벽은 같은 "낙차 있음"이지만 행동이 다르다.
  7월 로봇 사고 조사에서 "존재는 감지했으나 **심각도 추정 부재**"가 독립된 사고 기전으로 확인됐다
  (갇힘으로 심각도가 증폭된 사례 포함).
- **예시 단서**: 깊이 프록시 — 눈높이의 나무 꼭대기, 옹벽·계단 단수, 건너편 지면의 소실 각도.
  하부 표면 — 수면 반사(물), 재질 질감. 갇힘 — 사방 벽 여부.
- **시뮬의 존재 이유가 이 층에 있다**: 절벽 아래 깊이·표면은 현실에서 라벨링 불가능하다. 시뮬은 공짜다.
- **v2 상태**: 라벨 자체를 안 뽑았다(사장).
- **v3 구현**: 라벨 전량 산출(씬 설정에서 기계 산출: `depth_m` · `undersurface` · `entrapment`) + **분석까지**
  (깊이 구간별 recall/FA, 심각도 단서 유무별 트윈 Δ). 예측 **헤드는 이번에 넣지 않는다** — 넣으면
  A/B의 개선이 데이터 덕인지 헤드 덕인지 귀속이 무너진다(§6). 헤드는 후속(9월+)의 첫 후보.
- **자율 확장 메뉴**: 깊이-반응 검사 — 단 **심각도 단서가 화면에 있는 표본 한정**(§1의 비비례 원리상
  단서 없는 깊이 차이는 신호 차이가 없으므로, 무단서 표본에서 깊이 반응을 기대하는 것 자체가 오류다;
  단서 있는 표본에서의 반응 유무가 ②층 학습의 판별점) · 하부표면별 오류 분해 · "심각도 단서가 있는 H"의 층화표.

### 2.3 ③층 · 장면 맥락 사전 — 배경 확률, 그리고 그 오용

- **정의**: 장면 유형이 주는 기저율. 제방길이라면 한쪽에 수로가 있을 사전확률이 높고, 실내 복도라면 낮다.
- **올바른 역할**: 증거 해석의 배경이다 — 같은 "풀숲 끊김"도 농로에서는 배수로 신호로, 잔디밭에서는
  무해로 읽히는 것. 사후확률 ∝ 증거(①) × 사전(③).
- **오용 = 이번 프로젝트가 겪은 병**: 사전이 증거를 **참칭**하면 — "공사장처럼 생긴 그림 → 위험" —
  단서 없이도 발화한다. 우리가 "씬 연합"이라 부른 것의 정체가 정확히 이것이다: v2 모델은 ①을 배우지 못하고
  ③만 배웠다. 증거: RGB H 적중의 44.7%가 위험을 지운 쌍둥이에서도 발화 · Gazebo에서 6모델 중 5가
  "위험 안 보이는 월드"를 "훤히 보이는 월드"보다 높게 매김(부속물 순서 추종).
- **왜 v2 데이터가 이 오용을 강제했나**: (§3의 원인 A·B) 교란 때문에 ③이 ①을 대체해도 훈련 점수가 같았고,
  단서 0인 H에도 정답을 강요해 "씬 통계 암기"가 유일한 생존 전략이었다.
- **v3 구현**: 씬 수·유형 다양화로 사전의 예측력을 희석 + **미학습 씬 평가**(test-ext)로 사전 암기의 이득을
  차단 + 무위험 팔들의 벌점 — 역할 분담을 정확히: **D팔(단서·위험 모두 부재) 발화율이 순수 씬-연합의
  직접 측정치**다(같은 씬에서 남는 건 '분위기'뿐). C팔은 그 위에 단서-유발 몫을 얹으므로
  **FA_C − FA_D = 단서-유발 오경보 몫**으로 분해된다(§12-3).
- **검증**: 씬 홀드아웃 성적 · (확장) 씬 임베딩 유사도와 오류의 상관 — 오류가 "훈련 씬과 닮은 정도"를
  따라가면 연합 잔재가 남은 것.
- **자율 확장 메뉴**: 이질 배경 합성 프로브(같은 단서 배치를 전혀 다른 씬 유형에 이식해 발화 비교) ·
  씬-유형별 기저율 대 모델 발화율 대조표(사전을 얼마나 '적정하게' 쓰는지) · Gazebo를 ③층 스트레스로 재해석한 재주행.

### 2.4 ④층 · 신뢰도 저해 — 단서를 언제 얼마나 믿을 것인가

이 층이 v3의 승부처다. `[승용: "cue가 있어도 어떤 환경이라면 낙차가 없는지도 논리가 제대로 서지 못한
상태로 실험을 진행해서 그런 것 같아"]` — v2에는 이 층이 데이터에도 지도에도 **전무**했다.

- **정의**: 단서-위험 연결의 신뢰도를 조정하는 모든 요인. 세 갈래로 나눈다.
  - **(a) 단서의 거짓 양성 — N-cue**: 단서는 있는데 위험이 없다. 화단 둘레 난간, 승강장·정류장의 경고블록,
    공사 끝났는데 남은 표지, 장식 펜스. v2 모델이 여기서 전부 속는다는 게 실측됐다(장식 보존 off팔 FA .681).
  - **(b) 단서의 거짓 음성 — 무단서 위험**: 위험은 있는데 단서가 없다. 자연 지형·관리 부실 — §1의 발견 2가
    말하듯 **실제 사고가 몰리는 지대**다. 여기서 정직한 시스템의 답은 "확신 있는 탐지"가 아니라
    "낮지만 0 아닌 확률 + 신중 행동"이다. `[승용: "사람도, 처음 보는 환경이면 H라벨에선 추측만 할 수 있지,
    직접 보기 전까진 fake인지도 모르니깐"]` — 이 문장이 (b)의 지도 규칙을 결정했다: **화면에 근거가 없는
    정답을 모델에게 강요하지 않는다**(§5.1 무시 마스크). 강요가 바로 v2에서 암기를 낳은 원인 B다.
  - **(c) 단서 관측 저해**: 역광·그림자·마모·부분 가림·거리 — 단서가 있어도 읽기 어려운 조건.
- **출력 형식이 곧 이 층의 구현**: 판정(0/1)이 아니라 **보정된 확률**. "난간이 보이지만 이 맥락에선 0.6" —
  그리고 그 0.6이 실제 빈도와 맞아야 한다(보정). 행동 통로: 확률 지도 = traversability 코스트 →
  감속·추가 관측(active perception)으로 자연 연결 `[승용 결재 1: 실용 정보량 관점]`.
- **v3 구현**: (a) N-cue 하드 네거티브 군 — FA 현실 조사(§8.1)에서 유발원을 수입해 씬으로 번역.
  (b) 단서-조건부 지도 + 맨-가림 H 무시 마스크(§5.1). (c) 렌더 변주(조명은 광도 결론 준수 — 과노출만 금지)
  + 부분 가림 프로브는 확장 메뉴. 그리고 전 모델 T-스케일링 + 신뢰도 곡선·ECE 보고(§5.2).
- **검증**: 계기판 ③(N-cue FA) · ECE · 선택적 발화 곡선("확신 상위 x%만 답할 때 성능" — '모르겠다'의 가치를 잰다).
- **자율 확장 메뉴**: N-cue 난이도 사다리(뻔한 화단 난간 → 교묘한 철거 잔존 표지) · 단서 마모/역광 스트레스 ·
  "보류 밴드" 실험(확률 중간 구간을 답변 보류로 처리했을 때 실용 성능) · aux 마스크의 확신도와 그리드 확률의 정합 검사.

### 2.5 층 간 상호작용 — 흔한 오독 5개 (자율 확장 전 필독)

1. "단서가 보이면 위험이다" — ①만 있고 ④가 없는 시스템. N-cue에서 전멸한다.
2. "위험 씬처럼 생겼으면 위험이다" — ③의 참칭. v2의 병. 계기판 ①이 잡는다.
3. "H recall만 오르면 성공이다" — FA·보정을 무시한 반쪽. **모든 recall 주장은 FA-정합과 병기**가 이 프로젝트의 법이다.
4. "4층 = 모델 4모듈" — 아니다. 이번 창에서 층은 **데이터 축·지도 규칙·계기판**이다(§2.0-나).
5. "맨-가림 H도 맞혀야 좋은 모델이다" — 아니다. 근거 없는 정답은 (b)의 지도 원칙 위반이고,
   그걸 맞히는 유일한 방법이 암기다. 맨-가림 H의 올바른 목표는 "보정된 낮은 확률"이지 발화가 아니다.

## 3. v2 부검 — 경위, 원인, 교훈 (버전 여정 서사의 원형)

**경위.** 7월: 4층 프레임 설계, 트윈(쌍둥이) 장치 고안 — 원래 의도는 ①층 검증. 8월 초: 코퍼스 v2 제작 —
이때 off팔이 위험을 지우며 **단서까지 함께 지웠다**(구off). ①층 검증 장치가 의도치 않게 교란 생성기가
된 순간이다. 8월 중: 본 표 완성, "RGB .688이 Depth .438을 이긴다"는 헤드라인. 8/23 주말 창:
세 독립 장치(개입 CUE-OFF · FA-정합/트윈-조건부 재분석 · Gazebo 교차-시뮬)가 헤드라인과 그 해석을
연쇄 격파 — FA-정합 시 전 지점 Depth ≥ RGB(문턱 착시), RGB 적중 44.7% 무조건부, 단서 증거 0.
`[승용: "너무 결과물을 위한 실험을 강행한 느낌"]` — 실행 규율은 지켜졌으나(자기 헤드라인을 스스로 격파했다),
**상류의 데이터 논리가 설익은 채 동결된 것**이 사실이다. 본 문서가 그 교정이다.

**원인 3 (각각 v3 사양 하나와 짝지어진다).**
- **A. 교란**: 단서⊥위험 미분리 → ③이 ①을 대체해도 무벌점. ⇒ §4.1 직교 2×2.
- **B. 억지 지도**: 정보 0인 프레임에 정답 강요 → 암기가 유일 전략. ⇒ §5.1 단서-조건부 지도.
- **C. H-blind 선택**: 체크포인트 선택식의 H 항이 val 6프레임 분모 → "전부 발화"가 만점인 6문제 시험.
  convnext 2/3시드 상수출력 붕괴로 발현, 본 표에도 해당. ⇒ §4.3-3 선택지표 수리.

**교훈 3.** 직교화 없이 추론 없다 / 근거 없는 정답을 강요하지 않는다 / 선택 지표도 실험의 일부다 —
지표가 병들면 그 지표로 뽑힌 모든 모델이 병든다.

**부수 확정(설계 제약으로 승계).** 근거리(0–2m·발밑)는 주장 범위 밖이다 — 단, 이유가 둘로 갈리므로
정확히 구분한다: ⓐ band1 사각과 3a 무반응은 **관측 규정(전방 고정 포즈)의 시야각 인공물**이다 —
낙차의 성질이 아니다. ⓑ 근거리 E는 스침각이 서면서 내부가 보여버리므로(대체로 V가 됨) **기하상
성립하지 않는다**(림만 보이려면 개구 1–3cm = 균열). 낙차 고유의 난점은 정반대인 **원거리 소실**
(§1, 가시 개구 ~1/d²)이다. 따라서 v3는 근거리 성능을 약속하지 않고(E는 원거리 배치, 3a는 주장 제외),
근거리의 해법은 시간축(동영상 전파 — 승용 로드맵)으로 이월한다. §4.3-4 시퀀스 훅이 그 밑재료다.

## 4. 코퍼스 v3 사양

### 4.1 직교 2×2 (①·③층의 구현)

- 대상 씬마다 4팔: **A**(위험+단서) **B**(위험−단서) **C**(무위험+단서) **D**(무위험−단서).
  토글은 기존 배선 재사용 — 위험 = 트윈 기제, 단서 = `cue_*`(위험 기하 불변, 해시게이트로 실증).
- **각 팔의 교육적 역할**(이걸 알아야 비율 조정 판단이 가능하다): A = 정상 결합 학습 / B = "단서 없이
  함부로 확신 금지"(+§5.1 지도 규칙의 적용처) / C = "단서≠위험" 벌점 공급(④-a) / D = 기저 대조.
- 비율 초안 3:2:3:2 — C를 A와 동율로 두는 이유: 지름길("단서=발화")의 기대 이득을 0 근처로 끌어내리기
  위함. 학습 코퍼스의 단서↔위험 점상관 **|r| ≤ 0.2 목표, 실측치 보고 필수**("직교화했다"의 정량 증거).
- 라벨: A·B 위험 GT 동일(해시로 검증 — **P-3에서 '장식' 판정된 단서 씬에 한함**; 구조물 단서 씬은 B팔 제작 불가) /
  C·D 전 칸 음성 / B의 H 지도는 §5.1을 따른다.

### 4.2 씬 세트 (각 항목 = 목적 한 줄과 함께)

- **paired-H ≥ 10**(test-ext): H 통계가 씬 2개(사실상 scene14)에 갇힌 현 상태 해소. 자기가림 유형 다양화 —
  둔덕형·계단참형·복도 굴절형.
- **E는 원거리 전용**: 근거리 E는 세상에 없으므로(기하 역산) 표본을 원거리에서 늘려 통계를 살린다.
- **측방 위험 씬 신설**(test-ext): 섹터 분해능 논의(5→10)·밴드 세분을 "실용 정보량" 기준으로 재론할
  측정 기반 `[승용 결재 1 룰링]`. 현 test에 측방 씬이 0개라 지금은 원리적으로 잴 수 없다.
- **N-cue 군 신설**: ④-a의 표본. 사양은 §8.1 FA 현실 조사 결과를 번역해 확정(뻔한 것→교묘한 것의 사다리).
- **sceneC2 재설계 편입** `[승용: "응급수술까진 아니라도 재설계 깔끔하게"]`: 경사 통계 특이성 완화 +
  카메라 포즈 다양화(depth의 구별 입력 8개 문제 해소).
- **test-ext의 계기판 씬은 4팔 전부 제작(평가 전용·양 모델 공히 미학습)** — 계기판 ①②③의 A/B는
  여기서 잰다. 훈련 씬의 팔로 재면 v3만 분포-내(in-distribution)가 되어 비교가 구조적으로 기운다(§12-9).
- **test-core 불변**: v2/v3 A/B의 공통 잣대(헤드라인 표·FA-정합). 신규 지표는 전부 test-ext에서.

### 4.3 선행 수리 4종 — "없으면 v3의 개선이 아티팩트라는 반박에 답할 수 없다"

1. **G7 재융합+재라벨**: boost 6씬 높이맵이 융합 단계를 안 거쳐 GT가 조각났고 그 귀결로 s12의
   "H" 48프레임이 실제 티어 V였다. 수리 없이는 라벨 신뢰 전체가 인질. 게이트: 티어 재분류 대장.
2. **가드 사전 분류**: 모든 `cue_*` 대상을 두 팔 라벨러로 돌려 `cells_raw` 차이로 **구조물/장식**을 기계
   판별, 구조물은 토글 금지 목록에 등재. 이유: 구조물을 "단서"로 지우면 위험 발자국 자체가 변해 개입이
   무효가 된다 — 주말 CUE-OFF 판정 불가 칸의 최대 원인.
3. **선택지표 수리**: val strict-H ≥ 30 확충(§4.2에서 충당) + FA 항 포함 + 상수출력 거부 게이트.
   최종식은 v2 재현 검증(resnet34 성적 재현) 통과 후 결재란 상신 — 지표를 바꾸고도 v2가 재현돼야
   "지표 교체가 결과를 조작하지 않았다"를 보일 수 있다.
4. **시퀀스 훅**: 씬별 연속 포즈 궤적 저장(렌더 파라미터 수준 — 비용 최소). 동영상 전파 학습의 밑재료.

### 4.4 라벨·메타데이터

`depth_m`(낙차 깊이) · `undersurface`(물/콘크리트/흙풀) · `entrapment`(갇힘 여부) — ②층 분석용, 씬 설정에서
기계 산출. 프레임별 단서 존재 벡터(13키, cue matrix 정본 준용) — ①층 층화·§5.1 지도 판정용.
전 라운드 `ACCOUNTING.md` 분모 단일 참조.

## 5. 학습 사양 (v3-A는 아래 명시 항목 외 **전부 v2 레시피 동결** — A/B 순수성이 논문의 척추다)

### 5.1 단서-조건부 지도 (원인 B의 치료 · ④-b의 구현)

- 양성 지도는 **단서가 프레임에 존재하는 H**에만. 존재 판정은 씬 설정 기반 기계 판정(사람 개입 없음).
- 맨-가림 H(단서 0)는 **무시 마스크**(손실 제외)가 기본. 철학: 화면에 근거가 없는 정답을 강요하는 순간
  모델의 유일한 생존 전략은 암기다 — 사람에게 요구하지 않을 것을 모델에게 요구하지 않는다.
- 대안(씬 기저율 소프트 타깃)은 **1런 ablation으로만** 비교한다. 주의: 소프트 타깃은 ③층(사전)을
  타깃에 다시 주입하는 경로가 될 수 있어(기저율=사전) 기본값이 아니다 — ablation의 목적은 이 우려의 실측.
- V·E와 off팔 지도는 v2 동일. B팔의 H 칸은 무시 마스크.

### 5.2 보정 (④층의 출력 형식)

학습 후 val에서 temperature T 자동 탐색 → 전 평가에 원본/보정본 병기. 보고: 신뢰도 곡선(reliability
diagram) · ECE · 선택적 발화 곡선. 독법 제공 의무: "이 확률 지도를 코스트맵으로 쓰면"의 실용 문단 1개.

### 5.3 aux 아모달 — 유지 + 진단 활용 `[승용: "COST가 저렴하다면 최대한 활용"]`

훈련 가중 동결(레시피의 일부). 활용은 추론 전용 4종(§8.2): 마스크 품질 · **H 프레임에서 은닉 낙차를
그리는가**(그린다면 그것이 추론의 픽셀 증거) · CUE-OFF 팔별 마스크 반응(계기판의 픽셀판) ·
마스크→그리드 파생 vs 직접 그리드(아모달 방식 타당성 검토 `[승용]`).

## 6. 아키텍처 트랙 — 그리고 왜 이 순서인가

`[승용: "U-Net이 정말 최선일지… top-down으로 처음부터 다시"]` — 정당한 의심이고, 답의 구조는 이렇다.
주말 증거는 주범을 아키텍처가 아니라 데이터·지도·선택에 지목한다: 같은 병이 resnet34/50, convnext,
그리고 트랜스포머(B2)에서 **모두** 났다(B2가 Gazebo 0픽셀 월드에서 .905로 최악). 그래서:

- **v3-A (주 판정)**: resnet34 U-Net **완전 동결** — 코퍼스·지도만 바꾼 순수 A/B. 여기서 개선되면
  "데이터 설계가 추론을 만든다"는 인과 진술이 성립한다. 아키텍처를 함께 바꾸면 이 귀속이 영구히 무너진다.
- **v3-B (병행)**: 칸-질의 어텐션 헤드 — 폴라 20칸 각각이 query로 이미지 특징에 attend. 목적 둘:
  ⓐ "장거리 관계 매핑엔 픽셀 컨브넷이 부적합할 수 있다"는 가설의 실측 ⓑ 칸별 **어트리뷰션 지도 무료
  산출**(①층 검증기 — 발화 근거가 단서 픽셀인지 눈으로 보인다). v3 코퍼스로 학습, v3-A와 동일 계기판.
- **옵션 C (설계 우선)**: 단서-병목 2단 구조(단서 검출 → 위험 매핑) — 추론 경로를 구조로 강제.
  U-Net 대안 탐색의 다음 단계 후보로 설계서만 먼저.

## 7. 평가·판정 — 사전 등록

### 7.1 계기판 3종 (각각이 §2의 어느 층을 재는지와 함께)

1. **트윈-조건부 recall** (③ 검출): 위험 지운 쌍둥이에서도 난 발화를 빼고 센 recall. **쌍 정의는 (A,C)로
   통일**(§12-2) — v2 공표치 44.7%/0%는 구off(A,D) **세대가 다른 수치**이므로 참고치로 강등하고,
   A/B의 정본 기준점은 **v2 체크포인트를 (A,C) 쌍으로 재채점**해 새로 만든다(무대는 §12-9의 test-ext 4팔).
2. **CUE-OFF 용량-반응** (①↔③): 오경보가 단서 **개수**를 따르는가, 화면의 **광학 변화량**을 따르는가.
   v2 기준점 — 광학 질량 추종(scene17 역설).
3. **N-cue 함정 FA** (④-a, v3 신설): 단서 있음+위험 없음 표본 한정 오경보. v2에 해당 표본 없음 —
   근사 기준점은 장식 보존 off팔 FA .681. 낮을수록 선.
   보조: FA-정합 곡선(FA {.359,.20,.10,.05}) · ECE · test-ext(측방·paired-H).

### 7.2 판정 방식 — 왜 상대 기준인가

`[승용: "그 수치의 타당성을 현재로썬 내가 판단할 근거가 없는 것 같은데"]` — 옳다. 절대 문턱을 허공에서
발명하지 않는다. 사전 등록의 목적은 단 하나 — **결과를 본 뒤 목표선을 옮기는 일**의 원천 차단 — 이고,
그 목적은 방식 등록만으로 달성된다: "v3는 v2 대비 **옳은 방향으로, 시드 산포 σ를 초과하는** 변화"면 성공.
구조 게이트(상수출력·1에폭 붕괴·분모 회계)만 절대 수치를 갖고, 그 수치는 v2 실측에서 도출해 근거와 함께
결재란에 상신한다. σ는 시드 산포(런 재현성)의 잣대이지 씬-모집단 신뢰구간 주장이 아니다 — H·E의 씬-CI 철회 방침과
충돌하지 않으며, 씬-일반화 주장은 통계가 아니라 test-ext의 씬 수 확충으로만 강화한다. 본 절은 결과
산출 전 `PREREG_V3.md`로 복사·해시 고정한다.

### 7.3 실패 분기

계기판 미달 시 자율 실행 가능한 예비 레버는 **1개**(단서 어트리뷰션 보조 지도)로 사전 제한. 그 이상의
레버 추가는 결재 — 레버를 무한정 당기는 순간 사전 등록이 무의미해진다. 미달이어도 용량-반응 서사
(어디까지 갔고 무엇이 부족한가)는 그 자체로 논문 §결과다 — 교수님 지침: 실패 극복 여정도 기여
`[승용: "실패 하나하나도 좋은 기여로 담길 수 있으니"]`.

## 12. 정밀 정의 — 오독 방지 9선 (전부 ACCOUNTING.md에 등재할 것; 본 절이 §4~§8과 충돌하면 본 절 우선)

1. **G7 재라벨과 A/B 공정성**: "test-core 프레임 불변"은 이미지 불변이지 **정답지 불변이 아니다** —
   재융합·재라벨은 boost 영향 씬(s07=test 포함)의 GT를 바꾼다. 따라서 재라벨 완료 즉시 **v2 체크포인트
   전부를 교정 GT로 재채점**하고, 모든 A/B는 양측 공히 교정 GT 기준으로만 비교한다. 공표된 v2 표
   (구 GT)와의 델타는 별도 리포트(결재 4의 각주와 연결). v3만 교정 GT로 채점하는 순간 A/B는 무효다.
2. **v3의 반사실 쌍 명명**: 2×2는 반사실을 두 개 내장한다 — **(A,C) = 위험만 제거·단서 보존**
   (신off 세대; **트윈-조건부 계기판①의 쌍**) / **(A,B) = 단서만 제거·위험 보존**(CUE-OFF 세대;
   **계기판②의 쌍**) / (A,D) = 구off 세대(v2 트윈의 역사적 대응 — 비교 서술용으로만). "트윈"이라는
   낱말을 쌍 명시 없이 쓰지 않는다. **세대 통일 규칙**: 계기판①의 A/B는 양측 모두 (A,C)로 — test-ext
   계기판 씬의 C팔을 제작하고 v2 체크포인트도 (A,C)로 재채점한다. v2의 (A,D) 기반 44.7%/0%는 참고치.
3. **FA의 분리 집계**: FA_D(무위험−단서 = 청정 오경보)와 FA_C(무위험+단서 = 코퍼스 내 N-cue성 오경보)를
   **항상 분리 보고**한다. v2의 frame_fa_off와의 대응 관계를 ACCOUNTING에 명시. 해석 규약:
   **FA_D = 순수 씬-연합의 직접 게이지**(단서·위험 모두 부재), **FA_C − FA_D = 단서-유발 오경보 몫** —
   이 분해를 표준 보고에 포함한다.
4. **무시 마스크의 사거리**: 훈련 **손실에만** 적용된다. 평가 분모·recall·FA 정의는 v2와 동일하게
   유지(ACCOUNTING 단일 정의) — 분모를 줄여 얻은 recall은 개선이 아니라 아티팩트다.
5. **단서 존재 판정의 단위**: 지도 규칙(§5.1)의 판정은 **프레임 단위 가시성**이다 — 렌더 산출물
   (세그 마스크의 cue 클래스 픽셀 ≥ k, k는 게이트로 사전 고정; 세그 부재 시 기하 투영 검사)로 판정한다.
   씬 설정 기반 판정(주말 H_CUE_AUDIT 방식)은 상한 참고치로만 쓴다 — 씬 단위로 지도하면 화면 밖 단서
   프레임에 양성을 주게 되어 억지 지도가 부분 재발한다.
6. **cue_* 배선 커버리지는 보장이 아니라 감사 대상**: 주말 실증 — s14 가드는 구조물이라 토글 불가,
   CUE-OFF 가용 씬은 3개뿐이었다. 씬 설정은 git 미포함이므로 **로컬 커버리지 감사가 렌더 계획(P-5)의
   선행 입력**이다. 신규·개편 씬은 cue_* 토글 + 가드 구조물/장식 사전 분류를 표준 장비로 제작한다.
7. **P-4 "v2 재현 검증"의 정확한 의미**: 같은 숫자의 재출현이 아니라 **"지표 교체가 결과를 만들지
   않았음"의 증명**이다 — 신지표를 v2 기존 런에 적용(에폭 체크포인트가 로컬에 보존돼 있으면 재선택,
   미보존이면 resnet34 3런 한정 재훈련)하여 구지표 선택 대비 성적 차이를 보고한다. 차이가 시드 σ
   이내면 통과.
8. **계기판 ③의 v2 기준점 생성**: "v2에 N-cue 표본 없음"으로 끝내지 말 것 — **v2 체크포인트를
   test-ext(N-cue·측방·paired-H)에 zero-shot 재채점**하여 진짜 before를 만든다. test-ext는 v2·v3
   양측 모두 미학습이므로 공정 비교가 성립한다(장식 보존 off팔 FA .681은 보조 참고치로 격하).
   부칙: sceneC2 재설계판은 진단·대조 전용으로 유지(훈련 미편입) · 레시피 v2의 정본은 문서 서술이
   아니라 `runs/*/config.json`+코드다 · 구판 `PROJECT_STATE_0823.md` 상단에 "본 문서는
   PROJECT_STATE_0823_v2로 대체됨" 배너 1줄을 append한다(승인된 정정 권한 내·append 원칙 부합).
9. **계기판의 무대는 test-ext 4팔이다**: 계기판 ①②③의 v2/v3 비교는 양 모델이 공히 학습하지 않은
   test-ext 씬의 4팔(평가 전용 렌더)에서만 수행한다. 훈련 코퍼스의 B·C팔로 계기판을 재면 v3만
   분포-내가 되어 비교가 구조적으로 기운다. test-core는 헤드라인 표·FA-정합 전용이다.
