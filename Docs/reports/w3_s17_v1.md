### 2.3 Why 25.6 m and not 30 m

Two Korean numbers bound the choice, both already verified **in this repo** — no new statute was
fetched:

1. **Gradient.** 편의증진법 접근로/경사로 ceiling is **1/12**; the **1/8** relaxation requires **all
   three** of 기존시설 · 높이 ≤ 1 m · 상시보조서비스 (`Docs/surveys/cue_arrangement_survey.md:148`
   `[확인]`). **None holds here** — so 1/8 is used for what it is: **the steepest gradient the Korean
   accessibility code ever names.** The alternative, 30.0 m → 10.67 %, is a gradient **no Korean
   standard names at all**, i.e. an invented number, which is precisely what RF-5's *"not an invented
   yellow"* rule forbids. A named number with a declared deviation beats an unnamed one.
2. **Rest landing.** 조경설계기준 LDS-2016 5.9 경사로 (4) — a **1,500 × 1,500 landing every 30 m** of
   continuous ramp (`Docs/surveys/s3_research_numbers_v1.md` §217, source grade **A**). Landings are
   **CANCELLED for 02 · 03 · 17** (`w3_execution_spec_v1.md` §6.1-1/2/5/8/9/10). **The outgoing 40 m
   ramp therefore owed a landing it did not have.** At 25.6 m none is owed — so the shortening
   **closes a live code defect** instead of inheriting it. This is the strongest argument for the
   lever and it was not in the intake.

The scene now carries **two declared below-code realities** in one docstring block, the second new:
the ramp's river-side **kerb-not-guard** (pre-existing) and the **12.5 % gradient**. Declared, not
smoothed, on the precedent the file already set.

**The ramp deck is a walked surface.** The scene's own walking-continuity table has called it

GT-27 is declared FULL.

**What did *not* move**, which is why the flight's freeze matters:

* the scene's negative obstacle — crest shoulder **x = 0.00, fall 3.200 m** — unchanged;

* the crest cope stays an **`up_step`**, never a drop (GT-1's labelling rule, now asserted in code);
* one drop row changes value and is **stated, not hidden**: `ramp_river_edge`, the below-code kerbed
  edge, worst lateral fall **1.530 → 1.501 m (−29 mm)**, above `GT_DELTA` 0.020 and a *reduction*.
