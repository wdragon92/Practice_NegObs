- 샘플: 폭 U(0.50,1.10) · 깊이 U(0.28,0.40) · 간격 U(0.05,0.30) ·

### [기하 판단 — 브리프 "경사 30°" 의 해석]

순수 갈지자는 **수평 진행이 없다**(평면 x −1.40..4.40 안에서 6.60 하강 = 유효 56°).
따라서 계단 구간의 지면은 기하학적으로 연직일 수밖에 없다. 이를 은폐하지 않고
**공원 절토 석축 옹벽**으로 실체화했다:
- 머리 옹벽 `UpperBody` (x = −1.5 면, y −1.60..1.45, 0 → −6.62)
- 측면 옹벽 `BankCut` (y 1.45..2.60, 상면 0, 하단 −7.40)

브리프의 30° 사면은 **주변 지형**이 그대로 충족한다(둘 다 SMOKE 표에서 각도 재계산):
- 북측 `NorthBank` (y 2.60 z0 → y 15.0 z 7.16) = **30.0°**
- 남측 `SouthBankCap/Body` (y −1.60 z0 → y −13.0 z −6.62) = **30.1°**

Y 방향 사면은 `build_slope`(X 전용)로 만들 수 없으므로 씬 로컬 `ybank()` 를 신설했다
— `sc._oriented_box(rotx)` 기반, 두께 방향 오프셋을 `(0, sinθ, −cosθ)` 로 보정.
(`build_slope` 의 Y 대응물. scene_common 무수정 원칙 유지.)

### [보행 연속성 — SMOKE 전수 재계산]

14개 링크 전부 단차 ≤ riser 0.165 → **최대 단일 단차 0.165 m OK**.

```
상부 트레일 0.000 → 진입 데크 −0.005 (0.005) → 플0 1단 −0.165 (0.160)
플0 1단 → 플0 10단 −1.650 (×9, 0.165) → 참0 −1.650 (0.000)
… 4플라이트 반복 … → 참3 −6.600 → 하부 산책로 −6.620 (0.020)
```
참에서의 방향 전환 동선 `(x_bot, −0.70) → (참 중앙, 0) → (x_bot, +0.70)` 이 참
y ±1.40 안에 완전히 들어감(대역 커버 검사 OK). 상·하 플라이트 연직 여유 **3.01 m**.
