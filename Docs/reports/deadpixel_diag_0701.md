`h1.8_d5` 에서 포장(L>0.70)만 골라 행 밴드별로 잰 값:

| 행 밴드 | 화면 휘도 L | 국소std 중앙값 | **c**(=상대 알베도대비) | dead |

### (C) 참고 — 실사 기준선이 바뀌었다

`scripts/imgstats.py` 가 오늘 갱신되며 `REAL_N54` 가 들어왔다. 실사 **n=54** 실측은
`flat_gnd` **3.881 ± 5.005 (중앙값 1.79)** 이고 **실사의 46 % 가 목표 3.0 을 통과하지
못한다.** 브리프의 "실사 0.1 %" 는 화강석 광장 사진 2장의 이상치였다. 목표 3.0 자체는

한다"는 논거는 더 이상 성립하지 않는다.**

## 5. `bump_factor` 상향이 왜 안 통했는가

### 판정: **원리상 그늘에서는 통할 수 없다. 실측이 그대로 나왔다.**

#### 이론

디퓨즈 표면의 출사 휘도는 `L_o = (ρ/π)·∫ L_i(ω)(n·ω)⁺ dω` 다.

- **직달광(태양)** 아래: `L_o ∝ (n·s)`. 노멀을 `δθ` 기울이면 상대 변동이
  `δθ·tanθ_i` 로 **크게** 생긴다. → 노멀맵이 대비를 만든다.
- **균일 반구 스카이돔(앰비언트)** 아래: `∫(n·ω)⁺dω = π` 이며 **이 값은 n 의 방향과
  무관하다**(반구가 전부 보이는 한). → **노멀 섭동의 기여가 정확히 0 이다.**

그늘 = 직달광 성분 0 = 조명이 앰비언트뿐. 따라서 **`bump_factor` 는 그늘에서
원리적으로 무효**다. 노멀맵은 기하가 아니므로 **앰비언트 오클루전도 만들지 못한다**
(실제 자갈은 앰비언트에서도 자기그림자로 대비가 살지만, 노멀맵 자갈은 안 산다).

#### 실측 — 동일 재질·동일 행대(`temple_walk` y340–410, 자갈마당)

| 변종 | 영역 | 화면 L | 국소std 중앙값 | **c** | dead |
|---|---|---|---|---|---|
| `p2g3_on` (gravel bump 1.0) | 양지 | 0.6850 | 0.00900 | 0.0292 | 0.2 % |
| `p2g4_on` (gravel bump 1.4) | 양지 | 0.6767 | 0.00980 | **0.0321 (+10 %)** | 0.1 % |
| `p2g3_on` (bump 1.0) | 그늘 | 0.1174 | 0.00347 | 0.0483 | 74.3 % |
| `p2g4_on` (bump 1.4) | 그늘 | 0.1134 | 0.00328 | **0.0468 (−3 %)** | 82.1 % |

**양지에서만 +10 %, 그늘에서는 −3 %(= 노이즈).** 예측 그대로다.

밝기대별로 씬 전체를 봐도 같다(scene07, 하단 2/3):

| 밝기대 | 면적 % | dead % `g3_on`(bump 1.0) | dead % `g4_on`(bump 1.5/1.6) |
|---|---|---|---|
| 심음영 L<0.06 | 7.5 | 39.2 | **38.9 (−0.3)** |
| 음영 0.06–0.15 | 16.1 | 18.8 | **25.4 (+6.6, 악화)** |
| 반음영 0.15–0.30 | 12.2 | 14.8 | 9.2 (−5.6) |
| 중간 0.30–0.50 | 29.5 | 0.1 | 0.1 |
| 양지 0.50–0.75 | 20.9 | 7.7 | 6.9 |
| 고휘도 >0.75 | 13.7 | 3.4 | 2.7 |

**심음영은 0.3 p 밖에 안 움직였고, 음영대는 오히려 6.6 p 악화**했다(§6 의 어두워짐으로
반음영 면적이 음영대로 밀려 내려온 것). scene07 은 죽은 픽셀의 **~80 % 가 L<0.30**
이므로 net 이 0 이 될 수밖에 없다.

**반례가 이 진단을 확정한다 — scene01 에서는 bump 가 통했다.** scene01 포장은
**직사광 아래**이고, 고휘도(>0.75) 대역 dead 가 `g3_on 15.8 → rf_on 7.8 → g4_on 5.9 %`
로 단조 개선됐다. **같은 처방이 양지에서는 듣고 그늘에서는 안 듣는다** — 이보다 깨끗한
대조군은 없다.

### 그러면 그늘에서는 무엇이 답인가

임계 조건을 밝기의 함수로 풀어 두면 처방이 자동으로 나온다. 렌더 출력은 sRGB 인코딩
되어 있으므로, 선형 알베도 상대대비 `c` 와 화면 국소std 사이에는

> **σ_out ≈ 0.4167 · (L + 0.055) · c** → 죽지 않으려면 **c ≥ 0.00941 / (L + 0.055)**

| 화면 휘도 L | 필요한 상대 알베도대비 c |
|---|---|
| 0.03 | **0.111** |
| 0.06 | 0.082 |
| 0.10 | 0.061 |
| 0.15 | 0.046 |
| 0.25 | 0.031 |
| 0.40 | 0.021 |
| 0.60 | 0.014 |
| 0.85 | **0.010** |

즉 **그늘은 양지보다 5~10배 강한 알베도 대비를 요구한다.** 그늘에서 쓸 수 있는 무기는
셋뿐이고, 우선순위는 다음과 같다.

1. **알베도(디퓨즈) 대비 — 유일하게 확실한 수단.** 밝기에 곱해지는 성분이라 그늘에서도
   비율이 유지된다. 구체적으로는 ① 고대비 텍스처 조달 ② **텍셀 밀도 완화**(같은
   텍스처라도 `scale_m` 을 키우면 화면 축소율이 낮아져 c 가 오른다).
   scene07 자갈은 `scale_m=0.35 m` → **0.7~0.9 m** 로 올리는 것만으로 축소율이
   절반이 되고, 실측 c 는 축소 1/64 0.102 → 1/16 0.314 구간으로 이동한다.
   그늘 자갈의 현재 c 는 **0.047, 필요값은 0.055** — **17 %만 더 올리면 넘는다.**
2. **실제 기하(변위) — 앰비언트에서도 자기그림자를 만든다.** `scene_common` 에
   `_ground_skin`/`_SKIN_CLASSES`(paving·concrete·asphalt·soil·gravel·stone) 가
   이미 있다. 노멀맵과 달리 **AO 를 실제로 만들므로 그늘에서 유효한 유일한 셰이딩
   수단**이다. 다만 비용이 크고 낙차 기하를 건드릴 위험이 있다(`_SKIN_DENY` 참조).
3. **그늘 자체를 얕게 만들기**(`dome_intensity` 1000 → 1200~1400). **권장하지 않는다** —
   낙차 공동의 어두움은 이 프로젝트의 핵심 GT 단서다.

**하지 말 것: 앰비언트 오클루전 강화, 간접광 색 변동 주입.** 전자는 노멀맵에서
나오지 않고(기하가 필요), 후자는 5×5 픽셀 대역이 아니라 미터급 저주파라 D3 의
`macro_amp` 와 같은 대역 오류를 반복하게 된다.

## 6. [신규 발견] 텍스처 승격 경로의 색공간 불일치 — 승격 재질이 2~3.6배 어두워진다

D3 처방(상수색 → 역할 텍스처 승격)을 구현한 `_promote_const_to_texture()` 에 버그가 있다.

```python
# scene_common.py  _texture_mean()
a = np.asarray(im).astype(np.float64) / 255.0      # ← JPEG 원본 = sRGB 인코딩 값
v = tuple(a.reshape(-1, 3).mean(0))                # ← sRGB 공간 평균

# scene_common.py  _promote_const_to_texture()
bc = diffuse_color / tm                            # ← 선형 알베도 ÷ sRGB 평균
```

한편 MDL 은 `_tex("diffuse_texture_a", diff, "auto")` 로 바인딩되어 **텍스처를
sRGB→선형으로 디코딩한 뒤** `base_color` 를 곱한다. 따라서

> `E[알베도] = E[tex_linear] × diffuse / E[tex_sRGB] = diffuse × (E[linear]/E[sRGB])`

| 텍스처 | E[sRGB] | E[linear] | 비율 | **승격 재질이 어두워지는 배수** |
|---|---|---|---|---|
| `concrete_wall` | 0.504 | 0.221 | 0.433 | **×2.31** |
| `stone_flag` | 0.469 | 0.188 | 0.401 | ×2.49 |
| `paving_interlock` | 0.552 | 0.268 | 0.486 | ×2.06 |
| `gravel` | 0.518 | 0.249 | 0.463 | ×2.16 |
| `dirt_park` | 0.369 | 0.125 | 0.315 | ×3.17 |
| `asphalt` | 0.346 | 0.100 | 0.288 | **×3.47** |
| `brick_red` | 0.306 | 0.088 | 0.275 | ×3.64 |

### 실측 검증 — scene07 원경 능선(`Ridge/Crest` → concrete 승격, roughness 0.95, specular 0)

`h0.9_d2` 상단 3개 밴드, 선형 휘도 기준 `g3_on → g4_on`:

| 밴드 | `p2g3_off` L / dead | `p2g3_on` L / dead | `p2g4_on` L / dead | 선형 비 g3→g4 |
|---|---|---|---|---|
| 능선A y30–60 | 0.2775 / **100.0 %** (국소std **0.00000**) | 0.2714 / 48.4 % | 0.1396 / **67.7 %** | **0.289** |
| 능선B y95–130 | 0.1758 / 85.7 % | 0.1729 / 63.9 % | 0.0853 / 70.3 % | **0.312** |
| 능선C y150–180 | 0.3043 / 99.0 % | 0.2133 / 31.2 % | 0.1076 / 46.3 % | **0.301** |

**세 밴드 모두 선형 0.29~0.31 배로 어두워졌고, 그 결과 dead 가 g3 보다 나빠졌다.**
색공간 불일치 단독 예측치는 0.433 이므로, 나머지 0.7 배는 웨더링 `grime 0.35` ·
`desat_bright 0.30` 등 승격 시 함께 켜지는 항목의 기여로 본다 **[추정]**.

`flat_gnd` 는 `σ_out ∝ (L + 0.055)` 이므로 **밝기를 3배 깎으면 국소std 도 거의 3배
깎인다.** 텍스처를 붙여서 얻은 대비를 어두워짐이 그대로 상쇄한 것 — 이것이
`scene07 9.51 → 10.00` 역행의 직접 원인이다.

> D3 에서 이 버그가 드러나지 않은 이유: 아스팔트 텍스처의 c 가 0.15~0.24 로
> 압도적이라 3.5배 어두워지고도 임계를 크게 넘겼다(노면 실측 `g3_on` L 0.571
> c 0.128 dead 30.9 % → `g4_on` L 0.479 c 0.222 dead 4.7 %). **그러나 D3 노면의
> 의도 알베도 `(0.16,0.16,0.17)` 도 지금 3배 훼손된 상태다.** 지표는 통과했지만
> 물리적으로는 틀렸다 — 이 수정은 D3 를 포함한 전 씬에 필요하다.

**수정(3줄)**

```python
def _texture_mean(path):
    ...
    a = np.asarray(im).astype(np.float64) / 255.0
    a = np.where(a <= 0.04045, a / 12.92, ((a + 0.055) / 1.055) ** 2.4)   # ← 추가
    v = tuple(float(x) for x in a.reshape(-1, 3).mean(0))
```

**주의**: 이 수정은 승격된 전 재질을 2~3.6배 **밝게** 만든다. 알베도 클램프
`min(2.5, ...)` 에 걸리는 재질이 생길 수 있으므로 상한을 함께 재검토하고,
`sceneD3` 를 포함한 전 씬 재렌더 회귀가 필요하다.

## 7. 처방 (우선순위 = 면적 × 실현가능성)

### scene07

#### S7‑P0 — `LOOK_CLASS` 의 `veg`·`wood`·`metal` 에 `tex` 키 부여 · 면적 3.87 · 실현가능성 **높음**

지금 이 세 클래스는 `_CONST_MDL_CLASSES` 에 들어 있으면서 `tex` 가 없어
**승격 시도조차 못 한다.** 전부 저장소에 이미 있는 텍스처다(신규 조달 0건).

```python
# scene_common.LOOK_CLASS
"metal": dict(bevel=0.002, sat=1.00, mdl="omni", detail=True,
              tex="metal_rust", bump=1.2),      # c 0.29~0.50 — 대비 충분
"wood":  dict(bevel=0.004, sat=0.88, mdl="omni", detail=True,
              tex="wood_dark", bump=1.3),       # c 0.086~0.131
"veg":   dict(bevel=0.000, sat=0.76, mdl="omni", detail=False,
              tex="leaf_ground", bump=1.2),     # c 0.40~0.67 — 최상위권
```

- `_promote_const_to_texture` 는 **의도 알베도를 보존**하므로(§6 수정 후) 색은 그대로다.
- `veg` 에 `leaf_ground` 를 물리는 것은 수관·관목에 **잎 겹침 대비**를 주는 것이고,
  이미 같은 씬의 낙엽 사면이 c 0.63 / dead 6~11 % 로 잘 작동한다는 증거가 있다.
- **주의**: `veg` 승격은 `_make_ground_pbr`(NegObsGround) 경로로 라우팅된다. 수관은
  불투명 타원체라 opacity 가 필요 없어 안전하지만, **투명 잎 카드를 쓰는 씬이 있으면
  제외 규칙이 필요**하다. 전 씬 확인 후 적용할 것.
- **`metal` 은 신중히.** `Rail`(스테인리스 `(0.80,0.82,0.85)`)·`Lamp` 에 녹 텍스처를
  씌우면 훼손이다. `metal` 은 면적이 작으므로(scene07·01 합쳐 0.1 미만) **이번
  라운드에서는 손대지 않는 편이 옳다.** 우선순위는 `veg` ≫ `wood` ≫ `metal`.
- `Roof`(목조 기와)는 `LOOK_ROLE` 에서 `metal` → 별도 처리로 재분류(`brick` 또는
  전용 `tile` 역할). 녹슨 금속 텍스처를 기와에 씌우면 개선이 아니라 훼손이다.

**예상 효과 −3.5** (10.00 → 6.5)

#### S7‑P1 — §6 색공간 수정 · 면적 ≈0.9(scene07) · 전 씬 파급 · 실현가능성 **높음(코드 3줄)**

승격 재질이 3배 밝아지면 `σ_out ∝ (L+0.055)` 로 국소std 가 거의 3배 회복된다.
**S7‑P0 보다 먼저 적용해야 한다** — 안 그러면 P0 로 붙인 텍스처도 똑같이 3배 어두워진다.

**예상 효과 −0.9** (6.5 → 5.6)

#### S7‑P2 — 자갈 텍셀 밀도 완화 · 면적 2.09 · 실현가능성 **높음**

```python
# scenes/main/scene07_temple_stone_path.py  PARAMS["material"]["scale"]
scale=dict(rock_wall=3.5, rock_face=0.95, granite=3.2, leaf_ground=2.0,
           gravel=0.80,   # ← 0.35 에서 상향. 4096px/0.35m = 11 700 texel/m 는 과밀
           grass=4.0),
```

그늘 자갈의 현재 c 는 **0.047**, 필요값은 **0.055** — 17 % 만 더 올리면 임계를 넘는다.
축소율이 절반이 되면 실측 c 곡선상 **0.10 → 0.19 구간**으로 이동하므로 여유 있게 통과한다.
**반복 티가 나면** `patch_mix=1.0`(gravel 은 이미 1.0) 이 90° 패치 혼합으로 깨 준다.

## 9. 방법 (재현용)

```python
rgb = imgstats.load(path)              # 긴 변 1024 LANCZOS, RGBA→RGB
g   = imgstats.lum(rgb)
ls  = imgstats.local_std(g, 5)
dead = ls < 1/255
dead[:g.shape[0]//3] = False           # 하단 2/3 만
```

- **하늘 마스크**: 최상단 행을 씨앗으로 `(b > r + 0.03) ∧ (L > 0.30)` 위에서 4‑이웃
  flood‑fill. 하늘에 연결되지 않은 파란 유리창은 잡히지 않는다(검증: scene01
  `lower_lookback` 에서 유리창이 하늘로 분류되지 않음).
- **고형 vs 점묘**: 죽은 픽셀의 15×15 국소 밀도 > 0.72 면 "고형"(= 상수색 재질 통짜),
  아니면 "점묘"(= 텍스처가 임계에 걸쳐 있는 상태). **처방이 서로 다르므로 이 구분이
  본 진단의 축이다.**
- **재질 귀속**: 정규화 RGB(색도) + 화면 휘도. scene07 은 `목재(cr>0.44 ∧ cb<0.245)` /
  `식생(cg>cr ∧ cb<0.305 ∧ L<0.30)` / `심암부(L<0.055)` / `지면(중성)`,
  scene01 은 `유리(cb>cr+0.006 ∧ L>0.40 ∧ 고형)` / `목재(cr>0.40 ∧ cb<0.27)` /
  `심암부` / `음영부(L<0.40)` / `포장`.
- **연결성분**: 4‑이웃 런렝스 union‑find (numpy only).
- **시각 검증**: `mat_*.png` 27장 전수 육안 대조 완료.
- **상대 알베도대비 c**: `c = median(local_std) / (0.4167·(L+0.055))`.
  sRGB 인코딩의 미분 `d(sRGB)/d(linear) = 0.4396·L_lin^(-0.5833)` 에서 유도.

## 10. 감독 결정이 필요한 항목

1. **`gate_frame` 하늘 1.46 (scene07 예산의 38 %)** — 인정 / 뷰 피치 하향 / HDRI 교체.

3. **`veg` 텍스처 승격의 라우팅 위험** — 투명 잎 카드 사용 씬 전수 확인 후 적용.

5. **목표 3.0 의 근거 재확인** — `imgstats.py` 갱신본의 실사 n=54 실측은
   `flat_gnd` 중앙값 1.79 / 평균 3.88 이고 **실사의 46 % 가 3.0 을 통과하지 못한다.**
   "실사 0.1" 은 사진 2장의 이상치였다. 목표치 자체는 유지 가능하나 **논거를 교체**해야 한다.
