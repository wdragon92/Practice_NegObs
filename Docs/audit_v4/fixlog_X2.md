## 3. scene07_temple_stone_path — "그림자가 근경 마당으로 이동"

### 3-1. 원인 규명 — v6 주석의 **1점 투영 오류**

v6 는 "처마 그림자는 x ≈ 0.69 에 떨어져 배석 1~2석만 스친다"고 적었다.
이것은 **처마 끝선 1점만** 투영한 값이다. 지붕은 면이므로 그림자는 띠다:

```
일주문 = 주지붕(x cx±1.55, y ±2.35, z 3.38…4.00)
        + 부연(x cx±1.85, y ±2.57, z 2.81…3.55)   ← 더 넓고 더 낮다
그림자 이동 = −(cos az, sin az)·z·0.8455
구 az 225 · cx −3.0 → 발자국 x −3.17…+0.57 · y ≥ −0.89
h0.3_d2 하반 지면대(프레임 아래절반이 찍는 마당) = x −1.44…−0.30 · 반폭 ±0.33
  ⇒ 지면대가 발자국 **안에 통째로 들어간다** = 하반 mean 27.5 의 정체
h0.9_d5 지면대 x −3.31…+0.10 도 동일
```

부연 반폭(2.57 m) > 최대 그림자 이동량(2.81×0.8455 = 2.38 m)이므로
**태양 회전만으로는 워크라인을 원리상 비울 수 없다.** 세 축을 함께 썼다.

```
화각 내 공원 앵커 3개 : 북측 잔디사면 y4 · 이정표 · 벤치
```

프레임 상단(+2.0° 앙각)이 옹벽 갓돌 너머 **북측 30° 잔디 사면**을 담는다.
수직 구성 추정: 잔디 사면 ≈ 25 % / 데크(플라이트0 −7.7° … 참1 −24°) ≈ 45 % /
옹벽면 ≈ 28 % — 구 컷의 "조적벽 + 갈색 목구조 일색"에서 벗어난다.

### 4-3. `broken_rail` — 남측 회전 (판정 ② 대조쌍 판독 난이도)

시선 135°(법선 315° · lambert +0.273 — 파손/정상 난간이 같은 어두운 대역)
→ **112°(법선 292° · +0.480)**. eye (6.3,−2.1,−0.55) → **(5.60,−3.40,−0.30)**.

**4.95 m 낙차의 깊이가 프레임에 남는다.**
