## 1. 확정 사실 — 08-23 주말 창 반영 (전부 출처 원장 있음, MR23 §2)

1. **본 표 v2의 정직한 독법**: τ=0.5 단일 열 비교는 문턱 착시 — FA-정합 시 **전 지점 Depth ≥ RGB**
   (FA .10: .510 vs .326). 살아남는 문장: "RGB는 FA 10% 예산에서 은닉 프레임 1/3 회수(0이 아님)."
   구판 §5.1 "RGB .688 우위·YOLO 구성적 상한"은 **폐기** — YOLO의 E/H=0은 어댑터(det2cell)의 성질이며
   어댑터-프리 H 적중은 0.066이다(METRICS §RT.3).
2. **씬 연합 진단(3중 수렴)**: 트윈-조건부(RGB 적중 44.7% 무조건부 · Depth 96/96 위험-조건부) ·
   CUE-OFF 개입(사전등록 CUE EVIDENCE 0 · 오경보가 단서 개수 아닌 광학 변화량 추종) ·
   Gazebo(위험 0픽셀 발화 · 티어 사다리 역전 5/6). 구판 §6-4의 "H recall = 단서 추론 시사"는 **폐기**.
3. **통계 회계**: H는 test 2씬(효과는 scene14 집중), E는 단일 씬 — H·E CI는 **철회**(축소 아님).
   구판 §5.2 "9/9 CI 0 배제"는 **폐기**. aux "유의 이득" 주장도 철회(헤드 자체와 진단적 활용은 별개 — DZ §5.3).
4. **H 주장 범위**: 3b(전방형·단서 동반) 한정. 3a(발밑형)의 트윈 Δ≈0은 11포즈 균일 — 시점 아티팩트 아님.
5. **근거리는 주장 범위 밖(이유 구분)**: band1 사각·3a 무반응 = 관측 규정(전방 고정 포즈)의 **시야각
   인공물** / 근거리 E = 스침각이 서서 내부가 보이므로(대체로 V) **기하상 불성립**(개구 1–3cm 필요).
   낙차 고유의 난점은 정반대인 **원거리 소실**(가시 개구 ~1/d², DZ §1). 근거리 해법 = 동영상 전파
   (승용 로드맵). 실측 평가는 20칸 중 15칸(밴드1 주석 불가 — 채점 분모 제외, 모델 출력은 존재).
6. **코퍼스 결함(수리 대상)**: G7 — boost 6씬 높이맵 미융합(s12 "strict-H" 48프레임은 실제 티어 V).
   본 표 recall 분모 미오염 확인. **v3 1단계에서 재융합+재라벨** `[승용 결재 4]`.
7. **레시피 결함(수리 대상)**: 체크포인트 선택식이 H-blind(val strict-H 6프레임) — convnext 2/3시드
   상수출력 붕괴로 발현, 본 표에도 해당. v3 선행 수리 P-4.
8. **기타 확정**: V2S(10섹터) 사전등록 판정 ROLLBACK(V1 유지 — 재론 조건: 측방 씬 test 편입, DZ §4.2) ·
   광도 증강 불요(과노출만 비가역 — 파일럿 수칙 P1–P3) · 융합행 E/H +0.000(부록) · 신규 인코더 무이득(부록) ·
   sceneC2는 distinct-input 8 + 장식(RGB 77%/Depth 44%) + 경사 통계 — v3 재설계 편입.
