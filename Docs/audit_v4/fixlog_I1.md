## 보류 · 제안 사항

### scene_common.py 수정 제안 (읽기 전용 준수로 미적용)
1. **`build_tree(..., stakes=True)` 인자 추가.** 현재 지지대 3본이 무조건 생성돼
   성목·원경 나무에서 비현실적이다. scene03/04는 부득이 `stake_r 0.004 · stake_h 0.02`
   로 무력화했으나(프림 3개/나무 낭비), 인자 하나면 깨끗하다. scene01은 자체 build_tree라
   `stakes` 플래그로 처리 완료.
2. **`build_hedge`에 세그 분할/높이 지터 옵션**(또는 `build_hedge_cluster`).
   전 씬에서 '검은 상자' 대응으로 같은 중첩 코드를 반복 작성했다.
3. **`build_arc_steps`에 `refinementLevel` 설정 헬퍼**는 불필요(아크 세그로 대체 가능)이나,
   `add_cylinder`에 `refine` 인자를 두면 scene05 같은 원반 다각형 문제를 근본 해결 가능.

### 렌더 후 재확인 필요 (감독)
- **scene02 터널 형광등 광량**(intensity 1500, r 0.12 × 3). 렌더 없이 정한 값이라
  PT 8바운스에서 과다/과소 가능. 암부 그라디언트가 이 씬의 판정 포인트이므로 1차 렌더에서 조정 권장.
