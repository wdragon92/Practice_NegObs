## 5. 실세계 유사성 — 조사 3편 종합

### 5.1 sim-to-real 문헌 (출처 21편 — JSON research[0])

- **승리 조합은 항상 "구조는 사실적, 저수준 외형은 랜덤"**(SDR 52.5 vs 순수 DR 23.9 vs 타 도메인
  실사 45.6, KITTI Hard AP). 북극성 "있을법한 환경" = SDR 정의와 일치.
- **씬 33개는 사형선고가 아니다** — HSSD: 고품질 122씬이 절차생성 10,000씬을 제로샷에서 압도.
  병목은 씬 수가 아니라 **씬당 조건 축의 수**.
- **조명이 단일 축 1순위**(ablation 최대 하락 −6.1 AP; 조명 틀린 PBR 은 법선 오차 28.8°→49.3°).
  현 코퍼스는 30/33씬 태양고도 동일·32/33 동일 HDRI = 단일 순간. **그런데 variation_kit 에 조건
  8종·연속 카메라 샘플러가 이미 구현·검증돼 있다** — 남은 것은 개발이 아니라 **예산 배분 결정**.
- **센서 효과 후처리가 최고 ROI**(색수차·블러·노이즈·색온도 후처리만으로 +7.3 AP, 증강 2,975장 >
  무증강 50,000장). GPU 0, 렌더 재실행 0. 단 일반 기하 증강(회전·크롭)은 오히려 −3.1 = 해로움.
- **컷 수는 답이 아니다** — 10~17.5k 에서 포화, 70k 는 하락. 20k 예산은 적정선이며 증분은
  전부 조건 축에 쓸 것.
- **최대 방법론 공백 = 실사 평가셋 부재.** 전이가 되는지 측정할 수단 자체가 없다. 라벨 없는 실사
  수백 장이면 FDA(저주파 스왑, +7.7 mIoU)도 가능. 지름길 감사 스위트(휘도↔GT깊이 상호정보,
  지평선 행 분포 — 현 297컷 지평선이 단일 픽셀 행 247, 마스킹 프로브)는 렌더 0으로 구축 가능.

### 5.2 한국 보행환경 실물 (법령·시방서·논문 근거 — research[1])

- **핵심 반전: GT-107(데칼 정온)의 원인은 요소 부재가 아니라 위치 규칙 부재.** 구현체(stain 8종·
  crack·patch·joint)는 전부 존재한다. 실물 오염은 무작위가 아니라 규칙적이다:
  백화=줄눈·이음·그늘·누수 경로 / 물때=배수 구배 하류(횡단경사 1/50 → 항상 연석 방향) /
  녹물=난간 앵커 직하 / 토사·잡초=측구·연석 접합 / 아스팔트 패치=직사각 절삭 경계 /
  균열=차륜 나란한 종방향·시공 줄눈. → **"위치를 한 문장으로 설명 못 하면 미발행" 게이트**로
  재발행하는 것이 "자연스럽게" 갈래의 실행형.
- **밀도 규약 전환**: 실물 보도 파손·보수 최소 단위는 1㎡ 직사각(도로학회 2017) — 개수↓·개당
  면적↑ 이 실측 정합. 소면적 점상 다수 = "카펫 조각" 판정의 구조적 원인.
- **Tier 0(기하 0·데칼 0)이 가장 싸고 크다**: 동선 마모 roughness 이분화(승강장·지하도·계단 —
  "때"가 아니라 광택차가 실물 단서), 판별 톤 편차(화강석 흡습 얼룩·데크 회색화), 디테일 노멀 확대.
- 근거 있는 기하 소액: 옹벽 배수공(3㎡당 1개 — 위치가 구조에서 유도되는 유일한 벽면 얼룩),
  골목 도시가스 황색 입상관(다세대 시그니처, 사인 아님 — s15 처분과 묶어 선신고 권장),
  s13 램프 벽면 30cm 연석·거친 노면(주차장법 별표1 명문).
- 불채택 권고: 껌 자국(밀도 근거 없음·조형물 상한 충돌), 침수 뻘(이벤트성), 보행면 침하 기하
  (낙차 라벨과 경쟁하는 노이즈).

### 5.3 Isaac/RTX 기법 — slope 정면 대응 (research[2], 실측 다수)

- **slope 지표의 실효 대역을 역산으로 특정: 화면 7.5~15px = 지상 1cm~75cm(중심 2~10cm).**
  현행 알베도 변조 노브 3개(macro 14m·patch 4m·rough_noise 1.2m)는 전부 대역 위, detail
  normal(8cm 타일 텍셀 0.078mm)은 100배 아래(PT 64spp 가 평균화 → 소멸). **"flat% 는 좁혀졌는데
  slope 만 그대로"의 기계적 설명.**
- **실측 주입 실험: 대역 내 알베도 대비 3% RMS 만으로 slope −2.251→−2.049(실사 −2.03),
  flat_gnd 5.34→3.03 동시 개선, 부작용 0.** 최저가 레버 = `scene_common.py:1842` 한 줄
  (macro_wavelength 14→0.4~0.6m). 정밀 레버 = MDL 절차 알베도 그레인 신설(페치 0, 기본 0 규약).
- **렌더 설정이 재질보다 클 수 있다**: 블러 0.8px = Δslope −0.45(격차 전체보다 큼). PT AA
  filterRadius 기본 1.0(실질 바이리니어)·디노이저 blendFactor 기본값 모순은 **A/B 1라운드로 확정
  필요**. ⚠ **PT-fast 등가성 근거 스파이크의 PT 3종 6파일 md5 가 전부 동일 — "화질 동등" 근거가
  검증 안 된 상태일 수 있음. 재검증 요청**(사실 확인이며 판정 아님).
- 에지 웨어 마스크: `rounded_corner_normal` 편차 재활용 = **비용 0으로 연석·노징 탈색 띠**(낙차
  에지 RGB 단서 직접 강화). 헥스 타일링: MDL 구현 가능(hash2 재사용 예고 주석 존재)하되 지표
  무관 — 육안 전용으로 순위 매김. MDL displacement: 3중 조건+DMM deprecate 로 **비권고**,
  대신 변위 스킨 메시 조밀화(§2.3)로 같은 효과.
- **금지**: 언샤프로 지표 맞추기(+0.38 나오지만 육안 훼손 — 수치+육안 병행 원칙의 반례),
  절차 노이즈에 월드 z 사용(웨더링 z<0 사고 재발 방지 규율 승계).

## 6. "깔끔하게 바로잡는" 실행 로드맵 제안 (전부 선신고 대상 — 착수 판정 필요)

비용 오름차순·의존관계순. 괄호는 기존 큐와의 관계.

- **R0. 측정 기반 확정** (렌더 소량): 렌더 설정 A/B(AA 필터·디노이저) + PT-fast md5 재검증 +
  `look_report()` 에 실효 det_scale/unit_cell/far_override 노출. **이걸 먼저 하지 않으면 이후 재질
  A/B 판정이 전부 흔들린다**(§5.3).
- **R1. 배선 수리** (R-2 순수, 씬 무수정): W1 omni 밴드 배선 → W2 override 의미 정정 →
  W3 unit_cell 배선 → W4 use_blend 개방 → W5/W6 분류 규칙 → W7 발광 비발광 채널 분리.
  (레버1 2차 이월 3건이 W1·W2 에 정확히 걸려 있음 — 원장 행 64 의 정식 처리.)
- **R2. 클래스 재보정** (레버1 확산): snow/nosing/curb/metal 처방 + 알베도 밴드 양단화 +
  brick_red 0.87 확산(11씬) + 톤 상한 통합(0.34 vs 0.55) + macro_wavelength 대역 이동 +
  콘크리트 갈색 소스 교체(카펫 트랙). 파일럿 1~2씬 렌더 후 확산(§2.3 규율).
- **R3. 규칙 데칼 재발행** (GT-107 "자연스럽게" 갈래): 위치 규칙 6종 게이트 + 밀도 1㎡ 규약 +
  동선 roughness 이분화 + 앵커 하부 녹물. (GT-107 정온과 모순 아님 — 사용자 원문이 열어 둔
  두 번째 갈래의 실행형. 재발행 범위는 판정 사항.)
- **R4. 씬별 결함 수리**: §3-1 접지·관통·부유 17건(⚠ 표시 건은 건별 선신고) + §4 씬별 high.
  건물 관련(창 리빌·기단 개구·cam_h)은 **레버4/건물 재작업 트랙 입력**으로 귀속.
- **R5. 룩 v2** (기하·물리): 알베도 그레인 MDL + diffuse_roughness + grazing 감쇠 + 스킨 재조준
  (⚠ 위험 기하 3건 포함 — 전부 선신고·이격 증빙 선행).
- **R6. 데이터셋 층** (W5 생산 렌더 전 결정): 조명 8조건 예산 배분 + 센서 후처리 파이프라인 +
  지름길 감사 스위트 + 실사 평가셋 확보 + FDA. (렌더 예산은 §5.1 — 컷 수 아닌 조건 축에.)
