## 3. scene18 — 벽화(색칠) 계단화

`stair.phase` 0.4 → **0.25**, `stair.amp` 0.35 → **0.245**(30 % 축소). 5색 유지.
낙차 2.56 m(16 × 0.16) **불변**.

**치크월·상부 에지 세그 자동 추종 좌표 검증** — 신규 `_wave_selfcheck()`
(순수 수학, Isaac 부팅 불요. `NEGOBS_SMOKE=1` 시 부팅 전 출력). 실측 결과:

```
① 치크월 좌우 위상차  max|x(+4)−x(−4)| = 8.88e-16  → 동일(자동 추종 OK)
   치크월 x 구간(단 0) = [-0.0606, +0.3400] @ |y| 4.0..4.3
② 상부 세그 최소 폭   0.0520 m (x_cut=-0.295)  → OK
③ 직선 에지 여유      0.2550 m (x1=0.5, back_max=+0.2450) → OK
④ 하부 보도 겹침      0.1488 m (x0=5.05, front_min=5.1988) → OK
⑤ 노출 디딤 폭        0.2789 ~ 0.4011 m (구 0.201~0.479)
```

* **① 위상 동일성 재확인(신설 치크월 F-B 가정)**: k = 2π/wavelength = 2π/4 이므로
  y=+4 → sin(2π + iφ) = sin(iφ), y=−4 → sin(−2π + iφ) = sin(iφ). **파장 4 m 가 계단 폭
  8 m 를 정확히 2주기로 나누기 때문에 phase/amp 값과 무관하게 항상 성립** — 치크월이
  한 쌍의 x 구간(y1 기준)으로 좌우를 함께 만드는 현 구현이 유효. 수치로도 1e-15 수준.
* ② `x_cut = −amp − 0.05` 가 amp 를 함수로 참조 → 자동 추종(−0.40 → −0.295), 전 세그
  양폭 유지.
* ③④ 상부 직선 에지(x 0.5)·하부 보도(x0 5.05)는 상수지만, amp 축소로 여유가 오히려
  **증가**(0.15→0.255 / 0.04→0.149) → 매몰·슬롯 회귀 없음.
* ⑤ 1단 최소 노출 디딤 0.201 → **0.279 m**(브리프 목표 ~0.25 상회) = "표준 계단에 색만
  칠한" 인상.
