## 4. Phase 1 — 데이터셋 현황 지도 → `DATASET_STATE.md`

- 프레임 전수 인벤토리: 씬ID / 라운드 / RGB / depth / 폴라 GT / V·E·H 태그 / **raw 가시 데이터**(내부면 가시 픽셀 수, 경계 호 가시 비율 — A3의 raw 저장 원칙상 존재 예상) / 대응쌍 토글 상태(hazard on/off, cue 상태) / 카메라 포즈 메타 — 각 존재율 표.
- 결측 3분류: (a) 형식 문제 (b) 파생 가능(재료 있음) (c) 사람 필요.
- 씬 유형 분류 시도: 계단 본편 21 / batch1 12(비계단 낙차 4 포함) / 하드 네거티브(트롱프뢰유 등) — 씬명·메타 기반 추정, 아침 확인 표기 [A5].

## 5. Phase 2 — 보완 → `dataset_manifest_v1.json`

**원칙: 원본 무수정.** 파생물은 `WORKDIR/annotations/`에만. 스키마: `frame_id, scene_id, round, toggle_state, rgb, depth, polar_gt[15], raw_vis{int_px, edge_ratio}, tier, tier_source, gt_source, notes`.

- **폴라 GT 결측**: `SPEC_EXTRACTED.md`의 격자 상수·좌표 규약으로만 기하 투영 파생. **격자 상수가 [코드 미발견]이면 파생 금지 → (c) 사람 필요.** 파생 시 V 프레임에서 depth 불연속과 교차검증(일치율 보고).
- **V/E/H 태그 결측** [A3·A4]: raw 가시 데이터에서 파생 —
  1차 규칙(τ 비의존): 위험 기여 픽셀(내부면+림) = 0 → **strict-H**. 내부면 픽셀 > 0 → V 후보, 림만 > 0 → E 후보.
  τ_int·τ_edge는 [미확정 — 승용이 씬 점검으로 캘리브레이션하기로 결정]이므로: 코드 기본값이 있으면 그것 + 대안 2개, 없으면 후보 3개를 잡아 **티어 분포 민감도 표**를 만들고, strict-H 기준을 1차 라벨로 채택(`tier_source=strict` 표기). 최종 확정은 아침.
  raw 가시 데이터 자체가 없으면 (c)로 분류하되, semantic ID 렌더가 있으면 재계산 시도.
- **A3 부칙 준수**: 울타리·표지·주변 지면 조각은 티어 근거 아님 / 맞은편 안쪽 벽 가시 = V / 투과성 가림물(유리 등) 프레임 제외 / FOV 밖 = 제외(가림 아님) / 엣지 서브픽셀 소멸은 H 금지(거리 밴드 축 처리).
- **검증 게이트 (훈련 진입 조건)**: G1 매니페스트 필수 필드 결측 0(제외 목록 보고) / G2 hazard-off 프레임은 GT 전부 0, hazard-on 씬엔 양성 존재 / G3 strict-H 분포 정상성(0%면 플래그 — 헤드라인 표본이므로 개수 명시) / G4 층화 30프레임 오버레이 PNG(`audit_samples/`, V/E/H/off별) / G5 파생 폴라 GT의 V-프레임 교차검증 ≥ 80%.
- **A4 분리 원칙**: 훈련 의존성은 폴라 GT뿐. **τ 미확정·태그 보류는 훈련을 막지 않는다** — 층화 평가만 후보 τ 병산으로 대응.
- 게이트 미통과 → 훈련 보류 + `GAP_REPORT.md`(사람이 채울 것 항목별). CPU 트랙 계속.

## 6. Phase 3 — 잠정 씬 분리 → `split_v1.json` [A6]

- 분리 단위 = 씬이며, **같은 씬의 모든 토글 변형(hazard on/off·cue 변형 대응쌍)은 반드시 같은 분할** — 위반 0을 스크립트로 증명해 첨부.
- test = 씬 7±1개(20~25%): **strict-H 프레임 비중 높은 씬 ≥2 / 하드 네거티브(트롱프뢰유류) ≥1 / hazard-off 대응쌍 보유 씬 다수 포함**(무위험 평가는 test 씬의 off-변형으로 수행).
- seed 42, 기준 만족 조합 중 티어 분포가 전체와 가장 유사한 것 선택. "strict-H 비중 높은 씬" 판정은 씬별 strict-H 프레임 수 상위 정렬 기준.
- `SPLIT_PROPOSAL.md` 작성 — 상단에 "PROVISIONAL — 아침 승인 대상" 명기.

## 7. Phase 4 — 훈련 (RGB → Depth) [A9]

- 공통: `split_v1.json` / pretrained encoder / 512², batch 8 / seed 42 / val = train 중 2씬 — **val 분리에도 씬 단위 + 토글 변형 동반 규칙 적용**(patience 15, max 150ep) / **test 접근 금지**.
- **본 런 전 스모크 테스트 필수**: 훈련 50 step → 체크포인트 저장 → 평가 스크립트 1회 통과(숫자가 실제로 산출되는지 확인). 통과 후에만 본 런 — 통합 버그를 새벽이 아니라 초저녁에 잡기 위함.
- Depth 대조 공정성 [A9 확정]: 아키텍처·출력·학습 동일, 입력만 상이. depth는 시뮬 클린 depth 사용 [기본값 — 결과에 명시].
- LR: 캠페인 확인값(U-Net 3e-4) 명시 사용, 임의 튜닝 금지. 수렴 플래그 필수. 파생 GT 사용 시 `derived-GT` 태그.
- 시간 부족 시 우선순위: RGB 본 런 > Depth 본 런 > RGB seed 43(둘 다 완료 후 3시간+ 남을 때만).

## 8. Phase 5 — 평가 → `METRICS.md`, `RESULTS_DRAFT.md` [A8]

- 정의 고정: 셀 양성 = GT 위험 칸 / 예측 = sigmoid > τ_op / **τ_op = 0.5 기본 + τ*(val에서 셀 단위 F1 최대점) 병기**, {0.3,0.5,0.7} 스윕 부록.
- **층화 recall**: strict-H(헤드라인) / E / V — τ_int·τ_edge 후보별 민감도 표 동반. **허위경보**: test hazard-off 프레임에서 위험 칸 ≥1 예측 비율 + 셀 FPR. 거리 밴드별 분해(경계 m값 미확보 시 밴드 인덱스 기준).
- **트윈 페어드 분석**: 대응쌍 존재 시 hazard on−off 예측 차(같은 씬·같은 시점) — 인과성 핵심 증거로 별도 표.
- 95% CI: 페어드 부트스트랩(프레임 단위 리샘플, 10,000회), RGB−Depth 차이 CI 포함. 8/14 논문(Joint SR-HPE)의 부트스트랩 코드를 탐지해 재사용하되, **못 찾으면 표준 구현을 직접 작성**(`DECISIONS.md` 기록) — 이 코드의 부재는 차단 사유가 아니다.
- 시각화 12장: 맞춘 H / 놓친 H / off-프레임 허위경보 각 4장. (보너스: H 프레임 Grad-CAM.)

# 부록 A — 설계 확정 사양 (과거 결정 추적본. [확정]=승용 확정 / [기본값]=오늘 밤 임시, 아침 승인 필요 / [코드가 진실]=리포지토리에서 추출)

**A1. 과제·도메인 [확정]** — 보행 생활권(보도·캠퍼스 경로·뚝방·농로)의 낙차(negative obstacle) 위험. 최소 위험 규모 = **깊이 0.3m** (건축 계단 기준·NWS 침수 30cm·Spot 300mm·UGV 문헌의 4도메인 수렴값). 연석(10~25cm) = 비위험. 라벨러 경계 테스트 대역 0.28~0.32m.

**A2. 출력 = 폴라 위험 그리드 [확정: 5 방위 × 3 거리 = 15칸]** — 계보: VFH 극좌표 섹터 + Stixel 방향별 출력 + Direct Perception 압축 표현. 기여는 "격자를 가려진 위험 확률로 채우는 것". **[코드가 진실]**: 방위각 범위·경계값, 거리 밴드 경계(m), 셀 양성 판정(피복 규칙), 방위 방향·원점·pitch 부호. 코드에 없으면 해당 GT 파생 금지.

**A3. V/E/H 티어 [확정 정의]** — 분류 기준은 가림의 '양'이 아니라 **증거의 '출처'**:
- **V** = 위험 **내부면**(기준 지면 아래 바닥·안쪽 벽) 픽셀이 가시 (≥ τ_int).
- **E** = 내부면 비가시 + **개구 경계**(지면과 만나는 테두리 림 밴드, near/far edge)의 가시 비율 ≥ τ_edge. "안은 안 보여도 지면이 거기서 끊기는 건 보인다."
- **H** = 위험 자체가 기여하는 픽셀이 기준 미만/전무 — 다른 표면(울타리·수풀·벽·지형 마루)에 차폐, **맥락 단서만 남음**.
- 판정 계층적: V → E → H (혼합 시 상위 우선). 티어 단위 = 위험 인스턴스 × 프레임.
- 부칙 [확정]: ① 울타리·표지판·위험 너머 일반 지면 조각은 **티어 근거가 아니라 맥락 단서** — 티어를 올리지 않음. ② 맞은편 안쪽 벽이 조금이라도 보이면 내부면 → V. ③ 엣지가 서브픽셀로 소멸하는 원거리는 가림이 아니라 해상도 한계 — H에 넣지 말고 거리 밴드 축에서 처리, 유효 평가 거리 명시. ④ 투과성 가림물(유리 난간 등) 프레임은 데이터셋 제외(자동 라벨과 실제 증거 상태의 진리값 불일치). ⑤ FOV 밖 = '가림'이 아니라 제외.
- 조작적 정의 [확정]: 내부면 semantic ID + 림 밴드(폭 수 cm) ID → 가시 픽셀 카운트. **raw 저장·후처리 구간화 원칙** — raw 가시 수치가 프레임별 저장되어 있어야 함.
- **τ_int·τ_edge [미확정 — 승용이 씬 점검으로 캘리브레이션하기로 결정]**. 야간 규칙: strict-H(기여 픽셀 0)를 1차 정의로, τ 후보 민감도 병산, 아침 확정.

**A4. 훈련-태그 분리 [야간 운영 규칙]** — 훈련은 폴라 GT만 필요. V/E/H는 평가 층화·분할 구성용. τ 미확정은 훈련 비차단.

**A5. 씬 구성 [확정]** — 33씬 = 계단 본편 21 + batch1 12(비계단 낙차 4 포함). 범위 밖 씬은 하드 네거티브로 재활용(벽화 가짜 계단 트롱프뢰유 포함). 씬 조립 공식: 경로 + 위험 + **토글형 맥락 단서** + 가림 기제. 대응쌍 = hazard on/off·cue on/off 토글 변형. 난간 상태표 {absent/continuous/gap-stair/gap-drop/damaged}, 단서 역할 honest/deceptive.

**A6. 분할 [확정]** — 씬 단위 + **동일 씬의 모든 토글 변형 동반 이동**(파라메트릭 생성 유사 씬 누수 방지가 제1원칙). 무위험 평가는 test 씬의 hazard-off 변형으로.

**A7. 카메라 [확정]** — 시점 밴드: 높이 0.3~2.0m, pitch −15°~+5°, raw 저장·훈련 직전 구간화. 분포 몰림 점검. (캠페인 probe의 h1.8m/5m은 별도 관측 조건.)

**A8. 지표 [확정]** — 헤드라인 = 완전가림(H) recall + 짝 지표 허위경보. 페어드 부트스트랩(8/14 논문 코드). 트윈 페어드 분석(대응쌍 on−off 차)은 맥락 사용의 인과 증거. Grad-CAM은 정성 보강 [기본값: 보너스].

**A9. Depth 대조 [확정]** — 동일 아키텍처·출력·학습, 입력만 상이. "geometry 상한" 해석은 V-tier 한정. [기본값] 시뮬 클린 depth(노이즈 미부가).

**A10. 실측 [금일 결정]** — sim 학습 + real 평가 구도. 하행 계단 부지 우선, 파일럿 20장 선검증 후 본촬영.
